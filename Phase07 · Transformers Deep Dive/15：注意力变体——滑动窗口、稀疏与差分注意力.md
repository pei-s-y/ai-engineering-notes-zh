## 零、初学者先读：给“每人都看每人”的圆桌会议改规则

> 2026-11-06 整理的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。[第14课](<14：从零搭一个Transformer——总装课.md>)装出了全注意力的标准机；本课给它换三种“看人规则”——省显存、省算力，还能顺手治一种注意力怪病。前置：[第02课](<02：从零实现自注意力——Q、K、V与缩放点积.md>)的自注意力与[第12课](<12：KV缓存与Flash Attention——推理优化.md>)的 KV 缓存。

### 0.1 先理解这一课在做什么

标准（全）注意力像一个全员圆桌会议：每个 token 都能看所有其他 token，谁都能插话——代价是 N 个参会者的会议有 N² 条“视线”，上下文一长，显存先爆。Flash Attention（第12课）能把激活显存藏起来，但每条视线还是得真算一次——算力账单没变。

本课讲三类“改会议规则”的方案：

1. **滑动窗口注意力（SWA, sliding window attention）**：每人只能看左右几个邻居。视线条数从 N² 降到 N×W。
2. **稀疏/块注意力（sparse / block attention）**：只挑指定的几对参会者互相看（比如局部邻居 + 每隔几个取一个“哨兵”），其余视线强制归零。
3. **差分注意力（differential attention）**：算两份注意力相减。专治“注意力洼地”——softmax 逼着每行权重加起来等于 1，那些其实谁都不想看的 token 只能把权重泼给开头几个位置，相减可以抵消这种泼水。

这三类不互斥。2026 年的前沿模型常常混着用：多数层 SWA-1024、每 5 层掺 1 层全局全注意力、再放几个差分头做检索清理。Gemma 3 的 5:1 SWA:全局比例是当前的教科书默认（原课）。

### 0.2 本课术语先翻成白话

- 全注意力（full attention）：每个查询看全部历史位置，N² 条视线，一切变体的基线
- 滑动窗口注意力（SWA）：每个查询只看最近 W 个位置；因果版本是 [i−W+1, i]
- 窗口 W（window）：邻居半径的长度；W≥N 时退化为全注意力，W=1 时各 token 只看自己
- 稀疏/块注意力（sparse/block attention）：预先挑好 (i, j) 配对，其余位置在打分矩阵里填 −∞
- 局部+跨步（local + strided）：OpenAI 稀疏 Transformer 的经典形状——局部窗口外加每隔 stride 个取一个远位置
- 全局 token（global tokens）：Longformer/BigBird 里少数几个“人人都能看、也看人人”的特殊位置（如 [CLS]）
- 差分注意力（differential attention）：两套 Q/K 投影算两份注意力图，A1−λ·A2 相减
- 注意力洼地（attention sink）：softmax 行和恒为 1，无话可说的查询把权重泼给前几个 token 的现象
- λ（lambda）：差分注意力里的可学习混合系数，典型 0.5—0.8
- KV 缓存（KV cache）：推理时存历史 K/V 的账本；SWA 每层只需最近 W 条
- 有效感受野（effective receptive field）：L 层 SWA 堆叠后能“接力”看到 L×W 个 token 回
- 层型混合（layer type mix）：SWA 层与全局层交替堆叠（如 5:1）保质量又省显存
- FlexAttention：PyTorch 2.5+ 的 API，把“mask 写成 Python 函数”编译成 FlashAttention 级内核
- 困惑度（ppl, perplexity）：衡量质量损失的单位，本课对照表用“−0.1 ppl”这类差值说话

### 0.3 用小数字走一遍

**第一幕：数格子。** 取 8 个 token（位置 0—7），对比三种规则下打分矩阵里“可见”的格子数。全因果注意力是下三角，共 1+2+…+8=36 格。SWA 取 window=2（每个 token 只看它和前一个）：

| 查询位置 i | 能看的位置 | 格数 |
|---|---|---|
| 0 | {0}（没有前文） | 1 |
| 1 | {0, 1} | 2 |
| 2 | {1, 2} | 2 |
| 3 | {2, 3} | 2 |
| 4 | {3, 4} | 2 |
| 5 | {4, 5} | 2 |
| 6 | {5, 6} | 2 |
| 7 | {6, 7} | 2 |

合计 1+2×7=15 格，是全注意力 36 格的 42%。再看局部+跨步（window=2、stride=3）：局部邻居 ∪ {0, 3, 6, …} 里的远位置。比如位置 7 能看局部 {6,7} 加跨步 {0,3,6}，合起来 {0,3,6,7}——4 格但已经“够到”了位置 0！全表 24 格，比 SWA 多 9 格，买到的是“看得远”。

**第二幕：感受野接力。** SWA 一层只能看 W 个回，但 L 层堆起来是接力：位置 i 的第 1 层看 i−1，第 2 层的输入含第 1 层输出，于是第 2 层间接看到 i−2……L 层后有效感受野 = L×W。例：26 层、W=1024 → 约 26K 个 token 回，这就是 Mistral 7B 用纯 SWA 堆也能干长文本的原理。

**第三幕：差分相减。** 设某查询的两份注意力 A1=[0.5, 0.3, 0.2]、A2=[0.4, 0.3, 0.3]（三个位置的权重），λ=0.6，则差分权重 = A1−0.6×A2 = [0.5−0.24, 0.3−0.18, 0.2−0.18] = [0.26, 0.12, 0.02]。注意三件事：和是 0.4 不再是 1（差分注意力不强迫“把概率质量花光”，正是它能“闭嘴”的关键）；第 0 位从 0.5 相对放大到 0.26/0.4=65%（真内容被突出）；第 2 位几乎清零（两份注意力一致认为它平庸）。

**第四幕：账本。** N=8192、W=1024 时：全注意力 8192²≈6710 万条视线，SWA 约 1024×8192≈839 万条，省 8 倍；KV 缓存每层从 N 条降到 W 条，128K 上下文、1024 窗口 → 128 倍缩水。

以上是用于理解的算例（格子数、感受野、差分权重均为手算，KV/算力为量级换算），不是新增的训练或性能实测。

### 0.5 理解检查（含参考答案）

**问题1：** window=2 的 SWA 里，位置 0 为什么只看得到自己？

**参考答案：** 可见范围是 [i−W+1, i]=[−1, 0]，左端被 max(0, ·) 截到 0，所以只剩 {0}。同理任何 SWA 的前 W−1 行都比后面的行少格子——序列开头是“自然短视”的。

**问题2：** 既然 SWA 只能看 2 个邻居，26 层后凭什么看到 26K 那么远？

**参考答案：** 层层接力。每层把信息往前挪 W 步：第 1 层把 i−1 的信息带进 i 的表示，第 2 层又把（已含 i−1 信息的）i−1 表示带进来……所以 L 层 SWA 的有效感受野是 L×W 而非 W。代价是信息每传一层都要“过一道手”，长程检索质量弱于真全局注意力——这就是要掺全局层的原因。

**问题3：** 差分注意力算出来的权重和是 0.4 而不是 1，这合法吗？

**参考答案：** 合法，而且正是设计意图。softmax 的行和恒为 1 意味着查询“必须把注意力花光”，这正是注意力洼地的来源；相减后行和可以小于 1（理论上还可为负），模型因此能表达“这里没什么好看的”。代价是输出尺度变了，原论文配套了缩放与重新归一化的处理（本课代码未展示，见第七节）。

**问题4：** 5:1 的 SWA:全局混合是什么意思，为什么不 1:1 或全 SWA？

**参考答案：** 每 6 层里 5 层用 SWA、1 层用全局全注意力。全 SWA 省最多但长程检索吃亏（0.3 第二幕的“过手”衰减）；全全局最贵。1:1 是 Gemma 2 的选择，Gemma 3 改成 5:1——全局层像“信息中继站”，每 6 层把远处的关键信息（对话开头、文档标题）刷新一次到局部视野里，5:1 在质量与显存间取得当前经验最优点（原课参考）。

## 一、这一课解决什么问题？

全注意力在序列长度上的显存与算力都是 O(N²)。对 128K 上下文的 Llama 3 70B，每层是 160 亿个注意力格子，乘 80 层。Flash Attention（第12课）藏掉了 O(N²) 的激活显存，但不改变算术成本——每个 token 仍然要和每个 token 算一次相似度。

本课的三类变体改的是注意力矩阵自身的拓扑（哪些位置对真的被计算）：

1. **滑动窗口注意力（SWA）**：每个 token 只看固定窗口内的邻居。显存与算力降到 O(N·W)。用例：Gemma 2/3、Mistral 7B 的首层组、Phi-3-Long（原课）。
2. **稀疏/块注意力**：只有选中的 (i, j) 配对被算分，其余强制零权重。用例：Longformer、BigBird、OpenAI 稀疏 Transformer。
3. **差分注意力**：两套独立 Q/K 投影算两张注意力图，相减。杀掉把权重泼向前几个 token 的“注意力洼地”。出处：微软 DIFF Transformer（2024）。

它们可以共存：2026 年前沿模型常常是“多数层 SWA-1024、每五层一个全局全注意力、再加几个负责检索清理的差分头”。Gemma 3 的 5:1 SWA:全局是当前教科书默认（原课）。

## 二、核心概念与推导

### 2.1 滑动窗口注意力（SWA）

位置 i 的查询只看 [i−W, i]（因果 SWA）或 [i−W/2, i+W/2]（双向）。窗口外的位置在打分矩阵里填 −∞。原课的格子图（N=8、W=4，转录）：

```
full causal:           sliding window (W=4):
positions 0-7          positions 0-7, W=4
    0 1 2 3 4 5 6 7        0 1 2 3 4 5 6 7
0 | x                0 |  x
1 | x x              1 |  x x
2 | x x x            2 |  x x x
3 | x x x x          3 |  x x x x
4 | x x x x x        4 |    x x x x
5 | x x x x x x      5 |      x x x x
6 | x x x x x x x    6 |        x x x x
7 | x x x x x x x x  7 |          x x x x
```

数一数：全因果 36 格；W=4 的 SWA 是 1+2+3+4×5=26 格（补充：与 0.3 的 W=2 算例同一套数法）。N=8192、W=1024 时打分矩阵期望有 1024×8192 个非零行项——8 倍缩减（原课）。

**KV 缓存随 SWA 缩水**：每层只需保留最近 W 个 token 的 K 和 V。对 Gemma-3 量级的配置（1024 窗口、128K 上下文），KV 缓存缩 128 倍（原课；补充换算：131072/1024=128）。

**质量代价**：纯 SWA 的长程检索弱。补救：SWA 层与全局层交错。Gemma 3 用 5:1；Mistral 7B 用纯因果 SWA 堆叠，靠窗口重叠让信息“向前流”——每层把有效感受野扩 W，L 层后可看 L×W 个 token 回（原课；0.3 第二幕的手算就是这条定理的 8 格版）。

### 2.2 稀疏 / 块注意力

提前选定 N×N 的稀疏模式，三种经典形状（原课）：

- **局部+跨步（OpenAI 稀疏 Transformer）**：看最近 W 个 + 之前每隔 stride 个取一个。局部与长程兼得，算力 O(N·√N)。
- **Longformer / BigBird**：局部窗口 + 少数全局 token（如 [CLS]，人人看它、它看人人）+ 随机稀疏连接。同等质量约 2 倍上下文（经验值，原课）。
- **原生稀疏注意力（DeepSeek NSA，2025）**：学习哪些 (Q, K) 块重要，在内核层跳过零块，兼容 FlashAttention。

稀疏注意力本质是内核工程故事：数学很简单（给打分矩阵盖 mask），收益来自“零格子根本不进 SRAM”。FlashAttention-3 与 2026 年的 FlexAttention API 让自定义稀疏模式在 PyTorch 里成为一等公民（原课）。

### 2.3 差分注意力（DIFF Transformer，2024）

普通注意力的“注意力洼地”问题：softmax 强制每行和为 1，那些没有明确想看的 token 只能把权重泼给第一个（或前几个）token——这偷走了本该给真内容的容量。差分注意力算两份注意力再相减（原课公式转录）：

$$A_1 = \mathrm{softmax}(Q_1 K_1^T / \sqrt{d}),\qquad A_2 = \mathrm{softmax}(Q_2 K_2^T / \sqrt{d})$$

$$\text{DiffAttn} = (A_1 - \lambda \cdot A_2) V$$

λ 是可学习标量（典型 0.5—0.8）。A1 捕捉真内容权重，A2 捕捉洼地；相减抵消洼地、把权重重新分配给相关 token。0.3 第三幕的三格手算就是这条公式的最小版本。报告的结果（微软 2024，原课参考）：困惑度低 5—10%、同等训练长度下有效上下文长 1.5—2 倍、大海捞针检索更锐利。

### 2.4 变体对照表（原课转录）

| 变体 | 算力 | KV 缓存 | 相对全注意力质量 | 生产使用 |
|---------|---------|----------|-----------------|----------------|
| 全注意力 | O(N²) | 每层 O(N) | 基线 | 每个模型的默认层 |
| SWA（窗口 1024） | O(N·W) | 每层 O(W) | −0.1 ppl，配全局层则良好 | Gemma 2/3、Phi-3-Long |
| 局部+跨步稀疏 | O(N·√N) | 混合 | 与 SWA 相近 | OpenAI 稀疏 Transformer、Longformer |
| BigBird（局部+全局+随机） | 近似 O(N) | 混合 | 2 倍上下文下持平全注意力 | 早期长上下文 BERT |
| 原生稀疏（DeepSeek-V3.2） | O(N·激活比例) | O(N) | 0.05 ppl 以内 | DeepSeek-V3.2，2025 |
| 差分 | O(2·N²) | O(2N) | −5 到 −10% ppl | DIFF Transformer，2026 初的模型 |

读表提醒（补充）：差分是“两倍算力换质量”，其余都是“改拓扑省钱”；没有一列是免费的——SWA 省的是显存与算力，付的是长程检索；差分付算力，收的是检索锐度。

## 四、Build It：原课分步代码与中文讲解

原课实现一个因果掩码比较器，在玩具序列上并排展示全注意力、SWA、local+strided、差分注意力。

### 4.1 第 1 步：全因果掩码（基线，原课代码）

第 07 课的基线：下三角；对角线以上是零权重（−∞）。

~~~python
# 本块中文说明：全因果掩码——j>i 的格子填 -inf（永远不可见）。
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
~~~

0.3 的数法：这个 n×n 下三角共 n(n+1)/2 个 0 格，n=8 时 36 格。

### 4.2 第 2 步：滑动窗口因果掩码（原课代码）

一个参数——window。window≥n 时退化为全因果；window=1 时每个 token 只看自己。

~~~python
# 本块中文说明：SWA 掩码——每行只开最近 window 个格子。
def swa_mask(n, window):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
    return M
~~~

（核对）可见范围是 [i−window+1, i]，共 window 格（前 window−1 行被 0 截短）。0.3 的 window=2 例子里行 0 只有 1 格、其余行 2 格，合计 15——与代码行为一致。

### 4.3 第 3 步：局部+跨步稀疏掩码（原课代码）

稠密局部窗口，加上从序列开头起每隔 stride 个取一个的远位置。感受野随层数按对数步增长（原课）。

~~~python
# 本块中文说明：局部窗口 ∪ 每隔 stride 个的跨步远位置。
def strided_mask(n, window, stride):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
        for j in range(0, i + 1, stride):
            M[i][j] = 0.0
    return M
~~~

（核对）跨步循环从 0 覆盖到 i，与局部窗口取并集（同一格写两次 0.0 无副作用）。0.3 的 window=2、stride=3 例子里位置 7 可见 {6,7}∪{0,3,6}={0,3,6,7}，全表 24 格。

### 4.4 第 4 步：差分注意力（原课代码）

两次注意力通路，用可学习混合系数相减。代码里对比单注意力 vs 差分的注意力洼地热图，观察洼地塌缩（原课）。

~~~python
# 本块中文说明：两份注意力图相减，抵消注意力洼地。
def diff_attention(Q1, K1, Q2, K2, V, lam):
    A1 = softmax_causal(Q1 @ K1.T / sqrt_d)
    A2 = softmax_causal(Q2 @ K2.T / sqrt_d)
    return (A1 - lam * A2) @ V
~~~

（核对）`softmax_causal`、`sqrt_d`、矩阵乘法 `@` 均为页面未定义的伪接口/依赖——真实实现需要因果版 softmax（对 −∞ 掩码取指数后归一）与缩放因子 √d（第02课）。公式本体与 2.3 节一致：先各自 softmax 再相减（不是先相减再 softmax）。

### 4.5 第 5 步：KV 缓存尺寸（原课文字描述）

原文：打印 N=131072 时每种变体的每层缓存大小。SWA 与稀疏变体降 10—100 倍，差分翻倍。有意识地付你的显存账。对照 0.3 第四幕：SWA 每层 O(W)，128K/1024=128 倍缩水；差分每层 O(2N)，翻倍——表里数字都能从“每行可见格子数”直接推出来。

## 五、把代码运行起来：补充入口与检查

（补充）原课页面没有展示 main.py 全文；以下是我写的最小检查脚本（纯标准库），复核 0.3 的格子数与差分手算。本机已实际运行：

~~~python
# 本块中文说明：复算 0.3 的格子数与差分权重（补充，非原课代码）。
def causal_cells(n):
    return sum(1 for i in range(n) for j in range(n) if j <= i)

def swa_cells(n, w):
    return sum(1 for i in range(n)
               for j in range(n) if max(0, i - w + 1) <= j <= i)

def strided_cells(n, w, s):
    total = 0
    for i in range(n):
        vis = set(range(max(0, i - w + 1), i + 1)) | set(range(0, i + 1, s))
        total += len(vis)
    return total

print(causal_cells(8))          # 本机输出：36
print(swa_cells(8, 2))          # 本机输出：15
print(swa_cells(8, 4))          # 本机输出：26（对照 2.1 的原课格子图）
print(strided_cells(8, 2, 3))   # 本机输出：24

# 差分手算：A1 - lam * A2
A1, A2, lam = [0.5, 0.3, 0.2], [0.4, 0.3, 0.3], 0.6
diff = [a - lam * b for a, b in zip(A1, A2)]
print(diff, sum(diff))           # 本机输出：[0.26, 0.12, 0.02] 0.4（和不再为 1）

# 感受野与账本换算
print(26 * 1024)                # 本机输出：26624 —— 26 层 SWA 的有效感受野
print(8192 ** 2, 1024 * 8192)   # 67108864 vs 8388608 —— 8 倍算力缩减
print(131072 // 1024)           # 本机输出：128 —— KV 缓存缩水倍数
~~~

进一步检查（建议，需自己扩展）：用 4.2 的 `swa_mask(8, 4)` 与 4.1 的 `causal_mask(8)` 逐格比对，验证 window=8 时 SWA 与全因果**逐位相同**——这是练习 1 的验收内容；再给 `strided_mask` 的每行打印可见位置，与 0.3 的表格对号。

（核对）原课此处注释掉了打印行——加载 27B 模型只为看两个配置字段成本太高，实操建议直接读模型卡片或 config.json 的 `sliding_window` 与 `layer_types` 字段。

FlexAttention（PyTorch 2.5+）接受一个掩码函数（原课代码转录）：

~~~python
# 本块中文说明：FlexAttention —— mask 写成 Python 函数，编译成 Triton 内核。
from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def swa_pattern(b, h, q_idx, kv_idx):
    return (q_idx - kv_idx < 1024) & (q_idx >= kv_idx)

mask = create_block_mask(swa_pattern, B=batch, H=heads, Q_LEN=n, KV_LEN=n)
out = flex_attention(q, k, v, block_mask=mask)
~~~

这会编译成自定义 Triton 内核：常见模式下速度在 FlashAttention-3 的 10% 以内，而掩码只是个 Python 可调用对象（原课）。注意 `swa_pattern` 的两个条件分别是“距离在窗口内”与“因果方向”——正是 0.3 表格那两列的向量化表达。

**何时选哪种（原课）**：纯全注意力——上下文 ≤16K 或检索质量至上；SWA+全局混合——长上下文（>32K）、训练与推理都吃显存，是 2026 年 32K 以上的默认；稀疏块注意力——定制内核、定制模式，留给专门负载（检索、音频）；差分注意力——凡是洼地污染伤害大的场景（长上下文 RAG、大海捞针）。

## 七、失败模式、原文边界与工程注意

1. SWA 的窗口设得比任务需要短：对话开头的系统提示在有效感受野之外，模型“忘了”指令。先用 L×W 估有效感受野（0.3 第二幕），再留余量。
2. 纯 SWA 堆叠做长程检索是已知弱项——0.3 第二幕的“过手”是打折传递，不是无损转发；要检索质量就掺全局层（原课：Gemma 3 的 5:1）。
3. 差分的伪接口：4.4 的 `softmax_causal`、`sqrt_d` 页面未定义（核对），照抄会 NameError；先补因果 softmax 与 d 的定义。
4. 差分输出尺度问题：行和不再是 1（0.3 第三幕的 0.4），直接接入残差流会让输出幅度不稳；DIFF Transformer 论文在每头输出上做了缩放/重归一化，本课代码未展示（补充边界）。
5. 掩码与缓存不同步：SWA 的 KV 缓存滚动丢弃时若窗口判断与训练掩码差一（off-by-one），模型会静默劣化——`max(0, i - window + 1)` 与 `i - window` 是两种约定，统一用一种（补充）。
6. “−0.1 ppl”“5—10% 困惑度改进”“2 倍上下文”等数字都是论文/原课参考值，与你的任务、数据、模型尺寸无关；迁移前用自己的负载重测（原文边界）。
7. FlexAttention 的收益在编译后的内核里：忘了 `create_block_mask` 直接把 Python 函数传给 `flex_attention` 会退回慢路径（补充，按原课 API 用法理解）。
8. 记忆体量的直觉账：SWA 省的是注意力格子与 KV 缓存，**不省** FFN 与 logits 的显存——128K 上下文的瓶颈常常不在注意力了，别指望换个 mask 救一切（补充）。

## 十、术语与完成标准

全注意力：N² 视线的基线；SWA：每查询最近 W 格，KV 缓存每层 O(W)；窗口 W：W≥N 退化全注意力、W=1 只看自己；稀疏/块注意力：预选 (i, j) 配对其余 −∞；局部+跨步：邻居 ∪ 每 stride 个远位置，O(N·√N)；全局 token：Longformer/BigBird 人人可看的少数位置；差分注意力：A1−λ·A2 相减；注意力洼地：softmax 行和为 1 逼出的泼水权重；λ：可学习混合系数，0.5—0.8；有效感受野：L 层 SWA 接力 L×W；层型混合：SWA 与全局层交替（Gemma 3 的 5:1）；FlexAttention：掩码写成 Python 函数编译成内核；原生稀疏注意力：DeepSeek 的可学习块稀疏，内核层跳零块。
