## 一、从哪里开始

直接按 01→16 顺序学习即可。下面分组只帮助理解关系，不要求跳过任何课：

- 01—04：发动机的四个零件：RNN 为什么不够 → 自注意力 → 多头 → 位置编码。这四课是全阶段的地基，02 的手算要能默写。
- 05—08：三种成品：完整 Transformer（编码器+解码器）→ BERT（只编码器）→ GPT（只解码器）→ T5/BART（两半都用）。学完能说清「一句话进来，三种架构各拿哪半、各做什么任务」。
- 09—10：换模态：ViT 把图片切成块当句子读，Whisper 把音频转成谱当序列读——同一台发动机，换一种燃料。
- 11—12：省钱的两板斧：MoE 让参数多而激活少，KV 缓存让生成不用重复算。
- 13：缩放定律：算力、数据、参数的预算表——为什么大模型是「算出来的」而不是「试出来的」。
- 14：总装课：从零搭一个完整 Transformer，前十三课的零件全部上场。
- 15—16：前沿变体：注意力怎么省（滑动窗口/稀疏/差分）、解码怎么快（投机解码）。

与前后的衔接：本阶段把第五阶段（NLP）第 10 课「注意力机制」的种子长成整棵树；也是第十阶段（LLM from Scratch）所有内容的前置——预训练、量化、推理优化的每一步都在这里出现过手算版。

## 三、每课怎样使用这份笔记

每课均按以下结构编排：零、初学者先读（本课在做什么、术语白话、小数字算例、代码衔接、理解检查含参考答案）→ 问题 → 概念与算例 → 操作前准备 → Build It 逐步讲解和代码 → 补充入口与结果检查 → Use It → 失败模式/纠错 → 中文 Ship It 模板 → 原课练习 → 术语与完成清单 → 验证范围/许可。

学习时可以分三遍：

1. 先读「零、初学者先读」，自己把小数字算例算一遍（每课的 0.3 都设计成可以纸笔复核），再答 0.5 的理解检查。
2. 再看 Build It，按依赖顺序在自己的 WSL 练习环境里逐块运行；把补充入口中的变量先准备好。不要把包含 `>>>` 的交互展示、注释占位或省略号当完整脚本直接执行。
3. 最后核对结果、失败模式与练习。先完成 Easy；Medium/Hard 也完整保留，等数据、算力或前置知识具备再做，不要求首次读完就全部训练成功。

原文代码与修正版分开标识。保留来源代码不代表它无错；紧接的解释会指出缺变量、伪接口、API 版本或逻辑问题。凡标（核对/补充）处，原文均原样保留、未吞改。数值分三类：原课页面给的数字标「原课参考」；可以纸笔复核的等式标「可手算预期」；本机实际运行过的在第十一节的验证记录里注明——语法检查通过不等于变量齐全或结果正确。

本阶段的特殊情况：部分课程页只展示文字描述、完整代码在未展示的 `code/main.py` 里（第 05—08、13、14 课多处）。这些位置以「（补充，非原课代码）」的自写代码补足教学，均显式标注、未冒充原文；Learn 型课（01、08、10、13）本就代码少，第四节按原课实际内容处理。

## 四、WSL 操作和依赖约定

在 Ubuntu 中，先进入课程仓库；下面使用通用示例目录，请按实际位置替换：

~~~bash
cd ~/projects/ai-engineering-from-scratch
python3 --version
python3 -m pip --version
~~~

先激活你原有的虚拟环境，再检查 python 和 pip 是否属于同一环境。不确定环境名时不要照抄不存在的激活路径。若确实还没有环境，可在自己的练习项目中创建一次：

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version
~~~

笔记里的 `python -m pip install` 只供你按课选择安装，本次未替你安装。Windows Python 与 WSL Python 的包、GPU 配置不共享。本阶段大部分手算只需 Python 标准库与 NumPy；Use It 环节的 HuggingFace/PyTorch 示例需按课安装，且多数要下载预训练模型（数 GB 起），建议读到再做。原文的库版本与模型名可能变化，笔记已标出易漂移部分；遇到报错请保留完整错误、Python 版本、所在系统及包版本。

## 六、阅读中反复注意的区别

- 自注意力是「加权平均」不是「连线」：权重来自 QK 相似度、softmax 归一，读懂 02 课的 2×2 手算就永远不会再怕它。
- BERT 双向、GPT 单向、T5 两半——掩码的形状决定了模型能看见什么，能看见什么决定了它能做什么任务。
- 模态不改变发动机：ViT 与 Whisper 只是把图和声音翻译成「token 序列」，后面还是 02—05 课那台机器。
- MoE、KV 缓存、滑动窗口、投机解码都在做同一件事——把「计算」和「参数/信息」解耦：参数多不等于算得多，历史 KV 不必重算，看不见的位置不必看，小模型的草稿不必逐字生成。
- 缩放定律是预算表不是玄学：算力固定时参数和数据怎么分，Chinchilla 给出过可计算的回答。
- 原文效果数字、加速倍数与模型配置是来源背景，不是本次实测，也不是通用定律。
