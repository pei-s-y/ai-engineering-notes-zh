### 0.1 先理解这一课在做什么

前九课攒了一抽屉零件，每次训网络都要从五份笔记里复制粘贴再手工接线。框架解决的就是这件事：PyTorch 的 `nn.Module`/`nn.Sequential`/`optim.Adam`/`DataLoader` 不是魔法，只是一套“让零件即插即用”的组织模式。本课用约 500 行纯 Python（不用 numpy、零第三方依赖）造一个同骨架的迷你框架：能定义任意前馈网络、用 SGD 或 Adam 训练、分批喂数据、带 Dropout 和 BatchNorm。造完你会明白 `model.train()`/`model.eval()` 为什么存在、`optimizer.zero_grad()` 为什么是独立调用——因为每一行都是你自己写的。

### 0.2 本课术语先翻成白话

- Module（模块）=框架里的“零件”基类：会 forward（往前算）、会 backward（往回传梯度）、会 parameters（交出可训练参数）
- Sequential（顺序容器）=把一串 Module 按顺序接起来的容器；它自己也是 Module（组合模式：一串零件又是零件）
- 前向/反向传播（forward/backward pass）=数据从左到右流过模块得预测 / 损失梯度从右到左流回，沿途攒下参数梯度
- parameters（参数）=优化器能更新的全部权重与偏置
- 优化器（optimizer）=拿着“参数+梯度”的扁平清单做更新的算法，不知道网络长什么样
- DataLoader（数据加载器）=把数据集切块成批、每轮可洗牌的迭代器
- 训练/评估模式（train/eval）=一个开关：Dropout 与 BatchNorm 在训练时用随机/批统计，在评估时用直通/运行统计
- zero_grad（清零梯度）=把上一步攒的梯度清空，为下一步反传做准备
- 梯度累积（gradient accumulation）=多个样本的梯度先加起来再一起更新

### 0.3 用小数字走一遍

造一个最小网络：`Sequential(Linear(2,2), ReLU(), Linear(2,1))`，配 `MSELoss` 与 `SGD(lr=0.1)`。为了可手算，权重不用随机数，直接设：第一层 W1=[[0.1, 0.2], [0.3, −0.1]]、b1=[0, 0]；输出层 W2=[[0.2, −0.1]]、b2=[0]。样本 x=[1, 2]，目标 t=[0.5]。

**前向：** z1=[0.1×1+0.2×2, 0.3×1−0.1×2]=[0.5, 0.1]；ReLU 后 h=[0.5, 0.1]；pred=0.2×0.5+(−0.1)×0.1+0=0.09；损失=(0.09−0.5)²=0.1681。

**反向（对照框架每层的 backward）：** MSE 对 pred 的梯度=[2×(0.09−0.5)/1]=[−0.82]。输出层 Linear 拿到 −0.82：grad_W2=[−0.82×0.5, −0.82×0.1]=[−0.41, −0.082]、grad_b2=−0.82，回传给 ReLU 的输入梯度=[−0.82×0.2, −0.82×(−0.1)]=[−0.164, 0.082]。ReLU 两分量都为正，直通。第一层 Linear 拿到它：grad_W1 两行=δ×x：[[−0.164, −0.328], [0.082, 0.164]]，grad_b1=[−0.164, 0.082]。

**SGD 更新（lr=0.1）：** W2←[[0.241, −0.0918]]，b2←0.082；W1←[[0.1164, 0.2328], [0.2918, −0.1164]]，b1←[0.0164, −0.0082]。

**再前向验证：** z1=[0.5984, 0.0508]；pred=0.241×0.5984−0.0918×0.0508+0.082≈0.2216；损失≈(0.2216−0.5)²≈0.0775。0.1681→0.0775，一步更新损失降了一半多。这一步“前向→反传→更新→再前向验证”就是 `train()` 循环里每个样本的经历，也是整台机器的一次完整心跳。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么优化器只拿一个扁平的参数清单，而不直接持有网络？

**参考答案：** 解耦。优化器的数学（SGD 或 Adam）只需要“参数值+它的梯度”，与它是第几层、什么结构无关。这样同一个优化器能训练任何网络，新层类型只要按协议交出参数就能被优化——PyTorch 的 `optimizer.step()` 对任何 `nn.Module` 通用正是这个设计。

**问题2：** `optimizer.zero_grad()` 为什么必须是单独一步？忘了会怎样？

**参考答案：** 框架里梯度用累加（`+=`）攒，方便将来做批量累积。如果每步更新前不清零，这一步的梯度会叠在上一步的残渣上，等于用了错误的方向和两倍的步长。PyTorch 里同样如此——这是初学者最常踩的坑之一。

**问题3：** Dropout 在训练时随机置零、评估时直通，为什么还要把留下的值放大 1/(1−p)？

**参考答案：** 为了期望不变：训练时每个元素以 (1−p) 概率存活并被放大 1/(1−p)，期望=原值；评估时不做任何处理也不改变尺度。若不放大，训练时的期望幅度是评估的 (1−p) 倍，两层行为脱节。

## 二、核心概念与推导

### 2.1 Module 抽象：什么是“零件”

PyTorch 里每个层都继承 `nn.Module`。一个 Module 三个责任：forward（给定输入算输出）、parameters（交出全部可训练权重）、backward（算梯度；PyTorch 由 autograd 代劳，我们的版本手写）。Linear、ReLU、Dropout、BatchNorm 都是 Module——接口统一，零件才能互换。

### 2.2 Sequential 与组合模式

`nn.Sequential` 把模块串成链：前向从左到右依次喂数据，反向从右到左依次回传。容器本身也是 Module（有 forward/backward/parameters）——一串 Module 又是 Module，这就是组合模式（composite pattern）：网络可以无限嵌套拼装而框架不需要任何新代码。

### 2.3 训练模式与评估模式

Dropout 训练时随机置零、评估时全通过；BatchNorm 训练时用当前批统计、评估时用运行平均。`train()`/`eval()` 切换每个 Module 的 `training` 标志，Sequential 会递归传给子模块。这是框架里唯一的“状态开关”，也是新手最常忘调的（忘了 eval，测试结果带随机性）。

### 2.4 优化器：只认参数清单

优化器更新参数只用梯度：SGD 是 `param -= lr * grad`，Adam 额外维护动量与二阶矩估计。优化器完全不知道网络架构——它只看到一份扁平的“参数+梯度”清单（条目是四元组 `(容器, i, j, 梯度容器)`；补充：Python 的 float 不可变、无法按引用传递单个数，“容器+下标”定位是纯 Python 实现的聪明绕行）。

### 2.5 DataLoader 与训练循环

分批的两个理由：大问题的全量数据放不进内存；小批梯度自带的噪声有助于逃出局部极小。DataLoader 把数据切成批、每轮可选洗牌。训练循环的时序：每个 epoch 里 DataLoader 吐批 → 模型前向 → 损失 → 反向攒梯度 → 优化器 step → zero_grad 清梯度。0.3 节就是这循环跑一轮的慢放：前向=Linear→ReLU→Linear，反向=criterion.backward→Sequential.backward（从右到左），更新=SGD.step，0.1681→0.0775 的损失下降是整台机器一次完整心跳的投影。

## 四、Build It：原课分步代码与中文讲解

### 4.1 第 1 步：Module 基类

全框架最短的类，也是“什么是零件”的定义：默认训练模式，forward/backward 抛 NotImplemented，parameters 默认空。

~~~python
# 本块中文说明：所有模块的抽象基类。
class Module:
    def __init__(self):
        self.training = True

    def forward(self, x):
        raise NotImplementedError

    def backward(self, grad):
        raise NotImplementedError

    def parameters(self):
        return []

    def train(self):
        self.training = True

    def eval(self):
        self.training = False
~~~

### 4.2 第 2 步：Linear 层

最核心的零件。初始化用 `std=sqrt(2/fan_in)`——正是[第08课](<08：权重初始化——零、随机、Xavier与Kaiming.md>)的 Kaiming 公式。forward 算 Wx+b 并缓存输入；backward 同时攒偏置梯度、攒权重梯度（grad[i]×input[j]）、算出回传上游的输入梯度（grad[i]×weights[i][j]）。

~~~python
# 本块中文说明：全连接层，前向 Wx+b，反向攒参数梯度并回传输入梯度。
import math
import random


class Linear(Module):
    def __init__(self, fan_in, fan_out):
        super().__init__()
        std = math.sqrt(2.0 / fan_in)
        self.weights = [[random.gauss(0, std) for _ in range(fan_in)] for _ in range(fan_out)]
        self.biases = [0.0] * fan_out
        self.weight_grads = [[0.0] * fan_in for _ in range(fan_out)]
        self.bias_grads = [0.0] * fan_out
        self.fan_in = fan_in
        self.fan_out = fan_out
        self.input = None

    def forward(self, x):
        self.input = x
        output = []
        for i in range(self.fan_out):
            val = self.biases[i]
            for j in range(self.fan_in):
                val += self.weights[i][j] * x[j]
            output.append(val)
        return output

    def backward(self, grad):
        input_grad = [0.0] * self.fan_in
        for i in range(self.fan_out):
            self.bias_grads[i] += grad[i]
            for j in range(self.fan_in):
                self.weight_grads[i][j] += grad[i] * self.input[j]
                input_grad[j] += grad[i] * self.weights[i][j]
        return input_grad

    def parameters(self):
        params = []
        for i in range(self.fan_out):
            for j in range(self.fan_in):
                params.append((self.weights, i, j, self.weight_grads))
            params.append((self.biases, i, None, self.bias_grads))
        return params
~~~

### 4.3 第 3 步：激活模块

ReLU 缓存掩码、Sigmoid/Tanh 缓存输出——各自缓存反传需要的东西（第 03 课链式法则的落地，见 0.5 问题 2）。

~~~python
# 本块中文说明：ReLU、Sigmoid、Tanh 三个激活模块。
class ReLU(Module):
    def __init__(self):
        super().__init__()
        self.mask = None

    def forward(self, x):
        self.mask = [1.0 if v > 0 else 0.0 for v in x]
        return [max(0.0, v) for v in x]

    def backward(self, grad):
        return [g * m for g, m in zip(grad, self.mask)]


class Sigmoid(Module):
    def __init__(self):
        super().__init__()
        self.output = None

    def forward(self, x):
        self.output = []
        for v in x:
            v = max(-500, min(500, v))
            self.output.append(1.0 / (1.0 + math.exp(-v)))
        return self.output

    def backward(self, grad):
        return [g * o * (1 - o) for g, o in zip(grad, self.output)]


class Tanh(Module):
    def __init__(self):
        super().__init__()
        self.output = None

    def forward(self, x):
        self.output = [math.tanh(v) for v in x]
        return self.output

    def backward(self, grad):
        return [g * (1 - o * o) for g, o in zip(grad, self.output)]
~~~

### 4.4 第 4 步：Dropout 模块

训练时随机置零、存活者放大 1/(1−p)（期望不变，见 0.5 问题 3）；评估时直通。backward 复用同一个掩码——置零的元素梯度也是零。

~~~python
# 本块中文说明：Dropout，训练时随机置零并放大存活值，评估时直通。
class Dropout(Module):
    def __init__(self, p=0.5):
        super().__init__()
        self.p = p
        self.mask = None

    def forward(self, x):
        if not self.training:
            return x
        self.mask = [0.0 if random.random() < self.p else 1.0 / (1 - self.p) for _ in x]
        return [v * m for v, m in zip(x, self.mask)]

    def backward(self, grad):
        if self.mask is None:
            return grad
        return [g * m for g, m in zip(grad, self.mask)]
~~~

### 4.5 第 5 步：BatchNorm 模块

训练时按批统计均值方差并规范化，同时维护运行平均给评估用。核对：`backward` 里只用了 `self.x_norm[0]`——它假设反传的是单样本（x_norm 只有一条记录），与本课逐样本前向/反向的训练循环配套；若做真正的整批反向，此实现需要重写（原课边界，本篇显式标注而不修改）。gamma 初始化为 1、beta 为 0——先恢复原尺度再让训练去调整。

~~~python
# 本块中文说明：批归一化，训练用批统计、评估用运行统计。
class BatchNorm(Module):
    def __init__(self, size, momentum=0.1, eps=1e-5):
        super().__init__()
        self.size = size
        self.gamma = [1.0] * size
        self.beta = [0.0] * size
        self.gamma_grads = [0.0] * size
        self.beta_grads = [0.0] * size
        self.running_mean = [0.0] * size
        self.running_var = [1.0] * size
        self.momentum = momentum
        self.eps = eps
        self.x_norm = None
        self.std_inv = None
        self.batch_input = None

    def forward_batch(self, batch):
        batch_size = len(batch)
        output_batch = []

        if self.training:
            mean = [0.0] * self.size
            for sample in batch:
                for j in range(self.size):
                    mean[j] += sample[j]
            mean = [m / batch_size for m in mean]

            var = [0.0] * self.size
            for sample in batch:
                for j in range(self.size):
                    var[j] += (sample[j] - mean[j]) ** 2
            var = [v / batch_size for v in var]

            self.std_inv = [1.0 / math.sqrt(v + self.eps) for v in var]

            self.x_norm = []
            self.batch_input = batch
            for sample in batch:
                normed = [(sample[j] - mean[j]) * self.std_inv[j] for j in range(self.size)]
                self.x_norm.append(normed)
                output = [self.gamma[j] * normed[j] + self.beta[j] for j in range(self.size)]
                output_batch.append(output)

            for j in range(self.size):
                self.running_mean[j] = (1 - self.momentum) * self.running_mean[j] + self.momentum * mean[j]
                self.running_var[j] = (1 - self.momentum) * self.running_var[j] + self.momentum * var[j]
        else:
            std_inv = [1.0 / math.sqrt(v + self.eps) for v in self.running_var]
            for sample in batch:
                normed = [(sample[j] - self.running_mean[j]) * std_inv[j] for j in range(self.size)]
                output = [self.gamma[j] * normed[j] + self.beta[j] for j in range(self.size)]
                output_batch.append(output)

        return output_batch

    def forward(self, x):
        result = self.forward_batch([x])
        return result[0]

    def backward(self, grad):
        if self.x_norm is None:
            return grad
        for j in range(self.size):
            self.gamma_grads[j] += self.x_norm[0][j] * grad[j]
            self.beta_grads[j] += grad[j]
        return [grad[j] * self.gamma[j] * self.std_inv[j] for j in range(self.size)]

    def parameters(self):
        params = []
        for j in range(self.size):
            params.append((self.gamma, j, None, self.gamma_grads))
            params.append((self.beta, j, None, self.beta_grads))
        return params
~~~

### 4.6 第 6 步：Sequential 容器

组合模式的核心：forward 从左到右、backward 从右到左（`reversed`）；parameters 汇总所有子模块；train/eval 递归广播开关。

~~~python
# 本块中文说明：顺序容器，串模块、双向传递、汇总参数、广播模式开关。
class Sequential(Module):
    def __init__(self, *modules):
        super().__init__()
        self.modules = list(modules)

    def forward(self, x):
        for module in self.modules:
            x = module.forward(x)
        return x

    def backward(self, grad):
        for module in reversed(self.modules):
            grad = module.backward(grad)
        return grad

    def parameters(self):
        params = []
        for module in self.modules:
            params.extend(module.parameters())
        return params

    def train(self):
        self.training = True
        for module in self.modules:
            module.train()

    def eval(self):
        self.training = False
        for module in self.modules:
            module.eval()
~~~

### 4.7 第 7 步：损失函数

MSE 与 BCE 都是“可调用对象”：`__call__` 算损失并缓存预测与目标，`backward` 返回对预测的梯度。BCE 里把 p 夹到 [eps, 1−eps] 防 log(0)。MSE 的 backward=[2(p−t)/n] 正是 0.3 算例里的 [−0.82] 的来源。

~~~python
# 本块中文说明：MSE 与二元交叉熵两个损失模块。
class MSELoss:
    def __call__(self, predicted, target):
        self.predicted = predicted
        self.target = target
        n = len(predicted)
        self.loss = sum((p - t) ** 2 for p, t in zip(predicted, target)) / n
        return self.loss

    def backward(self):
        n = len(self.predicted)
        return [2 * (p - t) / n for p, t in zip(self.predicted, self.target)]


class BCELoss:
    def __call__(self, predicted, target):
        self.predicted = predicted
        self.target = target
        eps = 1e-7
        n = len(predicted)
        self.loss = 0
        for p, t in zip(predicted, target):
            p = max(eps, min(1 - eps, p))
            self.loss += -(t * math.log(p) + (1 - t) * math.log(1 - p))
        self.loss /= n
        return self.loss

    def backward(self):
        eps = 1e-7
        n = len(self.predicted)
        grads = []
        for p, t in zip(self.predicted, self.target):
            p = max(eps, min(1 - eps, p))
            grads.append((-t / p + (1 - t) / (1 - p)) / n)
        return grads
~~~

### 4.8 第 8 步：SGD 与 Adam

两个优化器都吃同一份参数清单、都有 step/zero_grad——它们不知道彼此训练的是什么网络。Adam 的偏差修正是第 06 课的内容：前几步 m、v 从零起步偏小，除以 (1−β^t) 拉回。

~~~python
# 本块中文说明：SGD 与 Adam，只认“参数+梯度”的扁平清单。
class SGD:
    def __init__(self, parameters, lr=0.01):
        self.params = parameters
        self.lr = lr

    def step(self):
        for container, i, j, grad_container in self.params:
            if j is not None:
                container[i][j] -= self.lr * grad_container[i][j]
            else:
                container[i] -= self.lr * grad_container[i]

    def zero_grad(self):
        for container, i, j, grad_container in self.params:
            if j is not None:
                grad_container[i][j] = 0.0
            else:
                grad_container[i] = 0.0


class Adam:
    def __init__(self, parameters, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = parameters
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.t = 0
        self.m = [0.0] * len(parameters)
        self.v = [0.0] * len(parameters)

    def step(self):
        self.t += 1
        for idx, (container, i, j, grad_container) in enumerate(self.params):
            if j is not None:
                g = grad_container[i][j]
            else:
                g = grad_container[i]

            self.m[idx] = self.beta1 * self.m[idx] + (1 - self.beta1) * g
            self.v[idx] = self.beta2 * self.v[idx] + (1 - self.beta2) * g * g

            m_hat = self.m[idx] / (1 - self.beta1 ** self.t)
            v_hat = self.v[idx] / (1 - self.beta2 ** self.t)

            update = self.lr * m_hat / (math.sqrt(v_hat) + self.eps)

            if j is not None:
                container[i][j] -= update
            else:
                container[i] -= update

    def zero_grad(self):
        for container, i, j, grad_container in self.params:
            if j is not None:
                grad_container[i][j] = 0.0
            else:
                grad_container[i] = 0.0
~~~

### 4.9 第 9 步：DataLoader

`__iter__` 每轮先洗牌再按 batch_size 切块，yield 出 (输入批, 目标批)；`__len__` 用向上取整公式算批数（最后一批可能不满）。

~~~python
# 本块中文说明：切批 + 可选洗牌的数据迭代器。
class DataLoader:
    def __init__(self, data, batch_size=32, shuffle=True):
        self.data = data
        self.batch_size = batch_size
        self.shuffle = shuffle

    def __iter__(self):
        indices = list(range(len(self.data)))
        if self.shuffle:
            random.shuffle(indices)
        for start in range(0, len(indices), self.batch_size):
            batch_indices = indices[start:start + self.batch_size]
            batch = [self.data[i] for i in batch_indices]
            inputs = [item[0] for item in batch]
            targets = [item[1] for item in batch]
            yield inputs, targets

    def __len__(self):
        return (len(self.data) + self.batch_size - 1) // self.batch_size
~~~

### 4.10 第 10 步：在圆环分类上训练四层网络

总装。模型 2→16→16→8→1（4 个 Linear，ReLU 夹层，Sigmoid 收尾），BCELoss，Adam(lr=0.01)，数据 500 点八二分，批大小 16，训 100 轮。注意训练循环的顺序：每个样本 forward→zero_grad→backward→step——核对：这是逐样本更新，不是先累积整批梯度再更新一次（PyTorch 的典型用法是后者），练习 5 正是让你改成真批梯度。补充：模型里没用到 Dropout 和 BatchNorm——它们是框架的能力演示。原课页面未展示训练输出，本篇不虚构准确率数值。

~~~python
# 本块中文说明：全部零件通电——圆环数据上训练四层网络。
def make_circle_data(n=500, seed=42):
    random.seed(seed)
    data = []
    for _ in range(n):
        x = random.uniform(-2, 2)
        y = random.uniform(-2, 2)
        label = 1.0 if x * x + y * y < 1.5 else 0.0
        data.append(([x, y], [label]))
    return data


def train():
    random.seed(42)

    model = Sequential(
        Linear(2, 16),
        ReLU(),
        Linear(16, 16),
        ReLU(),
        Linear(16, 8),
        ReLU(),
        Linear(8, 1),
        Sigmoid(),
    )

    criterion = BCELoss()
    optimizer = Adam(model.parameters(), lr=0.01)

    data = make_circle_data(500)
    split = int(len(data) * 0.8)
    train_data = data[:split]
    test_data = data[split:]

    loader = DataLoader(train_data, batch_size=16, shuffle=True)

    model.train()

    for epoch in range(100):
        total_loss = 0
        total_correct = 0
        total_samples = 0

        for batch_inputs, batch_targets in loader:
            batch_loss = 0
            for x, t in zip(batch_inputs, batch_targets):
                pred = model.forward(x)
                loss = criterion(pred, t)
                batch_loss += loss

                optimizer.zero_grad()
                grad = criterion.backward()
                model.backward(grad)
                optimizer.step()

                predicted_class = 1.0 if pred[0] >= 0.5 else 0.0
                if predicted_class == t[0]:
                    total_correct += 1
                total_samples += 1

            total_loss += batch_loss

        avg_loss = total_loss / total_samples
        accuracy = total_correct / total_samples * 100

        if epoch % 10 == 0 or epoch == 99:
            print(f"Epoch {epoch:3d} | Loss: {avg_loss:.6f} | Train Accuracy: {accuracy:.1f}%")

    model.eval()
    correct = 0
    for x, t in test_data:
        pred = model.forward(x)
        predicted_class = 1.0 if pred[0] >= 0.5 else 0.0
        if predicted_class == t[0]:
            correct += 1
    test_accuracy = correct / len(test_data) * 100
    print(f"\nTest Accuracy: {test_accuracy:.1f}% ({correct}/{len(test_data)})")

    return model, test_accuracy
~~~

## 七、失败模式、原文边界与工程注意

1. 忘调 `model.eval()` 就测：Dropout 仍在随机丢、BatchNorm 仍在用批统计，测试结果每次都不同且偏低；嵌套容器要记得把开关递归传下去（本框架 Sequential.eval 已做）。
2. 忘调 `optimizer.zero_grad()`：Linear 的梯度用 `+=` 累加，残渣会污染下一步的更新方向与步长——PyTorch 同理，新手第一大坑。
3. 原文边界一：BatchNorm.backward 只用 `self.x_norm[0]`，即只支持单样本反向，与逐样本训练循环配套；真做批梯度须重写（原课如此，本篇标注不改）。
4. 原文边界二：`train()` 是逐样本更新——batch_size 只影响数据怎么喂，不影响更新粒度，与 PyTorch 惯用法（批内累积再更新）不同；模型也未使用 Dropout/BatchNorm，也未接第 09 课调度（练习 2、5 的改造方向）。
5. 参数清单在优化器构造时建立引用——覆盖权重必须在构造优化器之前（第五节补充入口里专门注释了这个纯 Python 列表引用陷阱；改网络结构后要重建优化器）。
6. （补充）本框架无 autograd：每个 backward 都要人肉推导，漏缓存（如 Linear 的 self.input）就拿到错误梯度——第 03 课手推反向传播的价值正在于此。
