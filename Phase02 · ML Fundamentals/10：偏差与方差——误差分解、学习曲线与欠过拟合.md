## 零、初学者先读：模型出错的三个来源，你只能控制两个

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。前置是[第09课](<09：模型评估——指标、交叉验证与数据泄漏.md>)的训练/测试误差与学习曲线。

### 0.1 先理解这一课在做什么

射箭打靶：每次都往左上偏一大块，是准星歪了——怎么练都偏，这是**偏差**；落点倒是不偏，但散得一塌糊涂，是手不稳——多练几组、把多组平均一下就稳了，这是**方差**；靶纸本身在风里晃，任何人都压不住，这是**不可约噪声**。你能校准准星（换更复杂的模型，降偏差）、能稳住姿势（正则化、集成、加数据，降方差），但风永远在。这一课给你的是“诊断→对症下药”的完整流程：先看训练/测试误差的差距判断病根，再决定加复杂度还是加约束。

### 0.2 本课术语先翻成白话

- 偏差（bias）=换很多批训练数据、平均预测与真值的系统性差距
- 方差（variance）=换一批训练数据，预测跟着晃多大幅度
- 不可约噪声=数据生成过程自带的随机性，任何模型都消不掉
- 误差分解=期望误差 = 偏差² + 方差 + 噪声²
- 欠拟合（underfitting）=高偏差：训练误差测试误差都高、差距小
- 过拟合（overfitting）=高方差：训练误差低、测试误差高、差距大
- 正则化（regularization）=故意加约束（升偏差）换低方差
- L1/L2=绝对值惩罚（权重可归零）/平方惩罚（只缩小）
- 早停（early stopping）=训练在变差之前刹车
- bagging=多个 bootstrap 模型取平均，主要降方差
- boosting=顺序建模逐步修正残差，主要降偏差
- 插值阈值=参数量恰好能完美拟合训练集的临界点
- 双下降（double descent）=过参数化后测试误差再次下降的现象

### 0.3 用小数字走一遍

真函数 f(x)=x²，只看 x=2 这一点（真值 4），噪声方差 σ²=0.25。三个候选模型在不同训练集上的预测：

- 模型 A（恰当）：[3.5, 4.5, 4.0]，均值 4 → 偏差² = 0；方差 = ((3.5−4)²+(4.5−4)²+(4.0−4)²)/3 = 1/6 ≈ 0.17
- 模型 B（太死板）：[5, 5, 5]，均值 5 → 偏差² = 1；方差 = 0
- 模型 C（太飘）：[3, 5, 6]，均值 14/3 ≈ 4.67 → 偏差² ≈ 0.44；方差 ≈ 1.56

对着带噪声标签评估时，期望误差 ≈ 偏差² + 方差 + σ²：A ≈ 0.17+0.25 = 0.42，B ≈ 1.25，C ≈ 2.25。A 两项都不大所以最好；B 输在死板，C 输在飘。这就是分解的全部内容——把“模型差”拆成“系统性偏”和“不稳定”两种病，分别用药。

以上是用于理解的算例，不是新增的训练或性能实测。

## 一、这一课解决什么问题？

模型在测试数据上有误差，误差从哪来？太简单的模型（对弯曲数据拟合直线）会一直错过真实规律——这是偏差；太复杂的模型（15 个点上拟合 20 次多项式）能完美穿过每个训练点，但换个数据集预测就剧烈摆动——这是方差。对固定的模型容量，两者不能同时压到最低：压偏差则方差升，压方差则偏差升。原课的判断（方向正确）：理解这个权衡是机器学习里最有用的诊断技能——它直接告诉你该把模型变复杂还是变简单、该去搞数据还是搞特征、正则该加重还是减轻。

## 二、核心概念与推导

### 2.1 偏差：系统性看错

偏差衡量模型的平均预测离真值多远：在同一分布上抽出很多不同训练集、分别训练、把预测平均起来，平均值与真值的差距就是偏差。高偏差意味着模型太死板抓不住真实规律——直线拟合抛物线，给再多数据也总是差一截。这就是欠拟合：训练误差高、测试误差高、两者差距小。

### 2.2 方差：对训练数据过敏

方差衡量换一批训练数据时预测变多少。训练集小扰动、模型大变，就是高方差——模型拟合的是训练数据里的噪声而不是规律。20 次多项式穿过每个训练点、点与点之间剧烈震荡，就是过拟合：训练误差低、测试误差高、差距大。

### 2.3 误差分解

对任意点 $x$，平方损失下的期望预测误差**精确**分解为：

$$\text{Expected Error}=\text{Bias}^2+\text{Variance}+\text{Irreducible Noise}$$

$$\text{Bias}^2=\bigl(\mathbb{E}[\hat{f}(x)]-f(x)\bigr)^2,\qquad \text{Variance}=\mathbb{E}\bigl[(\hat{f}(x)-\mathbb{E}[\hat{f}(x)])^2\bigr],\qquad \text{Noise}=\mathbb{E}\bigl[(y-f(x))^2\bigr]=\sigma^2$$

其中 $f$ 是真函数、$\hat f$ 是模型预测、期望取遍不同训练集、$y$ 是带噪声的观测标签。噪声项不可约：没有模型能在噪声数据上低于 $\sigma^2$。你能做的只是找 $\text{Bias}^2$ 与方差的合适平衡。（补充：该分解对平方损失精确成立，对 0-1 损失等只有近似版本——这是公认定理的边界。）

### 2.4 复杂度与 U 形曲线

| 复杂度 | 偏差 | 方差 | 总误差 |
|---|---|---|---|
| 太低 | 高 | 低 | 高（欠拟合）|
| 恰好 | 中 | 中 | 最低 |
| 太高 | 低 | 高 | 高（过拟合）|

复杂度从低到高，总误差先降后升，呈 U 形；经典理论认为甜点之后再加复杂度只会更糟。

### 2.5 正则化：用偏差换方差的旋钮

正则化故意升高偏差来压方差——约束模型，让它没法追着噪声跑：

- **L2（Ridge）**：所有权重向零收缩，特征都保留但影响变小。
- **L1（Lasso）**：把部分权重压到恰好零，顺带做特征选择。
- **Dropout**：训练时随机失活神经元，逼迫冗余表示。
- **早停**：在模型完全拟合训练数据之前停止。

正则强度（lambda、dropout 率、轮数）直接决定你在偏差-方差曲线上的位置：正则越强，偏差越大、方差越小。

### 2.6 双下降：现代视角

2019 年以来的研究发现：越过**插值阈值**（参数量恰好能完美拟合训练数据）之后继续加容量，测试误差可能再次下降——“双下降”。它出现在线性模型、决策树、神经网络中；加数据、加训练轮数也可能触发；正则会抹平滑峰但不消除。直觉：阈值处模型被迫选择“穿过每个点”的极特定解，数据微扰导致解剧变，方差峰值就在这里；越过阈值后满足训练数据的解有很多，学习算法（如带隐式正则的梯度下降）倾向于挑其中较简单的那个，这种对简单解的隐式偏好就是过参数化模型泛化的原因之一。

| 区间 | 参数 vs 样本 | 行为 |
|---|---|---|
| 欠参数化 | p ≪ n | 经典权衡成立 |
| 插值阈值 | p ≈ n | 方差峰值、测试误差尖峰 |
| 过参数化 | p ≫ n | 隐式正则生效、测试误差回落 |

原课的实践建议（经验法则，非定律）：用神经网络或大树集成时，要么明显停在阈值之前（配显式正则），要么明显越过去——最差的位置是恰好卡在阈值上。经典偏差-方差权衡不是错的，只是在现代区间不完整。

### 2.7 诊断：症状与处方

| 症状 | 诊断 | 处方 |
|---|---|---|
| 训练误差高、测试误差高 | 偏差 | 加特征、换复杂模型、减弱正则 |
| 训练误差低、测试误差高 | 方差 | 加数据、正则化、简化模型、dropout |
| 两者都低 | 拟合良好 | 上线 |
| 训练误差还在降、测试误差开始升 | 过拟合进行中 | 早停 |

流程：比较训练与测试误差 → 差距大吗？大则高方差；不大则两者都高吗？高则高偏差；都不是则拟合良好。

### 2.8 集成方法与方差降低

**bagging（bootstrap aggregating）**：在不同 bootstrap 样本上训练多个模型再平均。数学直觉：平均 $N$ 个**独立**、各自方差 $\sigma^2$ 的预测，方差降为 $\sigma^2/N$；实际模型相关（数据相似），降幅小于 1/N 但仍然可观——随机森林就是 bagging 加决策树（回看[第04课](<04：决策树与随机森林.md>)）。

**boosting**：顺序建模型，每个新模型专注前面集成的错误，主要降偏差；加太多模型会过拟合，需要早停或正则。

| 方法 | 主要效果 | 偏差 | 方差 |
|---|---|---|---|
| bagging | 降方差 | 不变 | 下降 |
| boosting | 降偏差 | 下降 | 可能上升 |
| stacking | 两者都作用 | 取决于元学习器 | 取决于基模型 |
| dropout | 隐式 bagging | 略升 | 下降 |

实践口诀（原课）：基模型高方差（深树、高次多项式）用 bagging；基模型高偏差（浅桩、简单线性）用 boosting。

### 2.9 学习曲线：读法与两种画法

| 情形 | 训练误差 | 验证误差 | 间隙 | 含义 | 行动 |
|---|---|---|---|---|---|
| 高偏差 | 高 | 高 | 小 | 抓不住规律 | 加特征/复杂模型/弱正则 |
| 高方差 | 低 | 高 | 大 | 背了训练集 | 加数据/正则/简化 |
| 良好 | 中 | 中 | 小 | 泛化好 | 上线 |
| 高方差但在改善 | 低 | 随数据下降 | 收缩中 | 数据能治 | 收集更多数据 |
| 高偏差且平 | 高 | 高且平 | 小且平 | 数据救不了 | 换模型 |

关键读法：两线都平、间隙小、误差都高 → 加数据无用；间隙大且还在收缩 → 加数据有用。两种画法：**固定模型、扫训练集大小**（标准学习曲线，回答“加数据有没有用”）；**固定数据、扫复杂度参数**（验证曲线，回答“换模型有没有用”）。两者互补，做决定前都跑一遍。

### 2.10 用一个小例子把概念串起来（补充）

回到 0.3 的三个模型：模型 B 的诊断路径是“训练/测试误差都高、差距小 → 高偏差”，处方是“加 x² 特征”；模型 C 是“训练误差低、测试误差高 → 高方差”，处方是“岭正则或 bagging 多个 C 取平均”（平均后 [3,5,6] 类的波动互相抵消，方差从 1.56 往 1.56/N 方向压）。对模型 C 做正则扫描：λ 从 0.001 加到 100，方差单调降、偏差² 单调升，总误差在中段某处取最小——这就是 4.5 的实验要展示的“连续旋钮版 U 形曲线”。

### 4.1 从已知真函数生成合成数据

用 $f(x)=\sin(1.5x)+0.5x$ 加高斯噪声。知道真函数，才能逐点算出精确的偏差与方差——真实数据没有这个奢侈。

~~~python
# 本块中文说明：已知真函数的合成数据生成。
def true_function(x):
    return np.sin(1.5 * x) + 0.5 * x

def generate_data(n_samples=30, noise_std=0.5, x_range=(-3, 3), seed=None):
    rng = np.random.RandomState(seed)
    x = rng.uniform(x_range[0], x_range[1], n_samples)
    y = true_function(x) + rng.normal(0, noise_std, n_samples)
    return x, y
~~~

### 4.2 bootstrap 采样与多项式拟合

对每个多项式次数，抽很多个 bootstrap 训练集、拟合、在固定测试网格上记录预测——每个测试点得到一个预测分布。`fit_polynomial` 带可选岭正则（截距不惩罚）。

~~~python
# 本块中文说明：多项式最小二乘拟合，lam>0 时为岭正则版本。
def fit_polynomial(x_train, y_train, degree, lam=0.0):
    X = np.column_stack([x_train ** d for d in range(degree + 1)])
    if lam > 0:
        penalty = lam * np.eye(X.shape[1])
        penalty[0, 0] = 0            # 截距不惩罚
        w = np.linalg.solve(X.T @ X + penalty, X.T @ y_train)
    else:
        w = np.linalg.lstsq(X, y_train, rcond=None)[0]
    return w
~~~

原课说明：在 200 个不同 bootstrap 样本上拟合，每个样本来自同一分布但包含不同点。

### 4.3 计算 Bias² 与方差分解

原文说明：有了每个测试点上的 200 组预测，可以直接按定义算分解。**这是模块级片段**（直接作用在名为 `predictions`、`y_true` 的数组上，依赖未给出的外层循环构造）：

~~~python
# 本块中文说明：原文的分解核心三行（模块级片段，predictions 为预测矩阵）。
mean_pred = predictions.mean(axis=0)
bias_sq = np.mean((mean_pred - y_true) ** 2)
variance = np.mean(predictions.var(axis=0))
total_error = np.mean(np.mean((predictions - y_true) ** 2, axis=1))
~~~

逐行读：`mean_pred` 是用 bootstrap 样本估计的 $\mathbb{E}[\hat f(x)]$；`bias_sq` 是平均预测与真值差距的平方平均；`variance` 是预测跨 bootstrap 样本的平均散布；`total_error` 原文说应约等于 bias²+variance+noise。**核对（补充）**：若测试目标 `y_true` 用的是无噪声真函数值，则 total 恰好等于 bias²+variance（逐点方差分解恒等式）；噪声项只在对带噪声标签评估时显式出现，训练数据被噪声污染的影响已经体现在 variance 里。原文的“约等于三项之和”在这点上表述偏松。

### 4.5 正则化扫描（片段）

固定 15 次多项式，把岭正则强度从 0.001 扫到 100。**原文缺 `bias_variance_decomposition` 的定义**（第五节补齐）：

~~~python
# 本块中文说明：原文 Step 5 片段，缺 bias_variance_decomposition 定义。
def demo_regularization_sweep():
    alphas = [0.001, 0.005, 0.01, 0.05, 0.1, 0.5, 1.0, 5.0, 10.0, 50.0, 100.0]
    for alpha in alphas:
        results = bias_variance_decomposition([15], lam=alpha)
        r = results[15]
        print(f"alpha={alpha:.3f}  bias={r['bias_sq']:.4f}  var={r['variance']:.4f}")
~~~

原课描述预期现象：低 alpha 时 15 次多项式几乎不受约束，每个 bootstrap 样本各自追噪声，方差主导；高 alpha 时惩罚强到模型近乎常数，偏差主导；最优 alpha 在两者之间。这与扫多项式次数得到的是同一个 U 形，只是把离散旋钮换成了连续旋钮；实践中正则是首选的控制方式——不必改特征集就能细粒度调节。

~~~python
# 本块中文说明：补齐原文缺失的函数与最小分解实验入口（均未运行）。
import numpy as np

def predict_polynomial(x, w):
    # 原文缺该函数：按权重 w（含截距）算多项式预测。
    X = np.column_stack([np.asarray(x) ** d for d in range(len(w))])
    return X @ w

def bias_variance_decomposition(degrees, n_train=30, noise_std=0.5,
                                n_bootstrap=200, lam=0.0, seed=0):
    # 原文缺该函数：对每个次数抽 n_bootstrap 个训练集，逐测试点汇总分解。
    rng = np.random.RandomState(seed)
    x_test = np.linspace(-3, 3, 100)
    y_true = true_function(x_test)          # 测试点用无噪声真值
    results = {}
    for degree in degrees:
        preds = []
        for _ in range(n_bootstrap):
            x_tr, y_tr = generate_data(n_train, noise_std,
                                      seed=rng.randint(0, 10**6))
            w = fit_polynomial(x_tr, y_tr, degree, lam=lam)
            preds.append(predict_polynomial(x_test, w))
        preds = np.array(preds)
        mean_pred = preds.mean(axis=0)
        bias_sq = np.mean((mean_pred - y_true) ** 2)
        variance = np.mean(preds.var(axis=0))
        total = np.mean(np.mean((preds - y_true) ** 2, axis=1))
        results[degree] = {"bias_sq": bias_sq, "variance": variance,
                           "total": total, "noise_sq": noise_std ** 2}
    return results

if __name__ == "__main__":
    # 可手算预期：测试目标无噪声时，total 应精确等于 bias_sq+variance
    # （逐点方差分解恒等式），此处用小容差吸收浮点误差。
    results = bias_variance_decomposition([1, 3, 5], n_bootstrap=50)
    for degree in sorted(results):
        r = results[degree]
        print(f"degree={degree}  bias2={r['bias_sq']:.4f}  "
              f"var={r['variance']:.4f}  total={r['total']:.4f}")
        assert abs(r["bias_sq"] + r["variance"] - r["total"]) < 1e-6 * max(1.0, r["total"])
~~~

（补充）`demo_learning_curves` 的补全版：在 4.4 片段里补上 `x_test = np.linspace(-3, 3, 100)`、`y_test = true_function(x_test)` 与循环末尾的取平均打印即可，函数体其余照抄原文。预期方向（可手算预期、非实测）：degree=1 时两线快速收敛到同一高值；degree=5 时训练误差低、测试误差高、随 n 增大差距收缩。

## 七、失败模式、原文边界与工程注意

1. 分解公式对平方损失精确成立；对 0-1 损失（分类错误率）只有近似版本，别把三项拆解当万能读数。
2. bootstrap 分解是蒙特卡洛估计：200 个样本是“够用”的经验值，不是保证；换种子结果会小幅波动。
3. 高阶多项式在未缩放的 x∈[−3,3] 上条件数极差（x^15 量级 10^7）；实际做分解实验应先对 x 标准化，或像 4.5 那样配合正则（工程注意，原文未提）。
4. 4.4/4.5 依赖未定义函数，直接照抄跑不起来；第五节补齐后才是完整实验（原文缺函数，已声明）。
5. 双下降是经验现象不是定律：不是所有模型、所有数据都出现；正则会抹平滑峰。原文“最差的位置是插值阈值”是实用启发式。
6. 诊断表（症状→处方）是启发式：真实项目里“高偏差/高方差”常常并存，按主导项分步处理。
7. bagging 的 σ²/N 假设独立；bootstrap 样本高度相关，实际降幅小于 1/N（原课自己说了 less than 1/N）。
8. 表格中 boosting“方差可能上升”、dropout“偏差略升”是倾向性描述，不是保证。
9. 原文“~75 分钟”“10-15 分钟算力”是课程层面的估计，不是本机实测。

## 十、术语与完成标准

偏差：平均预测与真值的系统性差距；方差：预测对训练数据更换的敏感度；不可约误差：数据生成噪声，无法消除；欠拟合/过拟合：高偏差/高方差；正则化：加约束换低方差；L1/L2：绝对值/平方惩罚；早停：变差前停止训练；bagging：bootstrap 模型平均，降方差；boosting：顺序纠错，降偏差；插值阈值：恰好能完美拟合训练集的容量；双下降：过参数化后测试误差再次下降。

完成检查：

- 能手算 0.3 三个模型的偏差²、方差与期望误差。
- 能写出三项分解公式并说出每项对“训练集抽取”的期望含义。
- 能从一张误差对比表判断偏差/方差主导并开出处方。
- 能区分学习曲线与验证曲线各自回答什么问题。
- 能解释 bagging 降方差的数学直觉及其独立性假设。
