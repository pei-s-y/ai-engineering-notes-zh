## 零、初学者先读：在两类点之间修一条最宽的马路

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。需要先有[第02课](<02：线性回归——最小二乘、梯度下降与正规方程.md>)的损失—梯度框架和[第03课](<03：逻辑回归——sigmoid、交叉熵与决策边界.md>)的分类视角。

### 0.1 先理解这一课在做什么

两类点之间能画的分界线有无穷多条：贴着正类画的、贴着负类画的、歪七扭八的。支持向量机（SVM）的立场是：选中间那条，让分界线到两边最近点的“马路”最宽。直觉是马路越宽，新来的点越不容易站错边。修这条马路只靠少数几个贴边的点（支持向量），其他点挪走马路都不动——这是 SVM 最出名也最好玩的特点。

### 0.2 本课术语先翻成白话

- 超平面（hyperplane）=高维空间里的“直线”，写成 wx+b=0
- 间隔（margin）=分界线到最近训练点的距离，SVM 要它最大
- 支持向量（support vectors）=恰好贴在马路牙子上的那些点，只有它们决定分界线
- 铰链损失（hinge loss）=max(0, 1−y·f(x))：分对且距离够远罚 0，否则线性罚
- 软间隔（soft margin）=允许少数点越线或进马路，换来更宽的路
- 松弛变量 ξ=第 i 个点越界了多少
- C 参数=罚越界的力度：大 C 马路窄、错误少（易过拟合）；小 C 马路宽、错误多
- 核技巧（kernel trick）=不真的去高维，直接用函数算“高维点积”
- RBF 核=最常用的核，相当于映射到无穷维，能学光滑曲线边界
- 对偶形式（dual）=改写成只含点与点内积的优化问题，核技巧的入口
- SVR=回归版的 SVM：拟合一条 ε 管道，管内的点不算错
- λ（lambda_param）=代码里的正则强度，与 C 大致是倒数关系（补充，见 2.5）

### 0.3 用小数字走一遍

一维数据，正类点 x=1、x=2（y=+1），负类点 x=−1（y=−1）。假设 w=1、b=0。

铰链损失逐点算：x=1 → y·(wx+b)=1，损失 max(0,1−1)=0；x=2 → 2>1，损失 0；x=−1 → (−1)×(−1)=1，损失 0。三个点都“分对且在马路外”，x=1 和 x=−1 恰好贴边（y·f(x)=1），它们就是支持向量；x=2 挪到哪里都不影响这条分界线。

再看一个越界点：x=0.5、y=+1 → y·f(x)=0.5<1，损失 0.5。梯度里多出 −y·x=−0.5 这一项（对 w），更新会把 w 往“把这个点拉回马路边”的方向推。这就是软间隔要处理的情况。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么删掉一半训练数据，SVM 的分界线可能一点不变？

**参考答案：** 分界线只由支持向量决定；被删的不是支持向量的点本来就不影响它。只有贴边的少数点才“投票”。

**问题2：** C 调大，模型会怎样？

**参考答案：** 越界罚得狠，模型宁肯把马路修窄也要少犯错——训练错误变少但更容易过拟合。C 小则相反：容忍错误、马路宽、更平滑。

**问题3：** 核技巧到底“省”了什么？

**参考答案：** 省了显式映射。多项式核把点映射到约 D^d 维的空间，在那里找线性边界；核函数只用原始 D 维输入一步算出高维内积，不必真的构造那个高维向量。

## 一、这一课解决什么问题？

两类点要画一条分界线（超平面），能用的线有无穷多条，选哪条？SVM 选间隔最大的那条：边界到两类最近点的距离最大。直觉是更宽的间隔意味着更自信、泛化更好。SVM 是深度学习兴起前的主流分类方法，今天在小数据集、高维稀疏数据（如文本 TF-IDF）、需要理论保证的场景仍是好选择。它与 Phase 1 直接相连：优化是凸的、间隔用范数度量、核技巧利用内积。本课实现线性 SVM（铰链损失 + 梯度下降），并理解核技巧如何让它画出非线性边界。

## 二、核心概念与推导

### 2.1 最大间隔分类器

标签取 $y_i\in\{-1,+1\}$，求超平面 $w^\top x+b=0$。点到超平面的距离：

$$\text{distance} = \frac{|w^\top x_i + b|}{\|w\|}$$

正确分类即 $y_i(w^\top x_i+b)>0$；间隔是边界到两侧最近点距离的两倍。通过把尺度固定为 $y_i(w^\top x_i+b)\ge 1$（支撑超平面取 ±1），最大化间隔 $2/\|w\|$ 等价于：

$$\min \frac{1}{2}\|w\|^2 \quad \text{s.t.}\quad y_i(w^\top x_i+b)\ge 1$$

这是凸二次规划，唯一全局最优。恰好满足 $y_i(w^\top x_i+b)=1$ 的点是支持向量，它们（也只有它们）决定边界；挪动或删除非支持向量，边界不变。

### 2.2 软间隔：用 C 换取容错

真实数据常不可完美分开。引入松弛变量 $\xi_i\ge 0$ 允许越界：

$$\min \frac{1}{2}\|w\|^2 + C\sum_i \xi_i \quad \text{s.t.}\quad y_i(w^\top x_i+b)\ge 1-\xi_i$$

大 C：重罚越界，马路窄、错分少，易过拟合；小 C：容忍越界，马路宽，易欠拟合。C 是“反向的正则强度”：大 C = 弱正则。

### 2.3 铰链损失

软间隔可改写成无约束形式：

$$\min \frac{1}{2}\|w\|^2 + C\sum_i \max(0, 1-y_i(w^\top x_i+b))$$

$\max(0,1-y_if(x))$ 就是铰链损失：分对且在马路面外为 0，进马路或分错则线性增长。对比第03课的逻辑损失 $\log(1+e^{-yf(x)})$：铰链在 y·f(x)≥1 后“干脆利落归零”（解稀疏，只有支持向量有贡献），逻辑损失永远不为零（所有点都出力）。

~~~text
铰链损失示意（原文图）：

loss
  |\
  | \
  |  \_______________
  +-----|-----|---->  y*f(x)
       0     1
y*f(x) >= 1 时损失为 0；< 1 时线性上升。
~~~

### 2.4 梯度下降训练（原始形式）

对 $L=\frac{\lambda}{2}\|w\|^2+\frac{1}{n}\sum_i\max(0,1-y_i(w^\top x_i+b))$，单个样本的梯度分两种情况：

- 若 $y_i(w^\top x_i+b)\ge 1$：$\partial L/\partial w=\lambda w$，$\partial L/\partial b=0$
- 若 $y_i(w^\top x_i+b)<1$：$\partial L/\partial w=\lambda w-y_ix_i$，$\partial L/\partial b=-y_i$

这叫原始形式（primal），每轮 O(n·d)。对大型稀疏高维数据（文本分类）很快。

### 2.5 代码里的 λ 与概念里的 C

核对（补充）：原课概念部分用 $C\sum\xi_i$，代码部分用 $\frac{\lambda}{2}\|w\|^2+\frac{1}{n}\sum\text{hinge}$。两者是同一权衡的两种写法：等价于把目标除以 C 后 λ≈1/C。概念里“大 C 罚得重”对应代码里“小 lambda_param 罚得轻”——读代码时记住方向相反即可。

### 2.6 对偶形式与核技巧

拉格朗日对偶问题只含样本间内积：

$$\max \sum_i\alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j (x_i\cdot x_j)\quad \text{s.t.}\quad 0\le\alpha_i\le C,\ \sum_i\alpha_i y_i=0$$

把每个内积 $x_i\cdot x_j$ 换成核函数 $K(x_i,x_j)$，就能在“某个高维特征空间”里学线性边界，而不必显式计算映射：

$$K_{\text{linear}}(x,z)=x\cdot z,\quad K_{\text{poly}}(x,z)=(x\cdot z+c)^d,\quad K_{\text{rbf}}(x,z)=\exp(-\gamma\|x-z\|^2)$$

RBF 相当于映射到无穷维空间：输入空间近的点核值接近 1、远的接近 0。多项式核次数 d、维度 D 时显式特征空间约 $O(D^d)$ 维，但 $K(x,z)$ 只用 $O(D)$ 时间算出——这就是“技巧”省下的东西。

### 2.7 SVR：回归版 SVM

支持向量回归在数据周围套一条宽 ε 的管道：管内点损失为 0，管外线性罚。ε 大 → 支持向量少、拟合平滑；ε 小 → 支持向量多、贴得紧。

### 2.8 SVM 与深度学习的消长

原文给出对比（思路参考）：核 SVM 训练复杂度 $O(n^2)$～$O(n^3)$，深度学习每轮 SGD 近似线性；图像/文本/音频上 SVM 需要手工特征而深度学习从原始数据学特征；大数据上 SVM 慢。SVM 仍占优的场景：小数据集（几百到几千样本）、高维稀疏数据（TF-IDF 文本）、需要数学保证、要求训练时间极短、有清晰间隔结构的二分类、异常检测（单类 SVM）。这些是倾向性总结，不是硬边界。

### 2.9 用一个小例子把概念串起来（补充）

一维数据：正类 x=1、2，负类 x=−1，取 w=1、b=0。三个点的 $y\cdot f(x)$ 分别是 1、2、1：铰链损失全 0；x=1 与 x=−1 恰在马路边（=1），是支持向量；x=2 在外，挪走不影响边界（2.1 的论断在数字上落地）。现在把 x=2 改成 x=0.5：它的 $y\cdot f(x)=0.5<1$，铰链损失 0.5，按 2.4 的第二种情况更新 w ← w − lr(λw − y·x)=w − lr(λ−0.5)，b ← b+lr·y——边界被这个越界点拉动，这正是“软间隔用 C 换容错”的微观机制。核的视角再补一句：若这批点在原空间线性不可分（如正负类套同心圆），RBF 核相当于按到各点的距离重新表示每个点，在新表示里往往线性可分。

## 四、Build It：原课分步代码与中文讲解

原课 Build It 共 4 个分段；第 4 步同时提示完整实现见仓库 `code/svm.py`。以下代码逐字转录（原文缺 `dot`，见第五节）。

### 4.1 第 1 步：铰链损失

对每个样本算 y·(wx+b)，取 max(0, 1−margin) 后平均。这就是 2.3 节公式的直译。

~~~python
# 本块中文说明：计算一批样本的平均铰链损失。
def hinge_loss(X, y, w, b):
    n = len(X)
    total_loss = 0.0
    for i in range(n):
        margin = y[i] * (dot(w, X[i]) + b)
        total_loss += max(0.0, 1.0 - margin)
    return total_loss / n
~~~

### 4.2 第 2 步：梯度下降训练线性 SVM

核对（补充）：`fit` 里是对每个样本逐个更新（随机梯度风格），不是概念里“全批平均”的梯度；每轮 n 个样本各更新一次。样本满足 margin≥1 时只做权重衰减（λw 方向），b 不动；否则按 2.4 节第二种情况更新。预测按符号输出 ±1。

~~~python
# 本块中文说明：逐样本次梯度下降训练的线性 SVM。
class LinearSVM:
    def __init__(self, lr=0.001, lambda_param=0.01, n_epochs=1000):
        self.lr = lr
        self.lambda_param = lambda_param
        self.n_epochs = n_epochs
        self.w = None
        self.b = 0.0

    def fit(self, X, y):
        n_features = len(X[0])
        self.w = [0.0] * n_features
        self.b = 0.0

        for epoch in range(self.n_epochs):
            for i in range(len(X)):
                margin = y[i] * (dot(self.w, X[i]) + self.b)
                if margin >= 1:
                    self.w = [wj - self.lr * self.lambda_param * wj
                              for wj in self.w]
                else:
                    self.w = [wj - self.lr * (self.lambda_param * wj - y[i] * X[i][j])
                              for j, wj in enumerate(self.w)]
                    self.b -= self.lr * (-y[i])

    def predict(self, X):
        return [1 if dot(self.w, x) + self.b >= 0 else -1 for x in X]
~~~

### 4.3 第 3 步：核函数

三个核各是几行。RBF 核里的 gamma 控制“多近算近”：gamma 大 → 只有非常近的点核值高，边界更碎；gamma 小 → 影响范围大，边界更平缓（补充）。

~~~python
# 本块中文说明：线性、多项式、RBF 三种核函数。
def linear_kernel(x, z):
    return dot(x, z)

def polynomial_kernel(x, z, degree=3, c=1.0):
    return (dot(x, z) + c) ** degree

def rbf_kernel(x, z, gamma=0.5):
    diff = [xi - zi for xi, zi in zip(x, z)]
    return math.exp(-gamma * dot(diff, diff))
~~~

### 4.4 第 4 步：找支持向量与算间隔

训练后找“恰好贴边”的点：$y_i(w^\top x_i+b)$ 接近 1 的样本（tol 容差内）。原文提示完整实现（含演示）见仓库 `code/svm.py`，本课页面未展示该文件内容。

~~~python
# 本块中文说明：找出贴在间隔边界上的支持向量样本下标。
def find_support_vectors(X, y, w, b, tol=1e-3):
    support_vectors = []
    for i in range(len(X)):
        margin = y[i] * (dot(w, X[i]) + b)
        if abs(margin - 1.0) < tol:
            support_vectors.append(i)
    return support_vectors
~~~

## 七、失败模式、原文边界与工程注意

1. 忘记标准化是 SVM 第一大坑：间隔按 $\|w\|$ 计算，一个量纲大的特征会独占几何，其他特征形同虚设（原文已强调，此处重申）。
2. C 与 gamma 同时调才有意义：大 C 配大 gamma 很快过拟合；单独看其中一个参数的曲线会误判（补充）。
3. 核 SVM 在大数据上代价高：训练 $O(n^2)$～$O(n^3)$，十万级样本应改用线性 SVM或近似方法；原文“SVM 仍是小数据最佳选择”应理解为“常是好选择”，不是保证。
4. 教学实现不等于求解器：4.2 的逐样本次梯度下降是简化版，真实实现（SMO 等）解的是对偶问题；数值与收敛行为不要直接对标 sklearn。
5. 支持向量“越少泛化越好”是理论界的倾向性结论，不是逐条兑现的保证（原文给出的界是概率上界，补充降级表述）。
6. 标签约定易错：SVM 用 ±1，不是 0/1；把第03课的 0/1 标签直接喂进来，损失符号全错（补充）。
7. `find_support_vectors` 用容差 1e-3 找“恰好等于 1”的点：梯度下降训出的模型很少精确落在这个值上，实际使用要么放宽 tol、要么取 margin 最小的前若干个（补充）。
8. 原文“SVM 在文本 TF-IDF 上仍是强基线”是普遍有效的经验倾向；具体任务仍应以对照实验定夺。

## 九、Exercises：保留原课练习与验收方法

1. 原课 Easy：生成二维线性可分数据，训练 LinearSVM 并找出支持向量。验收标准：支持向量恰为离决策边界最近的点，可用逐点距离计算核对。
2. 原课 Medium：在有噪声数据上把 C 从 0.001 扫到 1000，画每个 C 的决策边界。验收标准：能展示从宽间隔（欠拟合）到窄间隔（过拟合）的连续过渡，并指出中间较优的区域。
3. 原课 Medium-Hard：造环形边界的类别数据，展示线性 SVM 失败；计算 RBF 核矩阵并说明类在核诱导特征空间中变得可分。验收标准：线性版准确率显著差于核矩阵上训练的版本；能解释“可分”是在核空间中验证的。
4. 原课 Hard：同一数据上比较铰链损失与逻辑损失，数一数两种模型分别有多少训练点对边界有贡献（支持向量 vs 全部点）。验收标准：能展示 SVM 的贡献点少而逻辑回归人人出力，与 2.3 节的理论对比一致。
5. 原课 Hard：实现 SVR（ε 不敏感损失），拟合 y=sin(x)+噪声，画出 ε 管道并高亮管外支持向量。验收标准：管道宽度与支持向量数量随 ε 的变化方向符合 2.7 节（ε 大 → 支持向量少）。

## 十、术语与完成标准

支持向量（support vectors）：贴在间隔边界上的点，唯一决定超平面的样本；间隔（margin）：边界到最近点的距离；铰链损失：max(0, 1−yf(x))；C：间隔宽度与错分的权衡，大 C 窄间隔；软间隔：用松弛变量容忍越界；核技巧：不显式映射、直接算高维内积；RBF 核：exp(−γ‖x−z‖²)，对应无穷维特征空间；多项式核：(x·z+c)^d；对偶形式：只含样本内积的等价优化；SVR：ε 管道回归；松弛变量：点越界的量。

完成检查：

- 能手算三点的铰链损失与谁是支持向量（0.3 节算例）。
- 能写出两种情形的梯度并解释符号方向。
- 能说明 λ 与 C 的反向关系。
- 能解释核技巧省掉了什么计算，RBF 为何等价无穷维。
- 能指出 SVM 必须标准化的原因。
- 能说出至少三个“SVM 仍占优”的场景和两个“别用核 SVM”的场景。
