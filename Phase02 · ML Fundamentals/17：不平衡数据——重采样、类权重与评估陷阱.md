## 零、初学者先读：当"全选C"就能得99分的时候，分数还有什么意义

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。

### 0.1 先理解这一课在做什么

一场考试99%的答案都是"否"：全盘押"否"就能拿99分，但这场考试的目的恰恰是抓住那1%的"是"。欺诈检测、疾病诊断、缺陷检出全是这种题——**少数类越重要，它往往越稀少**。本课做三件事：换掉会骗人的指标（准确率→F1/AUPRC/MCC）、改数据（复制/合成少数类）、改损失（分错少数类罚更重）、改判卷标准（调阈值）。

### 0.2 本课术语先翻成白话

- 类不平衡（class imbalance）=两类样本数量悬殊（如990比10）
- 多数类/少数类=人多的那类/人少但通常更重要的那类
- 混淆矩阵=TP/FP/FN/TN 四格账本
- 精确率（precision）=报出来的"正"里多少是真——低误报
- 召回率（recall）=真"正"里抓到多少——低漏报
- F1=精确率和召回率的调和平均，偏科会被狠罚
- F-beta=可调"更看重召回还是精确率"的F1，F2重召回
- AUPRC=精确率-召回率曲线下面积；随机基线=正类占比（不是0.5）
- MCC=预测与真实标签的相关系数，两类都做好才给高分
- 过采样（oversampling）=复制少数类补数量
- 欠采样（undersampling）=删多数类降数量
- SMOTE=在少数类两点连线段上插值造新样本
- 类权重（class weights）=少数类的错误在损失里乘大系数
- 阈值调优（threshold tuning）=把0.5的判卷线挪到最优点

### 0.3 用小数字走一遍

1000个样本、990负10正。全预测"负"：TP=0、FP=0、FN=10、TN=990——准确率99%，但精确率无定义（记0）、召回率0/10=0、F1=0、MCC=0。指标集体拆穿"99分好模型"。

类权重：950负+50正时，正类权重 $1000/(2\times50)=10$，负类 $1000/(2\times950)\approx0.526$——分错一个正样本相当于分错19个负样本。

SMOTE：少数类点 x1=(1.0, 2.0)，邻居 x2=(1.5, 2.5)，抽 t=0.4：新点 = x1+0.4×(x2−x1) = **(1.2, 2.2)**——落在两点连线段上，不是任何复制。

阈值：模型给某笔欺诈交易打 P(欺诈)=0.15。阈值0.5→漏掉；阈值0.10→抓住。只要欺诈的分数总体比正常高，就存在一条切得开的线——排名比标定更重要。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么SMOTE比"复制少数类"更不容易过拟合？

**参考答案：** 复制只是让模型反复看同一批点；SMOTE在少数类内部的连线段上生成新点，覆盖同一片区域但不重复，模型见到的是"这片区域"而不是"那几个点"。

**问题2：** 类权重和过采样在效果上什么关系、什么差别？

**参考答案：** 原课说法是"期望上等价"：都是让少数类错误在损失里占更大比重；类权重不增加样本量、训练快、没有复制导致的过拟合风险。

**问题3：** 什么时候该降阈值、什么时候该升？

**参考答案：** 看代价：漏报贵（欺诈、癌症）就降阈值多抓；误报贵（不必要的停机、复查）就升阈值少报。

## 一、这一课解决什么问题？

欺诈模型99.9%准确率，庆祝完发现它对每笔交易都预测"不是欺诈"。这不是bug：只有0.1%是欺诈时，永远猜多数类就是最小化整体错误的理性策略——技术上正确、业务上无用。疾病诊断1%阳性、网络入侵0.01%、缺陷0.5%、垃圾邮件20%、流失5%……原课的观察是"少数类越关键往往越稀少"（经验规律，非定律）。准确率把"正确识别一笔正常交易"和"正确抓住一笔欺诈"各记一分，而抓住欺诈才是模型存在的理由——需要强迫模型在意稀有类的新指标、新技术、新训练策略。

## 二、核心概念与推导

### 2.1 为什么准确率失效

990负/10正、全预测负的混淆矩阵：TP=0、FP=0、FN=10、TN=990，准确率 $(0+990)/1000=99\%$。模型抓住的欺诈是零，但准确率报99%——这就是准确率在不平衡问题上的欺骗性。

### 2.2 更好的指标

$$\text{Precision}=\frac{TP}{TP+FP},\quad \text{Recall}=\frac{TP}{TP+FN},\quad F_1=\frac{2PR}{P+R}$$

$F_1$ 是调和平均：P 和 R 严重偏科时被狠罚（P=1.0、R=0.05 时算术平均0.525看着还行，调和平均只有0.095）。$F_\beta=(1+\beta^2)\frac{PR}{\beta^2P+R}$：β>1 偏召回（欺诈常用F2），β<1 偏精确。

**AUPRC**：随机分类器的AUPRC=正类占比（不是ROC的0.5），不平衡下改进量因此更醒目。

**MCC（Matthews相关系数）**：

$$MCC=\frac{TP\cdot TN-FP\cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

取值[−1,1]，四个格子都答好才给高分，对类规模差异稳健。对上面"全负"模型：P无定义（记0）、R=0、F1=0、MCC=0——指标正确地判它一文不值。

### 2.3 重采样策略对比

- 随机过采样：复制少数类到与多数类同量。简单，但精确副本反复出现易过拟合、训练变慢。
- 随机欠采样：删多数类到与少数类同量。快，但丢掉可能有用的多数类信息、方差升高。
- SMOTE：插值造新少数类。不重样，但可能在决策边界附近造噪声，且不考虑多数类分布。

| 策略 | 改动的数据 | 风险 | 适用 |
|---|---|---|---|
| 过采样 | 复制少数类 | 过拟合 | 小数据、中度不平衡 |
| 欠采样 | 删多数类 | 信息损失 | 大数据、要快 |
| SMOTE | 合成少数类 | 边界噪声 | 中度不平衡、少数类够做kNN |

### 2.4 SMOTE：线段插值

对每个少数类样本 x：找 k 个少数类近邻 → 随机选一个邻居 → 在连线段上取点：

$$x_{new}=x+t\cdot(x_{neighbor}-x),\quad t\sim U(0,1)$$

新点落在少数类所在的同一片区域里，是"合理的新样本"而非拷贝。

### 2.5 类权重：改损失不改数据

二分类950负/50正时，`balanced` 式权重：

$$w_c=\frac{n_{samples}}{n_{classes}\cdot n_c}\;\Rightarrow\;w_{neg}\approx0.526,\;w_{pos}=10.0$$

正类权重是负类的19倍。逻辑回归的加权损失：

$$L=-\sum_i w_i\bigl[y_i\log p_i+(1-y_i)\log(1-p_i)\bigr]$$

原课：类权重在期望上与过采样等价，但不造新数据点——更快、无复制过拟合风险。

### 2.6 阈值调优：0.5不是天条

流程：训练 → 验证集上取概率 → 从0扫到1逐个算F1 → 选最优阈值上生产。原课的关键提醒：概率的**排名**比**标定**更根本——只要欺诈的分数总体高于正常，就存在切得开的阈值。标定（Platt缩放等）让概率可解释，但不改变排名。

### 2.7 成本敏感学习

类权重的推广：给两种错误各自标价（漏报欺诈100元、误报1元），模型优化总成本而非错误个数。能估出真实成本时这是最有原则的方法——漏诊癌症和一次多余活检的成本当然不同，把成本摆上桌面才能做出正确取舍。

### 2.8 决策流程

原课的分级：轻中度（<70/30）先试类权重；中度（70/30~95/5）SMOTE+类权重；重度（>95/5）多策略组合。数据量少（<1000）避免欠采样；中等（1000~10000）SMOTE+阈值调优；大（>10000）欠采样可用或类权重。评估一律F1/AUPRC/MCC，召回不够降阈值，精确率不行升阈值或加特征。

### 2.9 用一个小例子把概念串起来（补充）

验证集110条：TP=8、TN=90、FP=10、FN=2（可手算）。准确率=98/110≈0.89看着漂亮；但精确率=8/18≈0.44，召回=8/10=0.80，$F_1=2\times\frac{0.44\times0.80}{1.24}\approx0.57$，$MCC=\frac{8\times90-10\times2}{\sqrt{18\times10\times100\times92}}=\frac{700}{1286.9}\approx0.54$。同一份预测，准确率讲"很好"，F1/MCC讲"一般"——不平衡场景该信后者。

### 4.1 造不平衡数据

多数类中心在(0,0)、少数类中心在(2.5,2.5)，打乱后返回。

~~~python
# 本块中文说明：生成950/50两类簇状分布的不平衡二维数据。
import numpy as np


def make_imbalanced_data(n_majority=950, n_minority=50, seed=42):
    rng = np.random.RandomState(seed)

    X_maj = rng.randn(n_majority, 2) * 1.0 + np.array([0.0, 0.0])   # 多数类
    X_min = rng.randn(n_minority, 2) * 0.8 + np.array([2.5, 2.5])   # 少数类

    X = np.vstack([X_maj, X_min])
    y = np.concatenate([np.zeros(n_majority), np.ones(n_minority)])

    shuffle_idx = rng.permutation(len(y))          # 打乱顺序
    return X[shuffle_idx], y[shuffle_idx]
~~~

### 4.2 SMOTE：从零实现

`find_k_neighbors` 是朴素 O(n²) 的近邻查找；`smote` 每次随机挑少数类点和邻居，线段插值。

~~~python
# 本块中文说明：SMOTE——少数类内部k近邻连线段上插值生成合成样本。
def euclidean_distance(a, b):
    return np.sqrt(np.sum((a - b) ** 2))


def find_k_neighbors(X, idx, k):
    distances = []
    for i in range(len(X)):
        if i == idx:
            continue                          # 跳过自己
        d = euclidean_distance(X[idx], X[i])
        distances.append((i, d))
    distances.sort(key=lambda x: x[1])        # 按距离升序
    return [d[0] for d in distances[:k]]      # 返回k个近邻的下标


def smote(X_minority, k=5, n_synthetic=100, seed=42):
    rng = np.random.RandomState(seed)
    n_samples = len(X_minority)
    k = min(k, n_samples - 1)                # 近邻数不能超过样本数-1
    synthetic = []

    for _ in range(n_synthetic):
        idx = rng.randint(0, n_samples)      # 随机挑一个少数类点
        neighbors = find_k_neighbors(X_minority, idx, k)
        neighbor_idx = neighbors[rng.randint(0, len(neighbors))]  # 随机挑邻居
        t = rng.random()                     # 插值比例 t~U(0,1)
        new_point = X_minority[idx] + t * (X_minority[neighbor_idx] - X_minority[idx])
        synthetic.append(new_point)          # 线段上的新点

    return np.array(synthetic)
~~~

### 4.3 随机过采样与欠采样

过采样：每类补齐到最大类数量（有放回抽）；欠采样：每类砍到最小类数量（无放回抽）。

~~~python
# 本块中文说明：随机过采样(复制少数类)与欠采样(删减多数类)。
def random_oversample(X, y, seed=42):
    rng = np.random.RandomState(seed)
    classes, counts = np.unique(y, return_counts=True)
    max_count = counts.max()

    X_resampled = list(X)
    y_resampled = list(y)

    for cls, count in zip(classes, counts):
        if count < max_count:                        # 只补不够的类
            cls_indices = np.where(y == cls)[0]
            n_needed = max_count - count
            chosen = rng.choice(cls_indices, size=n_needed, replace=True)  # 有放回
            X_resampled.extend(X[chosen])
            y_resampled.extend(y[chosen])

    X_out = np.array(X_resampled)
    y_out = np.array(y_resampled)
    shuffle = rng.permutation(len(y_out))
    return X_out[shuffle], y_out[shuffle]


def random_undersample(X, y, seed=42):
    rng = np.random.RandomState(seed)
    classes, counts = np.unique(y, return_counts=True)
    min_count = counts.min()

    X_resampled = []
    y_resampled = []

    for cls in classes:
        cls_indices = np.where(y == cls)[0]
        chosen = rng.choice(cls_indices, size=min_count, replace=False)    # 无放回
        X_resampled.extend(X[chosen])
        y_resampled.extend(y[chosen])

    X_out = np.array(X_resampled)
    y_out = np.array(y_resampled)
    shuffle = rng.permutation(len(y_out))
    return X_out[shuffle], y_out[shuffle]
~~~

### 4.4 带类权重的逻辑回归

梯度里误差先乘样本权重再求平均——少数类的错误在梯度里占大头。

~~~python
# 本块中文说明：带样本权重的逻辑回归，梯度下降求解。
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-np.clip(z, -500, 500)))   # 防溢出裁剪


def logistic_regression_weighted(X, y, weights, lr=0.01, epochs=200):
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0

    for _ in range(epochs):
        z = X @ w + b
        pred = sigmoid(z)
        error = pred - y
        weighted_error = error * weights          # 权重乘进误差

        gradient_w = (X.T @ weighted_error) / n_samples
        gradient_b = np.mean(weighted_error)

        w -= lr * gradient_w                      # 沿负梯度更新
        b -= lr * gradient_b

    return w, b


def compute_class_weights(y):
    classes, counts = np.unique(y, return_counts=True)
    n_samples = len(y)
    n_classes = len(classes)
    weight_map = {}
    for cls, count in zip(classes, counts):
        weight_map[cls] = n_samples / (n_classes * count)   # balanced式权重
    return np.array([weight_map[yi] for yi in y])           # 展开成逐样本权重
~~~

（补充说明）本实现把加权梯度除以 `n_samples` 而非权重之和：当权重和≠样本数时，整体步长与过采样版相差一个常数倍——方向一致、等效学习率略不同，见第七节。

### 4.5 阈值调优

在 0.05~0.95 上步进扫描，取使目标指标最大的阈值。

~~~python
# 本块中文说明：扫阈值——在验证集上选F1/召回/精确率最优的判定线。
def find_optimal_threshold(y_true, y_probs, metric="f1"):
    best_threshold = 0.5
    best_score = -1.0

    for threshold in np.arange(0.05, 0.96, 0.01):
        y_pred = (y_probs >= threshold).astype(int)
        tp = np.sum((y_pred == 1) & (y_true == 1))
        fp = np.sum((y_pred == 1) & (y_true == 0))
        fn = np.sum((y_pred == 0) & (y_true == 1))

        if metric == "f1":
            precision = tp / (tp + fp) if (tp + fp) > 0 else 0.0
            recall = tp / (tp + fn) if (tp + fn) > 0 else 0.0
            score = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0.0
        elif metric == "recall":
            score = tp / (tp + fn) if (tp + fn) > 0 else 0.0
        elif metric == "precision":
            score = tp / (tp + fp) if (tp + fp) > 0 else 0.0

        if score > best_score:
            best_score = score
            best_threshold = threshold

    return best_threshold, best_score
~~~

### 4.6 评估函数

混淆矩阵四格 + 五个指标；分母为零时按0处理（对应"全预测负"的精确率无定义情形）。

~~~python
# 本块中文说明：混淆矩阵与P/R/F1/MCC/准确率的计算。
def confusion_matrix_values(y_true, y_pred):
    tp = np.sum((y_pred == 1) & (y_true == 1))
    tn = np.sum((y_pred == 0) & (y_true == 0))
    fp = np.sum((y_pred == 1) & (y_true == 0))
    fn = np.sum((y_pred == 0) & (y_true == 1))
    return tp, tn, fp, fn


def compute_metrics(y_true, y_pred):
    tp, tn, fp, fn = confusion_matrix_values(y_true, y_pred)
    accuracy = (tp + tn) / (tp + tn + fp + fn)
    precision = tp / (tp + fp) if (tp + fp) > 0 else 0.0
    recall = tp / (tp + fn) if (tp + fn) > 0 else 0.0
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0.0

    denom = np.sqrt(float((tp + fp) * (tp + fn) * (tn + fp) * (tn + fn)))
    mcc = (tp * tn - fp * fn) / denom if denom > 0 else 0.0

    return {
        "accuracy": accuracy,
        "precision": precision,
        "recall": recall,
        "f1": f1,
        "mcc": mcc,
    }
~~~

### 4.7 五种方案总对比

基线（无处理）、过采样、SMOTE、类权重、阈值调优，同数据同模型比较。注意阈值是在训练集切出的验证片段上调的（不是测试集）；但调好的阈值套在了另一个模型（全训练集+类权重版）的输出上——见第七节的核对。

~~~python
# 本块中文说明：五种处理方案在同一划分下的总对比脚本。
X, y = make_imbalanced_data(950, 50, seed=42)
split = int(0.8 * len(y))
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# Baseline: no treatment
w_base, b_base = logistic_regression_weighted(
    X_train, y_train, np.ones(len(y_train)), lr=0.1, epochs=300
)
probs_base = sigmoid(X_test @ w_base + b_base)
preds_base = (probs_base >= 0.5).astype(int)

# Oversampled
X_over, y_over = random_oversample(X_train, y_train)
w_over, b_over = logistic_regression_weighted(
    X_over, y_over, np.ones(len(y_over)), lr=0.1, epochs=300
)
preds_over = (sigmoid(X_test @ w_over + b_over) >= 0.5).astype(int)

# SMOTE
minority_mask = y_train == 1
X_minority = X_train[minority_mask]
synthetic = smote(X_minority, k=5, n_synthetic=len(y_train) - 2 * int(minority_mask.sum()))
X_smote = np.vstack([X_train, synthetic])
y_smote = np.concatenate([y_train, np.ones(len(synthetic))])
w_sm, b_sm = logistic_regression_weighted(
    X_smote, y_smote, np.ones(len(y_smote)), lr=0.1, epochs=300
)
preds_smote = (sigmoid(X_test @ w_sm + b_sm) >= 0.5).astype(int)

# Class weights
sample_weights = compute_class_weights(y_train)
w_cw, b_cw = logistic_regression_weighted(
    X_train, y_train, sample_weights, lr=0.1, epochs=300
)
probs_cw = sigmoid(X_test @ w_cw + b_cw)
preds_cw = (probs_cw >= 0.5).astype(int)

# Threshold tuning (tune on a validation slice of the training set, not the test set)
val_split = int(0.75 * len(y_train))
X_tr, X_val = X_train[:val_split], X_train[val_split:]
y_tr, y_val = y_train[:val_split], y_train[val_split:]
w_val, b_val = logistic_regression_weighted(
    X_tr, y_tr, compute_class_weights(y_tr), lr=0.1, epochs=300
)
probs_val = sigmoid(X_val @ w_val + b_val)
best_thresh, best_f1 = find_optimal_threshold(y_val, probs_val, metric="f1")
preds_thresh = (probs_cw >= best_thresh).astype(int)
~~~

## 六、Use It：使用现成工具

sklearn 与 imbalanced-learn 下这些技术都是现成的：

~~~python
# 本块中文说明：sklearn/imblearn 版——类权重、SMOTE与防泄漏的imblearn流水线。
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, f1_score
from sklearn.model_selection import train_test_split
from imblearn.over_sampling import SMOTE
from imblearn.under_sampling import RandomUnderSampler
from imblearn.pipeline import Pipeline

X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y)

model_weighted = LogisticRegression(class_weight="balanced")
model_weighted.fit(X_train, y_train)
print(classification_report(y_test, model_weighted.predict(X_test)))

smote = SMOTE(random_state=42)
X_resampled, y_resampled = smote.fit_resample(X_train, y_train)
model_smote = LogisticRegression()
model_smote.fit(X_resampled, y_resampled)
print(classification_report(y_test, model_smote.predict(X_test)))

pipeline = Pipeline([
    ("smote", SMOTE()),
    ("model", LogisticRegression(class_weight="balanced")),
])
pipeline.fit(X_train, y_train)
print(classification_report(y_test, pipeline.predict(X_test)))
~~~

原课的收束：从零实现揭示了每项技术的本质——SMOTE 就是少数类的kNN插值，类权重就是损失乘系数，阈值调优就是对截止点的for循环，没有魔法。另注意 `imblearn.pipeline.Pipeline`（非sklearn的）会在**每个训练折内**做重采样，防止合成样本泄漏进验证折。

## 七、失败模式、原文边界与工程注意

1. SMOTE 必须只作用于训练折：在划分前对全数据 SMOTE，合成样本会同时出现在训练与验证两侧（泄漏）；用 imblearn Pipeline 或在 CV 循环内做。
2. SMOTE 在决策边界附近插值会产生噪声样本，且不看多数类分布——类重叠严重时先用 Borderline/清理类变体（练习1）。
3. 随机欠采样丢信息；大数据集之外慎用。
4. 类权重过大时模型可能过拟合少数类、伤害多数类；权重是超参数，要用验证指标确认收益。
5. 阈值必须在验证数据上调、绝不碰测试集。核对：原课第7步在训练集切片上训练模型A、用A的验证分数调阈值，却把阈值套到全训练集模型B的输出上——方向正确（没碰测试集）但模型不匹配，更干净的做法是A=B或在最终模型自身的验证输出上调。
6. 补充：`logistic_regression_weighted` 的梯度除以 `n_samples` 而非权重和，与"期望上等价于过采样"相差一个常数倍的步长；不影响方向结论，但复现数值时会与过采样版有差异。
7. 原课"少数类越重要越稀少"是经验观察，不是定律；具体数据集的类分布要看实际统计。
8. 准确率在不平衡下无意义这条**是**可由2.1节混淆矩阵直接验证的结论，不是夸张。
9. `find_k_neighbors` 是 O(n²) 朴素实现，少数类很大时用 KD 树/近似近邻替换（补充）。
10. `random_oversample` 复制的是精确副本，`random_undersample` 会随机丢弃不同信息——两个随机性都以 seed 控制，比较实验时要固定。

## 十、术语与完成标准
