### 0.1 先理解这一课在做什么

门卫认熟客的方式不是背下所有通缉犯的照片，而是记住常客的样子——脸生的就拦下检查。异常检测把分类问题倒过来：**学什么是正常，不像正常的就可疑**。 Fraud 占交易的0.1%，故障一年就几次，"异常类"几乎没有样本可学；而"正常"的数据要多少有多少。这一课学四个工具：两个统计的（Z-score、IQR）、一个切分式的（孤立森林）、一个密度式的（LOF）。

### 0.2 本课术语先翻成白话

- 异常/离群点（anomaly/outlier）=显著偏离"正常模式"的观测
- 点异常（point anomaly）=单看数值就不正常（传感器读500度）
- 上下文异常（contextual anomaly）=数值正常但场合不对（一月出现90华氏度）
- 集体异常（collective anomaly）=每个点都正常、连成一串就不对（连续50次登录失败）
- Z-score=离均值几个标准差
- IQR 四分位距=中间50%数据的宽度，稳健的"正常带"
- 孤立森林（Isolation Forest）=用随机切分把点隔离，越快被隔离越可疑
- 路径长度（path length）=一个点在随机树里被隔离用了几刀
- LOF 局部离群因子=自己的密度和邻居的密度之比
- contamination=预设"异常占比"，只决定阈值不改变分数
- Precision@k=报警清单前k条里真异常的比例
- AUPRC=精确率-召回率曲线下面积，不平衡场景比AUROC更有信息量
- 遮蔽（masking）=异常自己把均值/方差拉歪，反而更难被发现

### 0.3 用小数字走一遍

温度序列 `[10, 11, 12, 13, 60]`。

Z-score：均值=21.2，总体标准差≈19.43（被60严重拉大），60的z=38.8/19.43≈**2.0**——阈值取3的话**漏报**！异常自己污染了均值和方差（遮蔽效应）。

IQR：Q1=11、Q3=13、IQR=2，正常带=[11−1.5×2, 13+1.5×2]=[8, 16]，60 超上界被**抓到**。分位数不受极端值影响，所以更稳健。

孤立森林分数：取 n=8，$c(8)=2(\ln 7+0.5772)-2\times7/8\approx3.30$。平均路径 h=2 的点得分 $2^{-2/3.30}\approx0.66$（可疑），h=4 的点得分 $2^{-4/3.30}\approx0.43$（正常侧）。越快被隔离，分数越接近1。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.4 怎样连接到正文代码

按顺序读：`zscore_detect`（一行向量化公式）→ `iqr_detect`（分位数+上下界）→ `_c_factor` + `IsolationTree`（递归随机切分，叶子记 size）→ `IsolationForest`（每棵树用一小撮样本，平均路径换算分数）。核心数据结构：树的节点存 `(feature, threshold, left, right)` 或叶子标记；森林存树列表和训练样本数。读代码时盯住一个不变量：**异常的路径短，正常的路径长**。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么异常检测不直接训练一个二分类器？

**参考答案：** 异常样本通常少到学不动，而且明天的异常和今天的不一样；建模"正常"不需要异常标签，还能抓到没见过的异常类型，代价是误报率更高。

**问题2：** Z-score 和 IQR 都逐特征判断，它们共同漏掉什么？

**参考答案：** 联合异常——每个特征单独看都正常（身高190cm、体重50kg各自都见过），组合起来不正常（又高又瘦得离谱）。逐特征方法看不见这种点。

**问题3：** 孤立森林里，"正常点路径长"的原因是什么？

**参考答案：** 正常点挤在密集区，随机切一刀很难把它单独分出来，要很多刀；异常点待在稀疏区，一两刀就被隔离了。

## 一、这一课解决什么问题？

2:05纽约刷的卡2:10在东京刷；传感器从80~120的正常带跳到150；服务器每秒5万请求而日均200。原课指出：找异常很难用监督分类——Fraud只占0.1%、设备故障一年几次，异常类几乎无样本可学，而且已有的异常标签也覆盖不了明天的新花样。异常检测翻转问题：学"正常"的分布，偏离正常的就可疑——无需标签、天然适应新型异常、可扩展到海量数据。

## 二、核心概念与推导

### 2.1 三种异常类型

点异常：单个观测无论上下文都不正常（500度读数、平时花50的账户刷5万）。上下文异常：值本身正常、上下文不正常（90度在一月异常、在夏天正常）。集体异常：个体正常、群体异常（5次登录失败正常，50连败是暴力破解）。多数方法只检测点异常；上下文异常需要时间/位置特征；集体异常需要序列感知的方法。

### 2.2 无监督框架：三种现实情形

完全无监督：完全没有标签，在全量数据上拟合，赌异常足够稀少不至于带坏"正常模型"。半监督（最强情形）：只有干净的正常数据，在干净集上拟合，给其他一切打分。弱监督：有少量已标异常——用于**评估**而非训练。核心区别：异常检测建模的是正常数据的分布，不是两类之间的决策边界。

### 2.3 有标签时：监督分类 vs 无监督检测

监督（当分类做）：对已见过的异常类型精确率高；但完全漏掉新型异常，新类型出现要重训，且异常样本常常不够。无监督（建模正常）：任何偏离都能抓，包括新类型；不需要异常标签；误报率更高（不寻常≠坏事），对分布漂移更稳健。原课建议：生产系统通常组合——无监督保覆盖、监督抓已知高优先类型、人审灰色地带。

### 2.4 Z-score 方法

$$z=\frac{x-\mu}{\sigma},\quad |z|>k\ \text{判为异常}$$

默认 k=3（正态假设下约99.7%数据落在3个标准差内）。优点：简单、快、可解释（"这个值偏离正常4.5个标准差"）。缺点：假设近正态；训练数据里的异常会拉偏 μ 和 σ，把自己藏起来（遮蔽）；多峰分布失效。适用：单特征监控、近钟形、基线稳定（响应时间、制造公差）。失效：多簇数据、偏斜数据（金额1000罕见但不异常）、训练集本身含异常。

### 2.5 IQR 方法

$$\text{下界}=Q_1-f\cdot IQR,\quad \text{上界}=Q_3+f\cdot IQR,\quad IQR=Q_3-Q_1$$

默认 f=1.5（箱线图的须）。优点：分位数对极端值稳健、无正态假设、偏斜分布可用。缺点：只逐特征独立判断，看不见联合异常。f 取 3.0 更保守（少报少误报）；选多少是误报容忍度的业务决策。

### 2.6 孤立森林

核心洞察：**异常又少又不同**——随机切分下它们更快被隔离。做法：建很多棵随机树，每个节点随机选特征、在 [min, max] 间随机选切分值，直到每个点独占一个叶子；异常点在多数树里的路径都短。异常分数：

$$s(x)=2^{-\,E[h(x)]\,/\,c(n)}$$

$E[h(x)]$ 是点 x 在所有树上的平均路径长度，$c(n)$ 是 n 个样本的期望路径长度（$c(n)=2H(n-1)-2(n-1)/n$，$H(i)\approx\ln i+0.5772$，与二叉搜索树期望高度同源）。分数接近1=异常，接近0.5=正常，接近0=深入稠密簇的正常点。关键超参数：`n_estimators`（100通常够）、`max_samples`（原论文默认256，子采样正是它快的原因）、`contamination`（**只用来定阈值，不影响分数**）。优点：无分布假设、高维可用、近似线性扩展。缺点：稠密区里的异常难分（遮蔽）；无关特征太多时随机切分失焦。

### 2.7 LOF：局部密度

LOF 比较一个点的局部密度与其邻居的局部密度：找 k 近邻 → 算局部可达密度 → 与邻居的密度比。LOF≈1=和邻居一样密（正常）；显著大于1（如2+）=局部稀疏（可疑）。"局部"的价值：一密一疏两个簇，疏簇边缘点全局看不奇怪，但它周围的邻居都比它密——全局方法看不见，LOF 能。缺点：朴素实现 $O(n^2)$、k 敏感、高维距离失真。

### 2.8 方法对比与评估难题

| 方法 | 假设 | 速度 | 高维 | 局部异常 |
|---|---|---|---|---|
| Z-score | 正态 | 极快 | 逐特征可 | 否 |
| IQR | 无（逐特征） | 极快 | 逐特征可 | 否 |
| 孤立森林 | 无 | 快 | 可 | 部分 |
| LOF | 距离有意义 | 慢 | 差 | 是 |

评估比分类难：0.1%异常下全预测"正常"就有99.9%准确率——准确率无意义；重不平衡下 AUROC 也可能虚高（容易在真负类上得分）。更好的指标：Precision@k（前k条报警里多少真异常）、AUPRC、固定误报率下的召回。

### 2.9 实践流水线

收基线数据（尽量无异常的时段）→ 特征工程（原始+滚动统计+时间特征+比值）→ 在基线上训练检测器 → 给新数据打分 → 定阈值（业务决策：阈值高=少报警少漏，阈值低反之）→ 报警并调查 → 收集反馈调阈值。原课强调：检测器永远不会"完成"——分布会漂移、新异常会出现，把它当活系统。

### 2.10 用一个小例子把概念串起来（补充）

两个特征：身高、体重，各自近正态。一个样本 (190cm, 50kg)：身高z≈+1.7、体重z≈−1.8，逐特征都不超3——Z-score、IQR 都放行。但"这么高且这么轻"的组合在联合空间里远离正常椭圆。孤立森林有机会抓到：随机切分若干刀后，这点周围没有邻居护着，很快被隔离。这也解释了为什么生产的检测器要多个方法组合（第六节）。

### 4.1 Z-score 检测器

逐特征算 z，任一特征超阈值即标记。`std[std==0]=1` 防常数列除零。

~~~python
# 本块中文说明：Z-score检测——任一特征的|z|超阈值即判异常。
def zscore_detect(X, threshold=3.0):
    mean = X.mean(axis=0)          # 逐列均值
    std = X.std(axis=0)            # 逐列标准差
    std[std == 0] = 1.0             # 常数列保护
    z = np.abs((X - mean) / std)
    return z.max(axis=1) > threshold  # 任一特征超标即异常
~~~

### 4.2 IQR 检测器

分位数不敏感于极端值；任一特征出界即标记。

~~~python
# 本块中文说明：IQR检测——Q1/Q3加减1.5倍IQR构成正常带，出界即异常。
def iqr_detect(X, factor=1.5):
    q1 = np.percentile(X, 25, axis=0)   # 下四分位
    q3 = np.percentile(X, 75, axis=0)   # 上四分位
    iqr = q3 - q1
    iqr[iqr == 0] = 1.0                 # 零宽度保护
    lower = q1 - factor * iqr
    upper = q3 + factor * iqr
    outside = (X < lower) | (X > upper)
    return outside.any(axis=1)          # 任一特征出界即异常
~~~

### 4.3 孤立树：随机切分的递归结构

`_c_factor` 是规范化常数（期望路径长度），孤立树随机选特征与切分值递归二分；`path_length` 返回隔离该点花的刀数（到叶子的深度+叶内修正项）。

~~~python
# 本块中文说明：期望路径长度c(n)与随机切分的孤立树。
def _c_factor(n):
    if n <= 1:
        return 0.0
    if n == 2:
        return 1.0
    return 2.0 * (np.log(n - 1) + 0.5772156649) - 2.0 * (n - 1.0) / n


class IsolationTree:
    def __init__(self, max_depth):
        self.max_depth = max_depth

    def fit(self, X, depth=0):
        n, p = X.shape
        if depth >= self.max_depth or n <= 1:
            self.is_leaf = True          # 到深度上限或只剩一个点
            self.size = n
            return self
        self.is_leaf = False
        self.feature = np.random.randint(p)        # 随机选特征(全局随机源!)
        x_min = X[:, self.feature].min()
        x_max = X[:, self.feature].max()
        if x_min == x_max:
            self.is_leaf = True         # 该特征无区分度
            self.size = n
            return self
        self.threshold = np.random.uniform(x_min, x_max)  # 随机切分值
        left_mask = X[:, self.feature] < self.threshold
        self.left = IsolationTree(self.max_depth).fit(X[left_mask], depth + 1)
        self.right = IsolationTree(self.max_depth).fit(X[~left_mask], depth + 1)
        return self

    def path_length(self, x, depth=0):
        if self.is_leaf:
            return depth + _c_factor(self.size)     # 叶内未分完的修正
        if x[self.feature] < self.threshold:
            return self.left.path_length(x, depth + 1)
        return self.right.path_length(x, depth + 1)
~~~

### 4.4 孤立森林：多树平均

每棵树只喂 `max_samples` 个无放回抽样的样本（默认256），深度上限 $\lceil\log_2(\text{样本数})\rceil$；分数=平均路径按 $2^{-\bar h/c(n)}$ 换算。

~~~python
# 本块中文说明：孤立森林——子采样建多树，平均路径换算异常分数。
class IsolationForest:
    def __init__(self, n_estimators=100, max_samples=256, seed=42):
        self.n_estimators = n_estimators
        self.max_samples = max_samples
        self.seed = seed
        self.trees = []
        self.n_train = 0

    def fit(self, X):
        self.n_train = X.shape[0]
        rng = np.random.RandomState(self.seed)      # 只控制子采样索引
        self.trees = []
        sample_size = min(self.max_samples, X.shape[0])
        max_depth = int(np.ceil(np.log2(sample_size)))
        for _ in range(self.n_estimators):
            idx = rng.choice(X.shape[0], size=sample_size, replace=False)
            tree = IsolationTree(max_depth=max_depth)
            tree.fit(X[idx])
            self.trees.append(tree)
        return self

    def anomaly_score(self, X):
        avg_path = np.zeros(X.shape[0])
        for tree in self.trees:
            for i in range(X.shape[0]):
                avg_path[i] += tree.path_length(X[i])   # 逐点逐树累计路径
        avg_path /= self.n_estimators
        c = _c_factor(min(self.max_samples, self.n_train))
        return 2.0 ** (-avg_path / c) if c > 0 else np.zeros(X.shape[0])
~~~

predictions = lof.predict(X_test)
~~~

`contamination` 只把连续分数切成二值预测，不改分数本身：`contamination=0.05` 标前5%，`=0.10` 标前10%。不知道真实异常率时设 `contamination="auto"` 直接用原始分数，按误报/漏报成本自定阈值。

One-Class SVM：在核空间里给正常数据画边界，`nu` 近似异常占比；中小数据可用，核矩阵平方增长导致难扩展：

~~~python
# 本块中文说明：One-Class SVM——核空间中包住正常数据的边界。
from sklearn.svm import OneClassSVM

oc_svm = OneClassSVM(kernel="rbf", gamma="auto", nu=0.05)
oc_svm.fit(X_train)
predictions = oc_svm.predict(X_test)
~~~

自编码器思路（第3阶段深度学习的内容预告）：在正常数据上训练压缩-重建网络，异常点重建误差高——原理仍是"建模正常，标记偏离"。

集成检测（呼应[第11课](<11：集成方法——Bagging、Boosting与Stacking.md>)）：多个检测器分数各自归一到[0,1]再平均，多数方法都报的点大概率真异常、只有一个方法报的可能是该方法的怪癖；更成熟的做法按验证集上的可靠性加权。

生产注意（原课转述）：阈值漂移（分布变了固定阈值过期，监控分数分布定期调）；报警疲劳（从高阈值起步建立信任再降）；多检测器组合降低误报；特征工程常比换检测器更重要（滚动统计、比值、距上次事件时间）；反馈回流持续积累标签。

## 七、失败模式、原文边界与工程注意

1. Z-score 的遮蔽效应：异常污染 μ/σ 后反而更难被检出（0.3 节手算可验证）；训练基线要尽量干净。
2. Z-score、IQR 都只逐特征判断，联合异常（190cm+50kg）结构性漏检；需要孤立森林/LOF/密度方法。
3. 孤立森林的 `seed` 参数只固定子采样索引，树内 `np.random.randint/uniform` 走全局随机源——复现需整体另行 `np.random.seed(...)`（核对，可从代码直接验证，第五节已按此处理）。
4. 稠密区域的异常（遮蔽/淹没）与大量无关特征是孤立森林的弱项；维度高到距离失真时 LOF 也失效。
5. `contamination` 只影响阈值不影响分数（原文正确，保留）；把它当"真实异常率"估计是误用。
6. 原课"AUROC 会误导"应理解为"重不平衡下可能虚高"，不是一律不能用；报告 Precision@k、AUPRC 与固定误报率下的召回更稳妥。
7. 阈值是业务决策不是技术指标：漏一次欺诈 vs 误报一次5分钟人工核查，成本结构决定阈值位置。
8. `anomaly_score` 是逐点逐树的双重 Python 循环，大数据量下慢——教学实现，sklearn 版是向量化的（补充）。
9. 演示场景（4.5节）与 sklearn 对比的输出数值均为原课参考，本文未运行。

## 十、术语与完成标准
