### 0.1 先理解这一课在做什么

模型有两类设置：训练时**自己学出来**的（权重、分裂阈值），和训练前**你先拧好**的（学习率、树深、正则强度）。后者叫超参数。调优像在黑屋子里找灯的开关：每试一个组合都要付一次训练的钱，试错了才知道。本课学三种找法——地毯式逐个试（网格）、撒豆子随机试（随机）、记住前几次结果再决定下一步试哪（贝叶斯）。

### 0.2 本课术语先翻成白话

- 超参数（hyperparameter）=训练前人为设定的设置，不由数据学出
- 参数（parameter）=训练过程学出来的数（权重、阈值）
- 网格搜索（grid search）=把每个超参数取几个值，所有组合挨个试
- 随机搜索（random search）=从分布里随机抽组合试
- 搜索空间（search space）=每个超参数允许取值的范围
- 对数尺度（log scale）=在对数轴上均匀采样，0.001~0.01 和 0.1~1 同等重要
- 代理模型（surrogate model）=代替昂贵训练的廉价近似，通常高斯过程（GP）
- 采集函数（acquisition function）=决定"下一个试哪里"的打分规则
- 开发/探索（exploitation/exploration）=在已知好的附近挖 / 去没去过的地方看
- 早停（early stopping）=一看就不行的配置提前杀掉
- Hyperband=先给很多配置小预算，逐轮淘汰，赢家加预算
- 嵌套交叉验证（nested CV）=外层估性能、内层选超参数的双层循环

### 0.3 用小数字走一遍

两个超参数、每个3个取值：网格是 3×3=9 次评估，但学习率只试过 3 个不同值。同样 9 次随机搜索，学习率能试到 9 个不同值——如果只有学习率重要，随机搜索花同样的钱探索了重要维度 3 倍的密度。这就是"低有效维度"：6个超参数常常只有1~2个真正重要。

对数尺度小例：学习率范围 [0.001, 1]，线性采样会把一半预算花在 0.5~1 这段（通常都发散）；对数采样让 0.001~0.01、0.01~0.1、0.1~1 各占三分之一。

以上是用于理解的算例，不是新增的训练或性能实测。

按顺序读：`grid_search`/`random_search`（两版暴力循环，差别只在组合怎么来）→ `SimpleBayesianOptimizer`（`_kernel` 算相似度、`_fit_gp` 用乔列斯基解GP、`_expected_improvement` 算采集值、`suggest` 在500个随机候选里挑EI最大的、`observe` 记录结果）→ 第4段的合成目标对比。核心数据结构：`(参数字典, 分数)` 列表；GP 内部是观测点矩阵 `X_observed` 和分数向量 `y_observed`。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么同样预算下随机搜索常赢网格搜索？

**参考答案：** 大多数问题只有少数超参数真正重要（低有效维度）；网格在重要维度上只获得"每参数取值数"个不同值，随机在所有维度上都是"试验次数"个不同值。

**问题2：** 代理模型和采集函数各管什么？

**参考答案：** 代理模型（GP）在每个候选点给出预测分数+不确定度；采集函数（如EI）把两者合成一个"值得试"的分数，平衡在好区域深挖（开发）和去不确定区域看看（探索）。

**问题3：** 为什么学习率要按对数尺度搜索、批量大小不用？

**参考答案：** 学习率的影响跨数量级（0.001和0.01的差别≈0.1和1.0的差别），线性采样在大值端浪费预算；批量大小在合理范围内的差别相对平缓，16/32/64这类离散值直接枚举即可。

## 一、这一课解决什么问题？

梯度提升有六个常见超参数（学习率、树数、深度、叶最小样本、行采样、列采样），每个5个合理取值就是 $5^6=15625$ 个组合；每个训练10秒就是43小时。网格搜索是最直觉的方案，也是规模一大就最差的方案；随机搜索同样算力覆盖更广；贝叶斯优化还能从已试过的评估里学习。原课目标：会从零实现三种方法、知道哪个该用、知道哪些超参数值得花钱调。

## 二、核心概念与推导

### 2.1 参数与超参数

参数在训练中由数据学出；超参数在训练前设定并控制学习过程本身。常见超参数与典型范围（原课表格，范围是惯例参考）：

| 超参数 | 控制 | 典型范围 |
|---|---|---|
| 学习率 | 每步更新多大 | 0.001 ~ 1.0 |
| 树数/轮数 | 训练多久 | 10 ~ 10000 |
| 最大深度 | 模型复杂度 | 1 ~ 30 |
| 正则强度 λ | 防过拟合 | 0.0001 ~ 100 |
| 批量大小 | 梯度噪声 | 16 ~ 512 |
| Dropout率 | 随机失活比例 | 0.0 ~ 0.5 |

### 2.2 网格搜索与组合爆炸

每维取若干值、全组合逐个评估：2个超参数各3个值是9次，6个各5个值是15625次——评估数随维度指数增长。更要命的缺陷：若只有一个超参数重要，9次评估里重要参数只试了3个不同值，其余6次的钱花在了不重要的维度上。

### 2.3 随机搜索为什么常胜过网格

随机搜索从分布采样而非网格点。同样9次预算，每个超参数都有9个不同取值。Bergstra & Bengio (2012) 的解释：多数超参数问题具有低有效维度——6个超参数里通常只有1~2个对该问题重要；网格在不重要维度上重复烧钱，随机把密度留给重要维度。原课"60次随机试验有95%概率找到最优值5%以内的点（若存在于搜索空间内）"是带条件的经验说法（原课参考），不是普适保证。

### 2.4 贝叶斯优化：记住结果再决定下一步

随机搜索不利用历史——它不知道"学习率一大就发散、深度3总比10好"。贝叶斯优化循环：定义搜索空间 → 随机试几个初始点 → 用观测拟合代理模型 → 用采集函数选下一个点 → 评估 → 重复直到预算耗尽。两个组件：

**代理模型**：廉价的近似模型（通常高斯过程），在任意点给出预测均值 $\mu$ 和不确定度 $\sigma$。

**采集函数**：平衡开发与探索。期望改进（EI）：$EI(x)=\mathbb{E}[\max(f_{best}-f(x),0)]$，即"这个点平均能比当前最好值好多少"；上置信界（UCB）：$\mu(x)+\kappa\sigma(x)$，预测好或没探索过都给高分；改进概率（PI）：超过当前最好值的概率。原课"贝叶斯优化通常以2~5倍更少的评估找到更好的超参数"是经验性结论（原课参考），不是定理。

### 2.5 早停与Hyperband

不该让每个配置都训满：耐心法（验证N轮不改善就停）、中位数剪枝（中间结果低于同期完成试验的中位数就停）、Hyperband（先81个配置各1轮，留前1/3给3轮，再留前1/3……用淘汰赛省算力）。原课"Hyperband比全预算快10~50倍"同样是条件性经验数字（原课参考）。对提升和神经网络，把轮数设高配早停，比把轮数当超参数调更好——等于从搜索空间里删掉一个维度。

### 2.6 学习率调度器

学习率几乎总是最重要的超参数，也可以训练中按计划变化。余弦退火：$lr(t)=lr\cdot0.5(1+\cos(\pi t/T))$；另有阶梯衰减、warmup+衰减、one-cycle、plateau 缩减。调度器属于训练内部策略，与"训练前调超参数"是两件事，但常常配合使用。

### 2.7 超参数重要性

高：学习率（最先调）、树数/轮数（用早停代替调）、正则强度。中：最大深度、叶最小样本/权重衰减、行采样比。低（原课归纳，来自随机森林与梯度提升的研究，具体问题会变）：max_features、激活函数选择、合理范围内的批量大小。策略：先调重要的，其余留默认。

### 2.8 实用策略与嵌套交叉验证

工作流：默认参数起步（常已到八成功力）→ 20~50次粗随机搜索（配早停）→ 分析哪些超参数与性能相关、收窄空间 → 50~100次精细搜索（贝叶斯或聚焦随机）→ 用最优超参数在全训练数据上重训。

单个验证集上调参有风险：最好的超参数可能过拟合这一折。嵌套交叉验证用双层循环：外层（评估）分出train+val与test，报告无偏性能；内层（调参）在train+val内再分train/val选超参数。每个外层折独立找自己的最优超参数，外层分数是对泛化性能的无偏估计——代价是 5外层×5内层×27网格点=675次拟合这类量级的算力，适合最终报告或高决策风险场景。

### 2.9 用一个小例子把概念串起来（补充）

原课第4段的合成目标：$f(lr,depth)=-(\log_{10}lr+2)^2-(depth-4)^2+10$。最优在 $lr=0.01$、$depth=4$，$f=10$（可手算：两项平方均为0）。网格恰好包含 (0.01, 4)，所以网格搜索必然拿到10.0——在这个特意构造的例子里网格不吃亏；但随机/贝叶斯在连续空间上采样，通常只能逼近10。反过来，若把 depth 网格改成 [2,3,5,6,7,8]（跳过4），网格就只能停在 $f=9$，而连续采样的随机/贝叶斯仍可能接近10——这时"网格在不重要维度浪费预算"的劣势才显形。

## 四、Build It：原课分步代码与中文讲解

原课 Build It 共 4 段，全部有代码。注意：`evaluate`、`sample`、`sample_random`、`to_vector`、`norm_cdf`、`norm_pdf` 在原课文档中均未定义——原文缺这些辅助函数，第五节补充。

### 4.1 网格搜索：全组合暴力循环

`itertools.product` 枚举所有组合；`model_fn(**params)` 按参数构造模型。返回最优参数、最优分数和实际评估次数。

~~~python
# 本块中文说明：网格搜索——枚举参数网格的所有组合，逐个训练评估。
def grid_search(model_fn, param_grid, X_train, y_train, X_val, y_val):
    keys = list(param_grid.keys())
    values = list(param_grid.values())
    best_score = -float("inf")
    best_params = None
    n_evals = 0

    for combo in itertools.product(*values):     # 全组合笛卡尔积
        params = dict(zip(keys, combo))
        model = model_fn(**params)               # 用这组参数建模型
        model.fit(X_train, y_train)
        score = evaluate(model, X_val, y_val)    # 在验证集打分
        n_evals += 1

        if score > best_score:
            best_score = score
            best_params = params

    return best_params, best_score, n_evals
~~~

### 4.2 随机搜索：从分布采样

与网格唯一差别：每轮从 `param_distributions` 采样一组参数。同样预算下每个参数都尝试了 `n_iter` 个不同值。

~~~python
# 本块中文说明：随机搜索——每轮从分布采样一组参数再评估。
def random_search(model_fn, param_distributions, X_train, y_train,
                  X_val, y_val, n_iter=50, seed=42):
    rng = np.random.RandomState(seed)
    best_score = -float("inf")
    best_params = None

    for _ in range(n_iter):
        params = {k: sample(v, rng) for k, v in param_distributions.items()}
        model = model_fn(**params)
        model.fit(X_train, y_train)
        score = evaluate(model, X_val, y_val)

        if score > best_score:
            best_score = score
            best_params = params

    return best_params, best_score, n_iter
~~~

### 4.3 简化版贝叶斯优化：GP代理 + EI采集

先随机试 `n_initial` 个点，之后每轮：采500个随机候选 → GP预测(μ, var) → 算EI → 挑EI最大的。`_fit_gp` 用乔列斯基金解GP后验；`_expected_improvement` 在方差大（没探索过）或均值高（预测好）时给高分。

~~~python
# 本块中文说明：简化贝叶斯优化器——高斯过程代理 + 期望改进采集函数。
class SimpleBayesianOptimizer:
    def __init__(self, search_space, n_initial=5):
        self.search_space = search_space
        self.n_initial = n_initial
        self.X_observed = []       # 已试过的参数向量
        self.y_observed = []       # 对应分数

    def _kernel(self, x1, x2, length_scale=1.0):
        dists = np.sum((x1[:, None, :] - x2[None, :, :]) ** 2, axis=2)
        return np.exp(-0.5 * dists / length_scale ** 2)   # RBF核

    def _fit_gp(self, X_new):
        X_obs = np.array(self.X_observed)
        y_obs = np.array(self.y_observed)
        y_mean = y_obs.mean()
        y_centered = y_obs - y_mean

        K = self._kernel(X_obs, X_obs) + 1e-4 * np.eye(len(X_obs))  # 抖动防奇异
        K_star = self._kernel(X_new, X_obs)

        L = np.linalg.cholesky(K)                 # 乔列斯基分解
        alpha = np.linalg.solve(L.T, np.linalg.solve(L, y_centered))
        mu = K_star @ alpha + y_mean              # 后验均值

        v = np.linalg.solve(L, K_star.T)
        var = 1.0 - np.sum(v ** 2, axis=0)        # 后验方差(先验方差取1)
        var = np.maximum(var, 1e-6)

        return mu, var

    def _expected_improvement(self, mu, var, best_y):
        sigma = np.sqrt(var)
        z = (mu - best_y) / (sigma + 1e-10)       # 标准化改进量
        ei = sigma * (z * norm_cdf(z) + norm_pdf(z))
        return ei

    def suggest(self):
        if len(self.X_observed) < self.n_initial:  # 冷启动：先随机
            return sample_random(self.search_space)

        candidates = [sample_random(self.search_space) for _ in range(500)]
        X_cand = np.array([to_vector(c) for c in candidates])
        mu, var = self._fit_gp(X_cand)
        ei = self._expected_improvement(mu, var, max(self.y_observed))
        return candidates[np.argmax(ei)]          # EI最大的候选

    def observe(self, params, score):
        self.X_observed.append(to_vector(params))
        self.y_observed.append(score)
~~~

### 4.4 三种方法同预算对比（合成目标）

直接对解析函数打分（不训练模型），三法各28次评估。网格28=4×7个组合；随机28次采样；贝叶斯28次（含5次初始随机）。

~~~python
# 本块中文说明：在合成目标上同预算对比三种搜索方法。
def synthetic_objective(params):
    lr = params["learning_rate"]
    depth = params["max_depth"]
    return -(np.log10(lr) + 2) ** 2 - (depth - 4) ** 2 + 10

param_grid = {
    "learning_rate": [0.001, 0.01, 0.1, 1.0],
    "max_depth": [2, 3, 4, 5, 6, 7, 8],
}

grid_best = None
grid_score = -float("inf")
grid_history = []
for combo in itertools.product(*param_grid.values()):
    params = dict(zip(param_grid.keys(), combo))
    score = synthetic_objective(params)
    grid_history.append((params, score))
    if score > grid_score:
        grid_score = score
        grid_best = params

param_dist = {
    "learning_rate": ("log_float", 0.001, 1.0),   # 对数均匀采样
    "max_depth": ("int", 2, 8),                   # 整数均匀采样
}

rand_best = None
rand_score = -float("inf")
rand_history = []
rng = np.random.RandomState(42)
for _ in range(28):
    params = {k: sample(v, rng) for k, v in param_dist.items()}
    score = synthetic_objective(params)
    rand_history.append((params, score))
    if score > rand_score:
        rand_score = score
        rand_best = params

optimizer = SimpleBayesianOptimizer(param_dist, n_initial=5)
bayes_history = []
for _ in range(28):
    params = optimizer.suggest()
    score = synthetic_objective(params)
    optimizer.observe(params, score)
    bayes_history.append((params, score))
bayes_score = max(s for _, s in bayes_history)

print(f"{'Method':<20} {'Best Score':>12} {'Evaluations':>12}")
print("-" * 50)
print(f"{'Grid Search':<20} {grid_score:>12.4f} {len(grid_history):>12}")
print(f"{'Random Search':<20} {rand_score:>12.4f} {len(rand_history):>12}")
print(f"{'Bayesian Opt':<20} {bayes_score:>12.4f} {len(bayes_history):>12}")
~~~

原课对输出的解读（原课参考）：同预算下贝叶斯通常最快找到最好分数，随机比网格覆盖广，网格只在超参数极少且能穷举时占优。

## 五、把代码运行起来：补充入口与检查

（补充）原文缺 `evaluate`、`sample`、`sample_random`、`to_vector`、`norm_cdf`、`norm_pdf`，这里补齐——`evaluate` 假定模型有 `score` 方法；`sample` 支持"取值列表 / ('float',lo,hi) / ('log_float',lo,hi) / ('int',lo,hi)"四种规格：

~~~python
# 本块中文说明：补充的辅助函数——采样、向量化、正态分布与评估。
import itertools
import numpy as np
from scipy.stats import norm as _norm

def evaluate(model, X_val, y_val):
    return model.score(X_val, y_val)              # 需要模型实现score

def sample(spec, rng):
    if isinstance(spec, (list, tuple)) and len(spec) == 3 and isinstance(spec[0], str):
        kind, lo, hi = spec
        if kind == "log_float":                   # 对数均匀：lr、正则用这个
            return float(10 ** rng.uniform(np.log10(lo), np.log10(hi)))
        if kind == "float":                       # 线性均匀
            return float(rng.uniform(lo, hi))
        if kind == "int":                         # 整数均匀（含hi）
            return int(rng.randint(lo, hi + 1))
    if isinstance(spec, list):                    # 离散选项随机选一
        return spec[rng.randint(len(spec))]
    raise TypeError(f"不支持的采样规格: {spec!r}")

def sample_random(search_space, rng=None):
    rng = rng if rng is not None else np.random.RandomState()
    return {k: sample(v, rng) for k, v in search_space.items()}

def to_vector(params):
    # 按字典顺序转数值向量；类别参数需先映射为数值（补充实现的选择）
    return np.array([float(v) for v in params.values()], dtype=float)

norm_cdf = _norm.cdf                              # 标准正态CDF
norm_pdf = _norm.pdf                              # 标准正态密度
~~~

### 6.2 Optuna + 中位数剪枝

剪枝要在 objective 里 `report` 中间值并检查 `should_prune`；`n_startup_trials=10` 保证至少10个完整试验后才开始剪。原课称通常省40~60%算力（原课参考）。注意：此例 `step=0` 只报告一步，实际剪枝要靠多步报告才发挥作用。

~~~python
# 本块中文说明：Optuna 剪枝模式——报告中间结果，落后于中位数即停。
import optuna
from sklearn.model_selection import cross_val_score

def objective(trial):
    params = {
        "learning_rate": trial.suggest_float("lr", 1e-4, 0.5, log=True),
        "max_depth": trial.suggest_int("max_depth", 2, 10),
        "n_estimators": trial.suggest_int("n_estimators", 50, 500),
        "subsample": trial.suggest_float("subsample", 0.5, 1.0),
    }

    model = GradientBoostingRegressor(**params)
    scores = cross_val_score(model, X_train, y_train, cv=3,
                             scoring="neg_mean_squared_error")
    mean_score = -scores.mean()

    trial.report(mean_score, step=0)
    if trial.should_prune():
        raise optuna.TrialPruned()                # 提前终止本试验

    return mean_score

pruner = optuna.pruners.MedianPruner(n_startup_trials=10, n_warmup_steps=5)
study = optuna.create_study(direction="minimize", pruner=pruner)
study.optimize(objective, n_trials=200)
~~~

param_dist = {

search = RandomizedSearchCV(

    param_dist,

inner_cv = GridSearchCV(
    GradientBoostingRegressor(),
    param_grid={
        "learning_rate": [0.01, 0.05, 0.1],
        "max_depth": [2, 3, 5],
        "n_estimators": [50, 100, 200],
    },
    cv=5,
    scoring="neg_mean_squared_error",
)

outer_scores = cross_val_score(
    inner_cv, X, y, cv=5, scoring="neg_mean_squared_error"
)
print(f"Nested CV MSE: {-outer_scores.mean():.4f} +/- {outer_scores.std():.4f}")

## 七、失败模式、原文边界与工程注意

1. 预处理泄漏：在全部数据上拟合缩放器再交叉验证，验证折信息漏进训练。所有预处理放进 `Pipeline`（见[第13课](<13：ML流水线与实验追踪——Pipeline、泄漏防护与记录.md>)），使缩放器只在训练折上拟合。
2. 验证集过拟合：几千次试验等于在验证集上"训练"。最终性能用嵌套CV报告，或留一个从不碰的测试集。
3. 搜索范围过窄：最优值落在搜索空间边界时说明没搜够宽，扩大范围再试。
4. 忽略交互：提升里学习率和树数强交互（小lr需要多树），分开独立调不如一起调。
5. 迭代模型不用早停：树数/轮数设高配早停，把一个维度从搜索空间里拿掉。
6. 原文的效率数字（贝叶斯省2~5倍、Hyperband快10~50倍、剪枝省40~60%）都是条件性经验值（原课参考），取决于目标函数与预算，不是普适保证。
7. `SimpleBayesianOptimizer` 是教学简化：RBF核长度尺度固定为1、先验方差固定为1、观测无噪声项；真实GP实现会学习核参数并建模观测噪声（补充）。
8. `to_vector` 的补充实现只接受数值型参数字典且顺序敏感；类别参数需先做数值映射（补充，原文未给出该函数）。
9. 6.2 剪枝示例中 `trial.report(mean_score, step=0)` 只报告单步，MedianPruner 的威力要在多步报告（如逐epoch）时才能体现；照抄到单步场景几乎不剪（核对，可从API语义直接验证）。
