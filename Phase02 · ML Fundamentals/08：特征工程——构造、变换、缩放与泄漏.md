## 零、初学者先读：同样的数据，为什么换个表示效果差这么多？

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。前置是[第01课](<01：what-is-machine-learning.md>)；文中“距离型算法”的含义可回看[第07课](<07：无监督学习——K-Means、DBSCAN与聚类评估.md>)的 K-Means。

### 0.1 先理解这一课在做什么

给模型“喂饭”前先“切菜”：同样的食材（原始数据），切配方式（特征）决定这顿饭好不好做。算法只能吃到你给它的表示——地址是一串原始文字时，再聪明的模型也用不好它；换成“面积、卧室数”两列数字，简单模型就够了。特征工程就是“切菜”，特征选择就是“把没营养的菜扔掉”。原课的口号“一个好特征抵得上一千条数据”是经验之谈，不是定理，但它指向的事实成立：在传统机器学习里，表示往往比算法更值得花时间。

### 0.2 本课术语先翻成白话

- 特征工程（feature engineering）=把原始数据变成模型好用的列
- 特征选择（feature selection）=扔掉没信号、纯添乱的特征（本课先讲过滤法，[第18课](<18：特征选择——过滤、包裹与嵌入.md>)深入）
- 标准化（standardization / z-score）=减均值、除标准差，变成均值 0 方差 1
- min-max 缩放=线性压到 [0, 1]
- 对数变换=压右偏分布（收入、词频），本课用 log(v+1)
- 分箱（binning）=把连续值切成几档当类别用
- 多项式特征=额外造 x²、x1·x2 等交叉项
- one-hot 编码=每个类别一列 0/1，每行恰好一个 1
- 标签编码（label encoding）=类别映射成整数，会引入假顺序
- 目标编码（target encoding）=类别替换成“该类别的目标均值”，泄漏高风险
- TF-IDF=词频 × 逆文档频率，越独特的词权重越高
- 插补（imputation）=给缺失值填一个估计值
- 数据泄漏（data leakage）=训练时用了预测时拿不到的信息，评估虚高

### 0.3 用小数字走一遍

标准化：`[1, 3]` 的均值是 2、（总体）标准差是 1，标准化后是 `[-1, +1]`。min-max：`[10, 20, 30]` 变成 `[0, 0.5, 1]`。

目标编码与平滑：类别 A 只有 2 行，目标值 0 和 100，朴素均值是 50；全局均值假设 40。用平滑参数 m=10：权重 = 2/(2+10) = 1/6，编码 = (1/6)×50 + (5/6)×40 ≈ 41.7——样本少的类别被拉向全局均值，避免被个别极端值带偏。注意：即使加了平滑，这个均值仍然“看过”了目标值，所以只能在训练集内算（见第七节）。

TF-IDF：两篇文档 `"cat sat"` 和 `"cat ran"`。cat 两篇都出现，IDF = log(2/2) = 0，权重 0——它没有区分度；sat 只出现在第一篇，IDF = log(2/1) ≈ 0.693，TF = 0.5，权重 ≈ 0.347。

以上是用于理解的算例，不是新增的训练或性能实测。

## 一、这一课解决什么问题？

原课的场景：选了算法、训练、调参一周，结果平庸；有人换了组特征，简单逻辑回归就打败了你调好的梯度提升集成。这不是段子——在传统机器学习里，数据的表示常常比算法的选择影响更大。模型只能利用你给它的东西：有“面积、卧室数”的房价模型就是比拿“地址字符串”硬塞的模型好，无论学习器多先进。

特征工程把原始数据变成让模式更容易被找到的表示；特征选择把“只添噪声不添信号”的特征扔掉。两者合起来是传统机器学习中杠杆率最高的活动（原课判断，方向正确，幅度因项目而异）。本课示范数值变换、类别编码、文本特征、缺失值处理与过滤式选择；注意原课标题含 Selection，但选择方法的三大家族（过滤/包裹/嵌入）完整版在[第18课](<18：特征选择——过滤、包裹与嵌入.md>)。

## 二、核心概念与推导

### 2.1 特征流水线总览

原课用流程图表达，转成文字：原始数据 → 缺失值处理 →（数值变换 / 类别编码 / 文本特征并行）→ 特征交互 → 特征选择 → 模型就绪数据。要点是顺序：先处理缺失，再做变换；选择放在最后一步之前。

### 2.2 数值变换

- **缩放**：让各特征处于同一量纲。min-max 映射到 [0,1]：$x'=\dfrac{x-x_{\min}}{x_{\max}-x_{\min}}$；标准化（z-score）：$z=\dfrac{x-\mu}{\sigma}$，变换后均值 0、标准差 1。距离型算法（K-Means、KNN、SVM）需要它。
- **对数变换**：压缩右偏分布（收入、人口、词数），把乘法关系变加法。本课用 $\log(v+1)$ 以兼容 0。
- **分箱**：连续值切成档。特征与目标的关系是非线性但呈台阶状时有用（如年龄段）。
- **多项式特征**：造 $x^2$、$x^3$、$x_1x_2$ 项，让线性模型能拟合非线性关系，代价是特征数膨胀。

### 2.3 类别编码

- **one-hot**：每个类别一列二值列（is_red、is_blue、is_green）。低基数好用，类别一多就爆炸。
- **标签编码**：red=0、blue=1、green=2。引入假顺序（模型可能推出 green > blue > red），只适合按单个值切分的树模型。
- **目标编码**：类别替换为该类别的目标均值，带平滑（$m$ 为平滑参数）：

$$\text{enc}(c)=\frac{n_c}{n_c+m}\cdot\bar{y}_c+\frac{m}{n_c+m}\cdot\bar{y}$$

威力大、泄漏风险也大：必须只在训练数据上算、再套用到测试数据（原课原文强调 Must be computed only on training data）。

### 2.4 文本特征

**词计数（count vectorizer）**：文档变“每个词出现几次”的向量。**TF-IDF** 在计数上按“独特度”加权：

$$\text{TF}(w,d)=\frac{\text{count}(w,d)}{|d|},\qquad \text{IDF}(w)=\log\frac{N}{\text{df}(w)},\qquad \text{TF-IDF}=\text{TF}\times\text{IDF}$$

常见词（the）IDF 低，罕见且有区分度的词 IDF 高。本课实现用自然对数，且不加平滑——一个出现在所有文档里的词 IDF 恰为 0（核对：与 0.3 的算例一致）。

### 2.5 缺失值

- 删行：只在缺失稀少且随机时用。
- 均值/中位数插补：简单、保住特征中心（中位数对离群点更稳），但压缩方差、把一堆填充值堆成一个尖峰，分布形状变了。
- 众数插补：类别特征用。
- 指示列：先加一列“这里原来缺失吗”再插补——缺失本身可能就是信息。
- 前向/后向填充：时间序列用。

### 2.6 特征交互

有时规律藏在组合里：身高体重单独都不如 $\text{BMI}=\text{weight}/\text{height}^2$ 好用。交互项会让特征空间快速膨胀，用领域知识挑，不要盲目全乘。

### 2.7 特征选择：本课的过滤式入门

特征多不等于好：无关特征添噪声、拖慢训练、带来过拟合机会。本课实现的是**过滤法（filter）**——不看模型、按统计分数独立打分：方差阈值（几乎不变的列删掉）、相关性（高度相关的冗余列删一个）、互信息（知道特征后对目标的不确定度下降多少）。**包裹法（wrapper）**（RFE 等）与**嵌入法（embedded）**（L1、树重要性）在[第18课](<18：特征选择——过滤、包裹与嵌入.md>)完整展开。原课结论方向正确：10 个好特征通常胜过“10 个好特征 + 90 个噪声特征”，因为噪声特征给了模型在训练集上过拟合的机会。

### 2.8 用一个小例子把概念串起来（补充）

一套 200 行的房价数据：面积（500–5000，右偏，有 5% 缺失）、房龄（0–50，8% 缺失）、社区（3 类）、有无泳池。走一遍流水线：先用指示列记下缺失、中位数插补面积；面积标准化、房龄 min-max；社区 one-hot 成 3 列；要不要加“面积×卧室数”交互由你判断；最后用方差阈值与相关性检查有没有列该删。每一步都问同一句话：这步用到的统计量（中位数、均值、min/max）将来在预测时拿得到吗？拿不到就是泄漏，必须只在训练集内算。

### 4.1 数值变换从零实现

五个纯函数：`min_max_scale` 全列同值时返回全 0；`standardize` 用总体标准差（除 n 不是 n−1）；`log_transform` 用 log(v+1)；`bin_values` 等宽分箱、右端点并入最后一箱；`polynomial_features` 在原值后追加平方项与两两乘积。注意：`polynomial_features` 的 `degree` 参数只在“≥2 与否”上起作用，degree=3 与 degree=2 输出完全相同——它不会生成三次项（核对：代码只写了平方与交叉项，保留原样，见第七节）。

~~~python
# 本块中文说明：数值列的五种基础变换。
import math


def min_max_scale(values):
    min_val = min(values)
    max_val = max(values)
    if max_val == min_val:
        return [0.0] * len(values)
    return [(v - min_val) / (max_val - min_val) for v in values]


def standardize(values):
    n = len(values)
    mean = sum(values) / n
    variance = sum((v - mean) ** 2 for v in values) / n
    std = math.sqrt(variance) if variance > 0 else 1.0
    return [(v - mean) / std for v in values]


def log_transform(values):
    return [math.log(v + 1) for v in values]    # +1 让 0 也能取对数


def bin_values(values, n_bins=5):
    min_val = min(values)
    max_val = max(values)
    bin_width = (max_val - min_val) / n_bins
    if bin_width == 0:
        return [0] * len(values)
    result = []
    for v in values:
        bin_idx = int((v - min_val) / bin_width)
        bin_idx = min(bin_idx, n_bins - 1)     # 右端点并入最后一箱
        result.append(bin_idx)
    return result


def polynomial_features(row, degree=2):
    n = len(row)
    result = list(row)
    if degree >= 2:
        for i in range(n):
            result.append(row[i] ** 2)          # 各维平方
        for i in range(n):
            for j in range(i + 1, n):
                result.append(row[i] * row[j])  # 两两交叉项
    return result
~~~

### 4.2 类别编码从零实现

`one_hot_encode` 类别按 `sorted(set())` 排序建列；`label_encode` 同一套映射但输出整数；`target_encode` 按类别累加目标值，用 0.3 的平滑公式混合类别均值与全局均值。注意：这个函数对传入的整份 `feature_values` / `target_values` 计算——调用时若把训练+测试一起传进去就是泄漏（原课概念部分自己警告了，见第七节）。

~~~python
# 本块中文说明：one-hot、标签编码与带平滑的目标编码。
def one_hot_encode(values):
    categories = sorted(set(values))
    cat_to_idx = {cat: i for i, cat in enumerate(categories)}
    n_cats = len(categories)

    encoded = []
    for v in values:
        row = [0] * n_cats
        row[cat_to_idx[v]] = 1
        encoded.append(row)

    return encoded, categories


def label_encode(values):
    categories = sorted(set(values))
    cat_to_int = {cat: i for i, cat in enumerate(categories)}
    return [cat_to_int[v] for v in values], cat_to_int


def target_encode(feature_values, target_values, smoothing=10):
    global_mean = sum(target_values) / len(target_values)

    category_stats = {}
    for feat, target in zip(feature_values, target_values):
        if feat not in category_stats:
            category_stats[feat] = {"sum": 0.0, "count": 0}
        category_stats[feat]["sum"] += target
        category_stats[feat]["count"] += 1

    encoding = {}
    for cat, stats in category_stats.items():
        cat_mean = stats["sum"] / stats["count"]
        # 样本少的类别被拉向全局均值（平滑）
        weight = stats["count"] / (stats["count"] + smoothing)
        encoding[cat] = weight * cat_mean + (1 - weight) * global_mean

    return [encoding[v] for v in feature_values], encoding
~~~

### 4.3 文本特征从零实现

`count_vectorize` 两遍扫描：先建词表（首现顺序编号），再逐文档计数。`tfidf` 额外统计文档频率（每篇去重后累加），TF 用“词出现次数 / 该文档总词数”，IDF 用自然对数、无平滑。注意 `doc_freq` 的统计先建 `seen` 集合去重，一篇文档里同一个词只记一次。

~~~python
# 本块中文说明：词计数与 TF-IDF 向量化。
def count_vectorize(documents):
    vocab = {}
    idx = 0
    for doc in documents:
        for word in doc.lower().split():
            if word not in vocab:
                vocab[word] = idx
                idx += 1

    vectors = []
    for doc in documents:
        vec = [0] * len(vocab)
        for word in doc.lower().split():
            vec[vocab[word]] += 1
        vectors.append(vec)

    return vectors, vocab


def tfidf(documents):
    n_docs = len(documents)

    vocab = {}
    idx = 0
    for doc in documents:
        for word in doc.lower().split():
            if word not in vocab:
                vocab[word] = idx
                idx += 1

    # 文档频率：每篇文档内先去重再计数
    doc_freq = {}
    for doc in documents:
        seen = set()
        for word in doc.lower().split():
            if word not in seen:
                doc_freq[word] = doc_freq.get(word, 0) + 1
                seen.add(word)

    vectors = []
    for doc in documents:
        words = doc.lower().split()
        word_count = len(words)
        tf_map = {}
        for word in words:
            tf_map[word] = tf_map.get(word, 0) + 1

        vec = [0.0] * len(vocab)
        for word, count in tf_map.items():
            tf = count / word_count
            idf = math.log(n_docs / doc_freq[word])
            vec[vocab[word]] = tf * idf
        vectors.append(vec)

    return vectors, vocab
~~~

### 4.4 缺失值插补从零实现

四个函数：均值/中位数（偶数个取中间两数的平均）/众数插补，外加 `add_missing_indicator` 生成“原来缺吗”的 0/1 列。约定用 `None` 表示缺失；全空列时均值、中位数填 0，众数原样返回。

~~~python
# 本块中文说明：均值/中位数/众数插补与缺失指示列。
def impute_mean(values):
    present = [v for v in values if v is not None]
    if not present:
        return [0.0] * len(values), 0.0
    mean = sum(present) / len(present)
    return [v if v is not None else mean for v in values], mean


def impute_median(values):
    present = sorted(v for v in values if v is not None)
    if not present:
        return [0.0] * len(values), 0.0
    n = len(present)
    if n % 2 == 0:
        median = (present[n // 2 - 1] + present[n // 2]) / 2
    else:
        median = present[n // 2]
    return [v if v is not None else median for v in values], median


def impute_mode(values):
    present = [v for v in values if v is not None]
    if not present:
        return values, None
    counts = {}
    for v in present:
        counts[v] = counts.get(v, 0) + 1
    mode = max(counts, key=counts.get)
    return [v if v is not None else mode for v in values], mode


def add_missing_indicator(values):
    return [0 if v is not None else 1 for v in values]
~~~

### 4.5 过滤式特征选择从零实现

`correlation` 算皮尔逊相关（分母为 0 时返回 0）；`mutual_information` 把连续特征分箱后按 MI 公式累加；`variance_threshold` 逐列算总体方差、保留不低于阈值的列号；`remove_correlated` 从前往后扫，相关系数绝对值 ≥ 阈值的后者被删（先到者留下）。

~~~python
# 本块中文说明：相关性、互信息、方差阈值与冗余列过滤。
def correlation(x, y):
    n = len(x)
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    cov = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y)) / n
    std_x = math.sqrt(sum((xi - mean_x) ** 2 for xi in x) / n)
    std_y = math.sqrt(sum((yi - mean_y) ** 2 for yi in y) / n)
    if std_x == 0 or std_y == 0:
        return 0.0
    return cov / (std_x * std_y)


def mutual_information(feature, target, n_bins=10):
    feat_min = min(feature)
    feat_max = max(feature)
    bin_width = (feat_max - feat_min) / n_bins if feat_max != feat_min else 1.0
    feat_binned = [
        min(int((f - feat_min) / bin_width), n_bins - 1) for f in feature
    ]

    n = len(feature)
    target_classes = sorted(set(target))

    feat_bins = sorted(set(feat_binned))
    p_feat = {}
    for b in feat_bins:
        p_feat[b] = feat_binned.count(b) / n

    p_target = {}
    for t in target_classes:
        p_target[t] = target.count(t) / n

    mi = 0.0
    for b in feat_bins:
        for t in target_classes:
            joint_count = sum(
                1 for fb, tv in zip(feat_binned, target) if fb == b and tv == t
            )
            p_joint = joint_count / n
            if p_joint > 0:
                mi += p_joint * math.log(p_joint / (p_feat[b] * p_target[t]))

    return mi


def variance_threshold(features, threshold=0.01):
    n_features = len(features[0])
    n_samples = len(features)
    selected = []

    for j in range(n_features):
        col = [features[i][j] for i in range(n_samples)]
        mean = sum(col) / n_samples
        var = sum((v - mean) ** 2 for v in col) / n_samples
        if var >= threshold:
            selected.append(j)

    return selected


def remove_correlated(features, threshold=0.9):
    n_features = len(features[0])
    n_samples = len(features)

    to_remove = set()
    for i in range(n_features):
        if i in to_remove:
            continue
        col_i = [features[r][i] for r in range(n_samples)]
        for j in range(i + 1, n_features):
            if j in to_remove:
                continue
            col_j = [features[r][j] for r in range(n_samples)]
            corr = abs(correlation(col_i, col_j))
            if corr >= threshold:
                to_remove.add(j)      # 与已保留列高度相关的后者被删

    return [i for i in range(n_features) if i not in to_remove]
~~~

## 七、失败模式、原文边界与工程注意

1. 最大陷阱是泄漏：本课演示在划分前对**全量数据**做插补、缩放、目标编码（`make_housing_data` 后直接算全列统计）。这是演示简化；原课概念部分自己写明 target encoding "must be computed only on training data"。真实流程：先划分，再只 fit 训练集。
2. `target_encode` 即使加平滑也只缓解不消除泄漏；更严谨的是练习 2 的留一法，或 sklearn 的 `TargetEncoder`（内含折内拟合）。
3. one-hot 遇到高基数类别（邮编、用户 ID）会维度爆炸；考虑合并稀有类别或用目标编码。
4. `label_encode` 的整数会被线性/距离模型当作真实大小关系；只用于树模型。
5. `log_transform` 要求 v > −1；负数或大量 −1 以下会抛异常（MathDomainError 的变体）。
6. 等宽分箱对离群点敏感——一个极大值会把绝大多数点挤进同一箱；离群多时考虑分位数分箱。
7. `polynomial_features` 的 `degree` 名不副实：degree=3 与 degree=2 输出相同（核对：代码只追加平方与两两乘积）。要真正高次项需自己扩展。
8. 本课 TF-IDF 用自然对数且无平滑：出现在所有文档的词 IDF=0 属预期行为，不是 bug；sklearn 默认 `smooth_idf=True` 数值会不同。
9. 演示里 `binary_prices` 用全量价格均值做阈值、MI/相关也在全量上算——作为探索可以，进入建模就是泄漏；选择要在训练折内做（链接[第18课](<18：特征选择——过滤、包裹与嵌入.md>)）。
10. 原课“一个好特征抵得上一千条数据”是格言不是定量结论；“最高杠杆活动”是经验判断，幅度因项目而异。
