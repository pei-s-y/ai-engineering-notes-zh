## 1. 这节课在解决什么问题？

面对“每行一个样本、每列一个特征”的表格数据，我们希望根据特征预测类别或连续数值。

- 分类：根据特征判断样本属于哪一类，例如是否发生故障。
- 回归：根据特征预测一个数值，例如温度、能耗。
- 决策树：学习一串判断条件，沿着条件走到叶节点得到预测。
- 随机森林：训练多棵不同的树，再合并它们的预测，通常比单树更稳定。

记住：树的判断规则来自训练数据，不是人为提前写好的完整规则；预测时只是使用已经学到的规则。

## 2. 决策树的结构与训练过程

内部节点提出一个问题：`某个特征 <= 某个阈值？`。满足条件走左边，否则走右边。叶节点不再提问，直接输出预测值。

本课的轴对齐划分一次只比较一个特征，因此二维空间中的区域通常呈矩形，而不是直接学习一条斜线或圆形边界。树可以通过多次划分逼近复杂边界。

训练的核心流程：

```text
当前节点的数据
    ↓
是否满足停止条件？── 是 → 创建叶节点
    │ 否
    ↓
枚举候选特征与阈值 → 选改善量最大的规则
    ↓
把数据分成左右两组 → 对两组分别重复以上过程
```

如何枚举阈值？先对某个特征的不同取值排序，再尝试相邻值的中点。例如 `[1, 2, 4]` 的候选阈值是 `1.5、3`。同一间隙内的其他阈值不会改变训练样本的分组。

这是“贪心算法”：每次选择当前节点最好的划分，不保证整棵树的全局结构最优。

## 3. 分类树：如何判断一个划分好不好？

### 3.1 Gini 不纯度

设当前节点第 k 类的比例为 p_k：

$$Gini(S)=1-\sum_k p_k^2$$

数值越小，类别越集中。全是同类时为 0；二分类各占一半时为 0.5。K 类均匀分布时最大为 `1 - 1/K`，所以多分类的最大值不一定是 0.5。

例：6 只猫、4 只狗，Gini = `1 - 0.6² - 0.4² = 0.48`。

### 3.2 熵 Entropy

$$H(S)=-\sum_k p_k\log_2p_k$$

纯节点的熵为 0；二分类各占一半时为 1。概率为 0 的项按 0 处理，不直接计算 `log₂(0)`。

Gini 与熵都衡量类别混杂程度，但数值尺度不同，不应该拿两者的原始数值直接比较“谁更好”。它们经常产生接近的效果，但不保证划分、树结构或预测完全相同。

### 3.3 划分改善量：必须加权

设 I 表示选中的不纯度指标，n 为父节点样本数，n_L、n_R 为两侧样本数：

$$Gain=I(S)-\left(\frac{n_L}{n}I(S_L)+\frac{n_R}{n}I(S_R)\right)$$

不能对两个子节点的不纯度直接取简单平均，否则样本多和样本少的节点被错误地视为同等重要。

手算例：`X = [[1], [2], [3], [4]]`，`y = [A, A, B, B]`。

- 父节点 Gini = 0.5。
- 阈值 2.5 把样本分为 `[A, A]` 和 `[B, B]`，两侧 Gini 都为 0。
- Gain = `0.5 - (2/4 × 0 + 2/4 × 0) = 0.5`，这是一次完全分离类别的划分。

严格地说，熵减少量常称“信息增益”；本课 `information_gain()` 也用来计算 Gini 减少量，理解公式比纠结函数名称更重要。

## 4. 树为什么需要限制生长？

浅树可能遗漏规律，出现欠拟合；过深的树可能把噪声也记住，出现过拟合。训练准确率很高，不等于新数据上表现很好。

代码中的主要控制条件：

| 条件或参数 | 含义 |
|---|---|
| 节点目标值全部相同 | 已经纯了，直接停止 |
| `max_depth` | 限制树的最大深度；根节点深度为 0 |
| `min_samples_split` | 当前节点至少多少样本才允许尝试分裂 |
| `min_samples_leaf` | 分裂后的左右子节点各至少保留多少样本 |
| 最佳 Gain 不大于 0 | 没有改善，不继续分裂 |

`min_samples_split` 与 `min_samples_leaf` 不是同一个参数。例如当前有 10 条样本，可以满足前者，却因候选划分为 9 条和 1 条而不满足后者。

这些属于预剪枝。课程还介绍了后剪枝：先长出树，再删减不值得保留的子树。本课完整代码没有实现后剪枝，也没有可调的最小 Gain 或最大叶节点数。

真实项目中应通过验证集或交叉验证选择深度等参数，最终测试集用于评估，避免反复看测试分数调参。

## 5. 回归树：结构相同，评价方式不同

分类树的叶节点输出多数类；回归树的叶节点输出该叶子内目标值的均值。均值能使节点内平方误差最小。

回归划分使用方差减少量：

$$VR=Var(S)-\left(\frac{n_L}{n}Var(S_L)+\frac{n_R}{n}Var(S_R)\right)$$

本代码的 `Var(S)` 是 `Σ(y_i - 均值)² / n`，不是除以 `n-1` 的无偏样本方差。

回归评估使用 MSE：`预测误差的平方，再取平均`，越小越好。单棵回归树在每个叶区域都输出同一个数，因此是分段常数模型。森林的平均输出可能看起来更平滑，但不保证连续。

注意：代码的回归示例实际生成 `y = x × sin(x) + 噪声`；课后练习要求的 `y = sin(x) + 噪声` 是另一种数据，不要混淆。

## 6. 随机森林的两个“随机”

### 6.1 样本随机：Bootstrap

从 n 条训练样本中有放回地抽取 n 次，形成一棵树的训练数据。每次抽取允许重复，因此“抽了 n 次”不等于“所有样本各抽一次”。

某条样本一次也没被抽中的概率是 `(1 - 1/n)^n`，大样本时约为 36.8%；被抽中过的不同样本约占 63.2%。未被该树抽中的样本称为袋外样本（OOB）。本代码没有实现 OOB 评分。

### 6.2 特征随机：每个节点重新抽取候选特征

不是每棵树永久固定一组特征，而是在寻找每个节点的划分时重新抽取。

本代码 `max_features="sqrt"` 表示每个节点随机考虑 `max(1, floor(√特征数))` 个特征。不同树不容易都依赖同一个强特征，预测错误的相关性通常会降低。

本代码的集成方式：分类采用多数投票，回归采用均值。多样化的树进行集成，主要帮助降低预测方差；不能理解为偏差一定不变，也不能保证树越多，某个测试集的准确率就越高。

课程写的“回归默认使用特征数的 1/3”不是所有实现的通用默认。本代码分类、回归都默认 `sqrt`；当前 scikit-learn 的 `RandomForestRegressor` 默认 `max_features=1.0`，表示考虑全部特征。[官方参数说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html)

## 7. 特征重要性：模型用了什么，不代表什么导致了结果

### MDI：训练时的不纯度减少贡献

对某个特征，累加所有使用它进行划分的节点贡献：

`节点样本数 / 全树训练样本数 × 本次不纯度（或方差）减少量`

代码先得到每棵树的归一化重要性，再汇总森林。它能帮助理解模型使用了哪些特征，但偏好取值种类多、可尝试阈值多的特征，噪声特征也可能得到分数。

### 置换重要性：打乱一个特征，看性能下降多少

先在独立验证/测试数据上计算基准分数，再只打乱一个特征列，保持其他列和真实标签不变，重新评分。

例如准确率从 0.90 降到 0.70，该特征的这次置换重要性为 0.20。应重复置换以观察波动；如果使用 MSE，则用“打乱后 MSE - 基准 MSE”表达误差增加。

置换重要性依赖已训练的模型、数据集和评分指标。高度相关的特征可能彼此替代，让各自的分数都显得低；重要性也不是因果证据。[官方说明](https://scikit-learn.org/stable/modules/permutation_importance.html)

本课代码只实现 MDI，置换重要性留作练习，不要把打印的 `feature_importances()` 当成置换结果。

## 8. 对照代码时，优先看哪些函数？

1. `gini_impurity()`、`entropy()`：先弄清字典计数和概率计算。
2. `information_gain()`：理解左右节点为什么要加权。
3. `DecisionTree._best_split()`：候选特征、候选中点、比较 Gain。
4. `DecisionTree._build()`：停止条件和递归，是核心。
5. `_make_leaf()`、`_predict_one()`：分类/回归如何输出，以及预测时如何走树。
6. `RandomForest.fit()`、`predict()`：bootstrap、训练多树、投票或平均。
7. `feature_importances()`：将重要性公式和代码累加过程对应起来。

Python 重点：字典 `.get()`、`set` 去重、列表推导式、`zip`、函数作为变量、类的实例属性和递归。能解释这些用法，就能逐步读懂核心实现，不必先掌握所有 Python 语法。

完整代码包含八组演示：不纯度、划分增益、分类树深度、Gini 对比熵、森林树数量、特征重要性、回归、稳定性。运行后不要只看最终分数，要看“本实验改变了什么、保持了什么、用什么指标比较”。

## 9. 原课与代码中需要注意的边界

- **树不一定能直接吃类别字符串。** 这份实现只处理数值阈值，字符串特征需要合适的编码或换用支持原生类别特征的实现。scikit-learn 决策树也不提供原生类别特征支持。[官方说明](https://scikit-learn.org/stable/modules/tree.html)
- **不一定需要标准化，不等于不需要预处理。** 类别编码、缺失值、数据泄漏仍要处理；这份教学代码没有缺失值处理。
- **“表格数据上树总胜过神经网络”过于绝对。** 树模型是很重要的强基线，实际优劣要由具体数据和规范评估决定。
- **更多树不保证测试准确率单调上升。** 原版打印语和练习中的绝对描述不能当作数学保证，分数有小幅下降也正常。
- **稳定性演示存在泄漏风险。** `demo_single_tree_vs_forest()` 先对全部原始数据有放回采样，再划分训练/测试，重复的原始样本可能进入两边。严谨做法是先留出固定独立测试集，只重采样训练集。
- **随机种子是为了复现，不是提高性能。** 本实现使用全局 `random.seed()`，各函数之间会影响同一随机序列；更严谨的项目可使用独立随机数对象。
- **教学类不等于库的全部接口。** 原版 `fit()` 不返回 `self`，不适合写 `model = DecisionTree().fit(...)`；先创建模型，再单独调用训练。
- **划分函数的返回顺序容易用错。** 本课为 `X_train, y_train, X_test, y_test`；sklearn 常用顺序为 `X_train, X_test, y_train, y_test`。

课程的 Use It 部分演示 sklearn：`n_estimators` 对应本课的 `n_trees`；sklearn 森林的重要性是属性 `feature_importances_`，本课森林使用方法 `feature_importances()`。实际使用时以各自 API 为准。

Ship It 部分提供解释树规则的提示词模板。它适合辅助转述模型，但仅凭树结构不能可靠判断是否泄漏；还需要数据来源、划分方式和预处理流程的信息。

按原课程顺序保留五项练习，你可以自己安排：

1. 二维三分类数据，比较深度 2 与 10，画出矩形决策区域。
2. 回归数据 `sin(x) + 噪声`，画出真实曲线和树的分段常数预测。
3. 比较 1、5、10、50、200 棵树，画训练/测试准确率；如实记录，不强求单调增加。
4. 在五份不同数据上比较 Gini 与熵，记录效果与树深度。
5. 实现置换重要性，与 MDI 比较高基数噪声特征；这是观察偏差的实验，不保证每次都会把噪声排到前面。

一句话回顾：**决策树靠局部划分降低节点误差，随机森林靠样本和特征的随机化增加多样性，再通过集成改善稳定性；判断效果始终要回到独立数据上的规范评估。**
