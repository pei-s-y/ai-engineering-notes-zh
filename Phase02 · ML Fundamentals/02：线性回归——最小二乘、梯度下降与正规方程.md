## 零、初学者先读：怎样找到那条“最好的直线”

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。什么是“模型、训练、参数”见[第01课](<01：what-is-machine-learning.md>)；本课是整个 ML 训练循环的第一个完整样板。

### 0.1 先理解这一课在做什么

给你一堆（面积，房价）的点，想预测新房子卖多少钱：拿一把直尺在散点图上画一条最贴近所有点的直线，以后新面积一代入直线就得到预测。线性回归就是让程序自己“画”这条线。更重要的是，它第一次完整走了一遍所有机器学习算法都用的循环：定义模型 → 定义“有多差”的损失 → 用优化器调参数。这里学会了，后面每课都能认出来。

### 0.2 本课术语先翻成白话

- 权重 w（weight）=直线的斜率：x 每增加 1，预测增加多少
- 偏置 b（bias）=直线的截距：x=0 时预测是多少
- MSE（均方误差，Mean Squared Error）=“预测减真实”的平方再取平均，越小越好
- 损失函数（cost function）=把“模型有多差”写成一个数
- 梯度（gradient）=损失对参数的导数，指出上坡方向
- 梯度下降（gradient descent）=反复沿负梯度方向小步更新参数
- 学习率（learning rate）=每一步走多远，典型 0.01 / 0.001 / 0.0001
- epoch（轮）=把全部训练数据完整过一遍并更新一次参数
- 正规方程（normal equation）=不用迭代、一步算出最优参数的闭式公式
- R²（决定系数）=与 y 的尺度无关的拟合优度：1 完美，0 等于只会预测均值，可为负
- 标准化（standardization）=每个特征减均值、除标准差，让数量级一致
- Ridge 回归=L2 正则化的线性回归：损失里加上“权重平方和”的惩罚
- 过拟合（overfitting）=训练数据记得太死，换批新数据就预测差

### 0.3 用小数字走一遍

三个训练点 (1,3)、(2,5)、(3,7)，真实关系是 y=2x+1。

先看损失：初始 w=0、b=0 时预测全为 0，误差是 3、5、7，MSE=(9+25+49)/3≈27.67。梯度 dw=(2/3)×(3×1+5×2+7×3)=68/3≈22.67，db=(2/3)×(3+5+7)=10。取学习率 0.01 走一步：w≈0.227、b=0.1，损失下降。反复做这件事就是梯度下降。

再用正规方程一步到位：x̄=2、ȳ=5，分子 =(-1)×(-2)+0×0+1×2=4，分母 =1+0+1=2，所以 w=4/2=2，b=5−2×2=1。因为三个点恰好在一条直线上，R²=1。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.4 怎样连接到正文代码

按顺序读：先 `LinearRegression` 类（predict → compute_cost → compute_gradients → fit → r_squared），这是主菜；再看 `LinearRegressionNormal` 的闭式解；然后 `MultipleLinearRegression` 与标准化函数（多个特征的推广）；`PolynomialRegression` 的 make_features（把曲线问题变回直线问题）；最后 `RidgeRegression`（加惩罚项）。核心数据结构只有普通 Python 列表：`X`（特征）、`y`（标签）、`weights`（参数列表）、`cost_history`（损失记录）。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么用“平方误差”而不是“误差绝对值”？

**参考答案：** 平方放大了大误差（误差 10 的惩罚是误差 1 的 100 倍），且处处光滑可导，求导和优化都简单；绝对值在 0 点不可导，优化更麻烦。

**问题2：** 学习率设成 10 会发生什么？

**参考答案：** 每步走得太远，可能越过碗底跳到对面更高的地方，损失不降反升甚至发散；太小则收敛极慢。所以要从 0.01、0.001 这类值开始试。

**问题3：** 概念里的矩阵公式和第四节的 `LinearRegressionNormal` 是同一个东西吗？

**参考答案：** 数学上等价但形式不同：矩阵公式 $w=(X^TX)^{-1}X^Ty$ 是通式，原课代码实现的是单特征情形的协方差闭式解（先算 w 再算 b），避免了矩阵求逆；两者在单特征时给出相同结果。

## 一、这一课解决什么问题？

你有历史房价数据（面积→价格），想给新面积一个预测。肉眼看散点图可以估，但需要一条能代入任意 x 的公式。线性回归给出这条直线，并借此引入完整的 ML 训练循环：模型、损失函数、优化。原课强调它不只是玩具——需求预测、A/B 测试分析、金融建模都在用，也是所有回归任务的基线（baseline）。上一课（[第01课](<01：what-is-machine-learning.md>)）讲了概念框架，本课把“训练”两个字落到具体数字上。

## 二、核心概念与推导

### 2.1 模型：从直线到超平面

假设输入与输出是线性关系：$y = wx + b$。$w$ 是斜率（x 增加 1 时 y 变化多少），$b$ 是截距（x=0 时的 y）。多个特征时推广为 $y = w_1 x_1 + \cdots + w_n x_n + b$，向量形式 $y = w^\top x + b$。目标：找一组 $w, b$，让预测值在所有训练样本上尽量接近真实值。

### 2.2 损失函数：MSE

$$\text{MSE} = \frac{1}{n} \sum (\hat{y} - y)^2$$

为什么平方？一是大误差被放大惩罚（误差 10 的代价是误差 1 的 100 倍）；二是平方函数处处光滑可导，优化容易。直觉补充：MSE 定义了一个以参数为坐标的“曲面”，单特征时像一只碗（凸抛物面），碗底就是最优参数，训练就是找碗底。

### 2.3 梯度下降：沿坡往下走

对 $\hat{y}=wx+b$，两个偏导数是：

$$\frac{\partial \text{MSE}}{\partial w} = \frac{2}{n}\sum(\hat{y}-y)\,x,\qquad \frac{\partial \text{MSE}}{\partial b} = \frac{2}{n}\sum(\hat{y}-y)$$

更新规则：$w \leftarrow w - \text{lr}\cdot\partial\text{MSE}/\partial w$，$b$ 同理。学习率太大越过碗底发散，太小收敛极慢。梯度告诉我们两件事：往哪个方向调、调多少。

### 2.4 正规方程：一步求解

线性回归有闭式解：$w = (X^\top X)^{-1} X^\top y$，一次矩阵运算直接得到最优权重，小数据集上完美。但矩阵求逆对特征数的复杂度是 $O(\text{特征数}^3)$，特征上千或样本上百万时，迭代式的梯度下降反而更实用。

### 2.5 多元线性回归与特征标准化

多特征时 MSE 和梯度下降形式不变，只是拟合的是超平面而非直线。此时特征尺度很关键：一个特征取值 0～1、另一个 0～1000000，损失曲面被拉得细长，梯度下降收敛困难。做法是训练前标准化（减均值、除标准差）。

### 2.6 多项式回归：用线性模型拟合曲线

关系不是直线时，可以造特征：$y = w_1 x + w_2 x^2 + w_3 x^3 + b$。它仍是“线性”回归，因为模型对权重 $w_1,w_2,w_3$ 是线性的，非线性只出现在输入上。次数越高拟合能力越强，但风险过拟合：10 个点的数据集上，10 次多项式能穿过每个点，对新数据预测很差。

### 2.7 R²：与尺度无关的拟合优度

$$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}}$$

其中 $SS_{\text{res}}=\sum(y-\hat{y})^2$ 是残差平方和，$SS_{\text{tot}}=\sum(y-\bar{y})^2$ 是对均值的偏离平方和。$R^2=1$ 完美；$R^2=0$ 与“永远预测均值”一样差；$R^2<0$ 比预测均值还差（可能，且没有下界）。

### 2.8 正则化预览：Ridge 回归

特征很多时模型可能靠大权重过拟合。Ridge（L2 正则化）在损失上加惩罚：

$$\text{Cost} = \text{MSE} + \lambda \sum_i w_i^2$$

$\lambda$ 越大权重被压得越小、正则越强。原课在此只做预览，细节在后续课展开。

### 2.9 用一个小例子把概念串起来（补充）

取 0.3 节的三个点 (1,3)、(2,5)、(3,7)。初始 w=b=0：MSE≈27.67，dw≈22.67、db=10，一步 lr=0.01 后 w≈0.227、b=0.1；这就是 `fit()` 循环里每个 epoch 做的事。用闭式解：x̄=2、ȳ=5，w=4/2=2、b=1，一步得到真值。再算 R²：残差全为 0，$R^2=1-0/SS_{\text{tot}}=1$。三个视角（梯度、闭式、评价）在同一组数字上对上了，读代码时把每个函数对应回这三个视角即可。

### 4.2 第 2 步：梯度下降实现线性回归

这个类是全课的核心样板。`compute_gradients` 就是 2.3 节两个公式；`fit` 每个 epoch 用全量数据算一次梯度再更新（批量梯度下降）；`r_squared` 是 2.7 节公式。注意演示用的学习率是 0.005，不是类默认的 0.01。

~~~python
# 本块中文说明：从零实现批量梯度下降训练的一维线性回归。
class LinearRegression:
    def __init__(self, learning_rate=0.01):
        self.w = 0.0
        self.b = 0.0
        self.lr = learning_rate
        self.cost_history = []

    def predict(self, X):
        return [self.w * x + self.b for x in X]

    def compute_cost(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        cost = sum((pred - actual) ** 2 for pred, actual in zip(predictions, y)) / n
        return cost

    def compute_gradients(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        dw = (2 / n) * sum((pred - actual) * x for pred, actual, x in zip(predictions, y, X))
        db = (2 / n) * sum(pred - actual for pred, actual in zip(predictions, y))
        return dw, db

    def fit(self, X, y, epochs=1000, print_every=200):
        for epoch in range(epochs):
            dw, db = self.compute_gradients(X, y)
            self.w -= self.lr * dw
            self.b -= self.lr * db
            cost = self.compute_cost(X, y)
            self.cost_history.append(cost)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f} | w: {self.w:.4f} | b: {self.b:.4f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


print("=== Training Linear Regression (Gradient Descent) ===")
model = LinearRegression(learning_rate=0.005)
model.fit(X, y, epochs=1000, print_every=200)
print(f"\nLearned: y = {model.w:.4f}x + {model.b:.4f}")
print(f"True:    y = {TRUE_W}x + {TRUE_B}")
print(f"R-squared: {model.r_squared(X, y):.4f}")
~~~

学到的 w 应接近 3、b 接近 7（原课参考），具体数值依赖随机数据，不是本机实测。

### 4.3 第 3 步：正规方程（闭式解）

不用迭代一步求解。核对：本类实现的是单特征最小二乘的协方差公式（w=Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²，b=ȳ−w·x̄），与 2.4 节的矩阵公式在数学上等价，但不是“求矩阵逆”的代码化；矩阵求逆的说法只在概念部分成立。

~~~python
# 本块中文说明：单特征情形的最小二乘闭式解，一次算出最优参数。
class LinearRegressionNormal:
    def __init__(self):
        self.w = 0.0
        self.b = 0.0

    def fit(self, X, y):
        n = len(X)
        x_mean = sum(X) / n
        y_mean = sum(y) / n
        numerator = sum((X[i] - x_mean) * (y[i] - y_mean) for i in range(n))
        denominator = sum((X[i] - x_mean) ** 2 for i in range(n))
        self.w = numerator / denominator
        self.b = y_mean - self.w * x_mean
        return self

    def predict(self, X):
        return [self.w * x + self.b for x in X]

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


print("\n=== Normal Equation (Closed-Form) ===")
model_normal = LinearRegressionNormal()
model_normal.fit(X, y)
print(f"Learned: y = {model_normal.w:.4f}x + {model_normal.b:.4f}")
print(f"R-squared: {model_normal.r_squared(X, y):.4f}")
~~~

在同一份数据上，它与 4.2 训练足够轮数后的结果应基本一致（核对：两者最小化同一个 MSE，凸问题最优解唯一）。

### 4.4 第 4 步：多元线性回归

三个特征（面积、卧室数、房龄）预测价格，权重是长度 3 的列表，梯度对每个权重分别算。数据没有划分训练/测试集，R² 是在训练数据上算的。标准化函数对每个特征减均值除标准差（方差用除以 n 的版本）；y 也做了标准化。

~~~python
# 本块中文说明：多特征线性回归，含自写的按特征标准化。
class MultipleLinearRegression:
    def __init__(self, n_features, learning_rate=0.01):
        self.weights = [0.0] * n_features
        self.bias = 0.0
        self.lr = learning_rate
        self.cost_history = []

    def predict_single(self, x):
        return sum(w * xi for w, xi in zip(self.weights, x)) + self.bias

    def predict(self, X):
        return [self.predict_single(x) for x in X]

    def compute_cost(self, X, y):
        predictions = self.predict(X)
        n = len(y)
        return sum((pred - actual) ** 2 for pred, actual in zip(predictions, y)) / n

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        n_features = len(X[0])
        for epoch in range(epochs):
            predictions = self.predict(X)
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            for j in range(n_features):
                grad = (2 / n) * sum(errors[i] * X[i][j] for i in range(n))
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            cost = self.compute_cost(X, y)
            self.cost_history.append(cost)
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


random.seed(42)
N = 100
X_multi = []
y_multi = []
for _ in range(N):
    size = random.uniform(500, 3000)
    bedrooms = random.randint(1, 5)
    age = random.uniform(0, 50)
    price = 50 * size + 10000 * bedrooms - 1000 * age + 50000 + random.gauss(0, 20000)
    X_multi.append([size, bedrooms, age])
    y_multi.append(price)


def standardize(X):
    n_features = len(X[0])
    means = [sum(X[i][j] for i in range(len(X))) / len(X) for j in range(n_features)]
    stds = []
    for j in range(n_features):
        variance = sum((X[i][j] - means[j]) ** 2 for i in range(len(X))) / len(X)
        stds.append(variance ** 0.5)
    X_scaled = []
    for i in range(len(X)):
        row = [(X[i][j] - means[j]) / stds[j] if stds[j] > 0 else 0 for j in range(n_features)]
        X_scaled.append(row)
    return X_scaled, means, stds


y_mean_val = sum(y_multi) / len(y_multi)
y_std_val = (sum((yi - y_mean_val) ** 2 for yi in y_multi) / len(y_multi)) ** 0.5
y_scaled = [(yi - y_mean_val) / y_std_val for yi in y_multi]

X_scaled, x_means, x_stds = standardize(X_multi)

print("\n=== Multiple Linear Regression (3 features) ===")
print("Features: house size, bedrooms, age")
multi_model = MultipleLinearRegression(n_features=3, learning_rate=0.01)
multi_model.fit(X_scaled, y_scaled, epochs=1000, print_every=200)

print(f"\nWeights (standardized): {[round(w, 4) for w in multi_model.weights]}")
print(f"Bias (standardized): {multi_model.bias:.4f}")
print(f"R-squared: {multi_model.r_squared(X_scaled, y_scaled):.4f}")
~~~

权重解读要在标准化空间里做：面积（0～3000）和卧室数（1～5）原始尺度差三个数量级，标准化后权重大小才可直接比较“谁更重要”（补充：这是标准化带来的可解释性收益）。

### 4.5 第 5 步：多项式回归

`make_features` 把每个 x 变成 [x, x², …, x^degree]，之后一切照旧。数据真实关系是二次 y=0.5x²−2x+3。训练前把 x 除以最大绝对值、把 y 标准化，避免大数让梯度下降不稳。2 次与 5 次各训练 2000 轮，原课结论“2 次足够、5 次在训练集上略好但有风险”是原课参考。

~~~python
# 本块中文说明：把 x 扩展成多项式特征后再做线性回归。
class PolynomialRegression:
    def __init__(self, degree, learning_rate=0.01):
        self.degree = degree
        self.weights = [0.0] * degree
        self.bias = 0.0
        self.lr = learning_rate

    def make_features(self, X):
        return [[x ** (d + 1) for d in range(self.degree)] for x in X]

    def predict(self, X):
        features = self.make_features(X)
        return [sum(w * f for w, f in zip(self.weights, row)) + self.bias for row in features]

    def fit(self, X, y, epochs=1000, print_every=200):
        features = self.make_features(X)
        n = len(y)
        for epoch in range(epochs):
            predictions = [sum(w * f for w, f in zip(self.weights, row)) + self.bias for row in features]
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            for j in range(self.degree):
                grad = (2 / n) * sum(errors[i] * features[i][j] for i in range(n))
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            if epoch % print_every == 0:
                cost = sum(e ** 2 for e in errors) / n
                print(f"  Epoch {epoch:4d} | Cost: {cost:.6f}")
        return self

    def r_squared(self, X, y):
        predictions = self.predict(X)
        y_mean = sum(y) / len(y)
        ss_res = sum((actual - pred) ** 2 for actual, pred in zip(y, predictions))
        ss_tot = sum((actual - y_mean) ** 2 for actual in y)
        return 1 - (ss_res / ss_tot)


random.seed(42)
X_poly = [x / 10.0 for x in range(0, 50)]
y_poly = [0.5 * x ** 2 - 2 * x + 3 + random.gauss(0, 1.0) for x in X_poly]
~~~

### 4.6 第 6 步：Ridge 回归（L2 正则化）

损失变为 MSE + α·Σw²，梯度里多出一项 2αw。偏置 b 不进惩罚项（对照 2.8 公式，惩罚只对权重）。本块依赖 4.4 的 `X_scaled`、`y_scaled` 和 `multi_model` 已在内存中。

~~~python
# 本块中文说明：带 L2 惩罚的岭回归，与 4.4 的普通多元回归对比。
class RidgeRegression:
    def __init__(self, n_features, learning_rate=0.01, alpha=1.0):
        self.weights = [0.0] * n_features
        self.bias = 0.0
        self.lr = learning_rate
        self.alpha = alpha

    def predict_single(self, x):
        return sum(w * xi for w, xi in zip(self.weights, x)) + self.bias

    def predict(self, X):
        return [self.predict_single(x) for x in X]

    def fit(self, X, y, epochs=1000, print_every=200):
        n = len(y)
        n_features = len(X[0])
        for epoch in range(epochs):
            predictions = self.predict(X)
            errors = [pred - actual for pred, actual in zip(predictions, y)]
            mse = sum(e ** 2 for e in errors) / n
            reg_term = self.alpha * sum(w ** 2 for w in self.weights)
            cost = mse + reg_term
            for j in range(n_features):
                grad = (2 / n) * sum(errors[i] * X[i][j] for i in range(n))
                grad += 2 * self.alpha * self.weights[j]
                self.weights[j] -= self.lr * grad
            grad_b = (2 / n) * sum(errors)
            self.bias -= self.lr * grad_b
            if epoch % print_every == 0:
                print(f"  Epoch {epoch:4d} | Cost: {cost:.4f} | L2 penalty: {reg_term:.4f}")
        return self


print("\n=== Ridge Regression (L2 Regularization) ===")
print("Same data as multiple regression, with alpha=0.1")

print(f"Plain weights: {[round(w, 4) for w in multi_model.weights]}")

~~~

## 七、失败模式、原文边界与工程注意

1. 学习率不当是第一失败原因：过大发散（损失变 NaN/暴涨）、过小极慢。先画 `cost_history` 再谈别的。
2. 多元回归不标准化会显著拖慢甚至卡住梯度下降；本课 4.4 的演示没有训练/测试划分，R² 是训练集分数，不能当作泛化能力（原文边界，补充提醒）。
3. 原文说正规方程“对小数据集完美工作”——核对：它给出的是精确最优解，但特征多时求逆代价高；原文也承认大数据集应用梯度下降，此处提醒不要把它当万能捷径。
4. R² 高不代表模型正确：加一个无关的多项式项，训练 R² 不会下降（残差平方和只会减不会增）；判断过拟合必须看独立测试数据（补充）。
5. 多项式次数的选择是偏差—方差权衡：训练 R² 单调随次数上升不是“越多项越好”的证据。
6. Ridge 的 α 是超参数，要用验证集/交叉验证选，不是拍脑袋；α=0 时退化为普通最小二乘（补充）。
7. 原课“你的实现和 sklearn 结果一样”应理解为算法等价；默认超参、数值细节可能造成小差异。
8. 线性模型对离群点敏感：MSE 的平方惩罚放大了大误差的影响（补充，与第03课逻辑回归的动机呼应）。

## 十、术语与完成标准

线性回归（linear regression）：最小化平方误差拟合 y=wx+b 的模型；MSE：预测误差平方的平均；梯度下降：沿负梯度迭代更新参数；学习率：步长超参数；正规方程：$w=(X^\top X)^{-1}X^\top y$ 的闭式解；R²：模型解释的方差比例，上界 1、无下界；特征缩放：把各特征变到可比范围；正则化：惩罚大权重以抗过拟合；Ridge：L2 平方惩罚的线性回归；多项式回归：对权重仍线性的曲线拟合；过拟合：拟合了训练噪声。

完成检查：

- 能手算三点数据的 MSE、梯度与一步更新（0.3 节算例）。
- 能写出两个梯度公式并解释“为什么乘 x、为什么除 n”。
- 能说出梯度下降与正规方程各自适用场景及原因。
- 能解释为什么多元回归前要标准化。
- 能说明 R²=0 与 R²<0 各代表什么。
- 能区分 L2 惩罚在损失、梯度两处分别长什么样。
