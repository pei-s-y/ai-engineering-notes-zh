## 一、从哪里开始

直接按 01→21 顺序学习即可。下面分组只帮助理解关系，不要求跳过任何课：

- 01—04：机器学习是什么，加上线性回归、逻辑回归、决策树/随机森林三个最经典的模型。
- 05—06：另外两个经典分类器：支持向量机与 KNN。
- 07：唯一的无监督课：聚类（K-Means、DBSCAN、GMM）。
- 08—09：特征工程与模型评估——全阶段的地基，「统计量只能来自训练集」和「泄漏」贯穿所有后续课程，值得反复读。
- 10—13：把模型做强的工程手段：偏差方差诊断、集成、超参数调优、流水线与实验追踪。
- 14：朴素贝叶斯——概率视角的分类器，学完可直接衔接第五阶段（NLP）的文本分类课。
- 15—18：特殊数据问题：时间序列、异常检测、不平衡数据、特征选择。
- 19—21：走向生产：系统设计、生产监控与漂移、特征仓库与训练服务偏差。

与第五阶段的衔接：14（朴素贝叶斯）→ Phase05 的 02（词袋/TF-IDF）与 05（情感分析）是同一条线；19—21 的生产化内容与 Phase05 后半的评估课互补。

## 三、每课怎样使用这份笔记

新增各课均按以下结构编排：零、初学者先读（类比、术语白话、小数字算例、代码衔接、理解检查含参考答案）→ 问题 → 概念与算例 → 操作前准备 → Build It 逐步讲解和代码 → 补充入口与结果检查 → Use It → 失败模式/纠错 → 中文 Ship It 模板 → 原课练习 → 术语与完成清单 → 验证范围/许可。第 01、04 课为早期笔记，格式与新增各课不同，内容仍完整。

学习时可以分三遍：

1. 先读「零、初学者先读」，自己把小数字算例算一遍，再答 0.5 的理解检查。
2. 再看 Build It，按依赖顺序在自己的 WSL 练习环境里逐块运行；把补充入口中的变量先准备好。不要把包含 `>>>` 的交互展示、注释占位或省略号当完整脚本直接执行。
3. 最后核对结果、失败模式与练习。先完成 Easy；Medium/Hard 也完整保留，等数据、算力或前置知识具备再做，不要求首次读完就全部训练成功。

原文代码与修正版分开标识。保留来源代码不代表它无错；紧接的解释会指出缺变量、伪接口、API 版本或逻辑问题。凡标（核对/补充）处，原文均原样保留、未吞改。

## 四、WSL 操作和依赖约定

在 Ubuntu 中，先进入课程仓库；下面使用通用示例目录，请按实际位置替换：

~~~bash
cd ~/projects/ai-engineering-from-scratch
python3 --version
python3 -m pip --version
~~~

先激活你原有的虚拟环境，再检查 python 和 pip 是否属于同一环境。不确定环境名时不要照抄不存在的激活路径。若确实还没有环境，可在自己的练习项目中创建一次：

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version
~~~

笔记里的 `python -m pip install` 只供你按课选择安装，本次未替你安装（唯一例外见下）。Windows Python 与 WSL Python 的包、GPU 配置不共享；看到 Windows 里已经安装，不等于 Ubuntu 也有。

建议先跑标准库小例子，再按课安装 NumPy/scikit-learn 等，最后才考虑更大的依赖。原文模型名、库版本与下载权限可能变化，笔记已标出易漂移部分；遇到报错请保留完整错误、Python 版本、所在系统及包版本。

## 六、阅读中反复注意的区别

- 训练集拟合好不等于泛化好；交叉验证分数是估计，不是保证。
- 泄漏不报错，只让分数虚高——它是最常见的「离线 95%、上线 55%」成因。
- 评估指标要匹配代价：不平衡数据下准确率会说谎，先看混淆矩阵再选指标。
- 原文效果数字、成本与固定阈值是来源背景，不是本次实测，也不是通用定律。
- 集成/调参提升的是既有特征与标签的上限，救不了坏数据。
- 标「核对/补充」处原文原样保留，读的时候以紧邻解释为准。
