## 零、初学者先读：500 个特征里，哪些真的有用？

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。前置是[第08课](<08：特征工程——构造、变换、缩放与泄漏.md>)的过滤法入门与[第04课](<04：决策树与随机森林.md>)的树模型。

### 0.1 先理解这一课在做什么

搬家装箱，带的东西越多不一定越好——箱子塞满了，反而找不到要用的。三类打包策略对应三类特征选择：**过滤法**像出发前按“单件物品重量”快速断舍离（快，但看不到组合价值）；**包裹法**像试装几箱看哪套组合装得下（准，但反复试很累）；**嵌入法**像边装箱边扔（一次搞定，但只适合那种箱子）。原课开出的药方：特征越多，空间越大、数据越稀疏、距离越失真，噪声淹没信号、过拟合成为默认结局——选择的要点不是用上所有信息，而是用对的信息。

### 0.2 本课术语先翻成白话

- 特征选择=从全部特征里挑出真正有用的子集
- 过滤法（filter）=训练前按统计分数独立打分，不看模型
- 包裹法（wrapper）=反复训练模型来评估特征子集
- 嵌入法（embedded）=训练过程中顺带完成选择
- 方差阈值=方差太低的列直接删（连目标都不看）
- 互信息（MI）=知道 X 后对 Y 的不确定度下降多少，能抓非线性关系
- RFE（递归特征消除）=训练→按重要性排名→删最差→重复
- L1 / Lasso=绝对值惩罚，把无关权重压到恰好 0
- L2 / Ridge=平方惩罚，只缩小、几乎不归零
- 软阈值（soft-threshold）=L1 的单步更新规则：向零收缩、过头归零
- 树重要性=按“不纯度下降 × 样本数”累加的特征分数
- 置换重要性=打乱一列看性能掉多少
- 基数偏差=高唯一值特征在树重要性里虚高（随机 ID 也会“重要”）
- 维数灾难=特征太多导致空间稀疏、距离失真

### 0.3 用小数字走一遍

互信息手算：标签 y=[0,0,1,1]，特征分箱后 x=[1,1,2,2]。边缘分布各 0.5/0.5；联合分布 p(x=1,y=0)=0.5、p(x=2,y=1)=0.5、其余 0。代入 $I=\sum p(x,y)\log\frac{p(x,y)}{p(x)p(y)}$：两非零项各为 0.5·log(0.5/0.25)=0.5·log2，合计 **log 2 ≈ 0.693**（自然对数）——特征完全确定标签，MI 达到标签自身的熵。

方差阈值：x=[5,5,5,5] 方差 0，删；x=[4,5,4,6] 方差 = (1+0+1+1)/4 = 0.75，留（阈值 0.01）。

L1 软阈值：阈值 λ'=0.3 时，w=0.8 → sign(0.8)·max(0.8−0.3, 0) = 0.5（收缩）；w=0.2 → 0（**恰好归零**）。对比 L2：0.2 只会变成 0.2×(1−η)，永远碰不到 0——这就是 L1 做选择、L2 只压缩的差别。

“标准答案”数据（4.1）：前 5 列有信息（其中 2 列是冗余拷贝）、中间 5 列与前 5 列相关、最后 10 列纯噪声；好方法应把 info 排最高、noise 排最低。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.4 怎样连接到正文代码

按依赖顺序读：`make_feature_selection_data`（先看懂“标准答案”长什么样）→ `variance_threshold` → `discretize` + `mutual_information` → `simple_logistic_importance` + `rfe` → `soft_threshold` + `l1_feature_selection` → `best_split` + `tree_importance`（含 `_build_tree_importance`）。核心数据结构是两个：布尔掩码（`selected_mask`，第 j 位为 True 表示选中第 j 列）与排名数组（`rankings`，1 表示留到最后）。RFE 的逻辑核心是“每轮在**剩余**列上重新训练”——特征间的影响会随删列而变，这是包裹法区别于过滤法的关键。

### 0.5 理解检查（含参考答案）

**问题1：** 为什么互信息能发现相关性发现不了的关系？

**参考答案：** x 与 y=x² 在对称分布下相关系数约为 0，但知道 x 完全确定 y；MI 度量一般依赖（含非线性），相关系数只测线性关联。

## 一、这一课解决什么问题？

原课的场景：500 个特征，训练慢、过拟合、没人能解释模型学了什么；继续加特征，反而更差——维数灾难在起作用：特征数增长，特征空间体积爆炸、数据点变稀疏、点间距离趋同，模型需要指数级更多的数据才能找到真实规律，噪声特征淹没信号特征。特征选择是解药：剥掉噪声、去掉冗余、留下对目标有真实信息的特征，换来更快的训练、更好的泛化、能解释的模型。目标不是用上所有信息，而是用对的信息。本课从零实现过滤（方差阈值、互信息）、包裹（RFE）、嵌入（L1、树重要性）三类方法，并给出选择流程（第08课已铺垫过滤法，本课是完整版）。

## 二、核心概念与推导

### 2.1 三大类方法

- **过滤法**：每个特征用统计量独立打分，不训模型。快，但看不到特征间的交互。
- **包裹法**：训练模型来评估特征子集，用模型性能当分数。效果常更好，但反复重训、昂贵。
- **嵌入法**：选择内嵌在训练里。L1 把权重压到零，树按最有用的特征切分——拟合的同时完成选择。

### 2.2 方差阈值：最简单的过滤

$$\text{variance}(x)=\text{mean}\bigl((x-\text{mean}(x))^2\bigr)$$

设阈值（如 0.01），低于就删。1000 个样本里 999 个都是 0.0 的特征，方差近零，任何模型都无法靠它区分样本。**它完全不看目标变量**：删的是“显然没用”的，作为其他方法之前的预处理，近零成本。局限：高方差照样可能是纯噪声——必要但不充分。

### 2.3 互信息：线性和非线性都能抓

$$I(X;Y)=\sum_x\sum_y p(x,y)\,\log\frac{p(x,y)}{p(x)\,p(y)}$$

若 X 与 Y 独立，则 p(x,y)=p(x)p(y)，对数项为 0，MI=0；X 对 Y 知道得越多，MI 越大。相对相关性的关键优势：非线性关系（二次、周期）也能抓到。连续特征先离散化（直方法估计）：分箱数影响估计——太少丢信息、太多添噪声，常见选择 $\sqrt{n}$ 箱或 Sturges 法则（$1+\log_2 n$）。流程：分箱 → 估计联合分布 → 套公式 → 按 MI 排名取前 K。

### 2.4 RFE：训练、排名、剪枝、重复

1. 用全部特征训练模型
2. 按重要性排名（线性模型看系数、树看不纯度下降）
3. 删掉最不重要的一个（或一批）
4. 重复直到剩目标数量

因为模型每次看到全部剩余特征，删一列会改变其他列的重要性——这让它能处理特征交互，比过滤法周全。代价：训练 N−目标 次模型（500 列留 10 列是 490 次训练）；提速办法是每轮删底部 10%。

### 2.5 L1 / Lasso：嵌入在选择

$$\text{loss}=\text{prediction\_error}+\alpha\cdot\sum_j |w_j|$$

alpha 控制剪枝强度，越大越多权重恰好归零。为什么恰好是零（几何直觉，补充）：L1 惩罚在权重空间里是菱形约束区域，最优解容易落在菱形的角上——角上恰有某些分量为零；L2 的约束区域是圆，解只会滑到圆边而几乎不会正好落在坐标轴上。零权重的特征即被移除：训练一次完成选择。优点：单次训练、能处理相关特征（挑一个、清零其余）、多数线性实现自带。局限：只作用于线性模型，无法度量非线性重要性。

### 2.6 树重要性与基数偏差

森林里每棵树的每个切分节点都在降低不纯度；把“样本数 × 不纯度下降”按特征累加、再对 T 棵树平均，就得到重要性：

$$\text{importance}(j)=\frac{1}{T}\sum_{\text{trees}}\;\sum_{\text{nodes splitting on } j}\bigl(n_{\text{node}}\cdot \Delta\text{impurity}\bigr)$$

它自动处理非线性与交互。**警告（原文强调）**：树重要性偏向高唯一值特征——随机 ID 列能完美切分每个样本，看起来“很重要”。务必用置换重要性做核对。

### 2.7 置换重要性：打乱一列看损伤

1. 训练模型，记录验证集上的基准性能
2. 对每个特征：随机打乱它的取值，重测性能
3. 掉得越多，特征越重要

打乱不伤性能 → 模型不依赖它；性能崩塌 → 该特征关键。它没有树重要性的基数偏差，且模型无关；但慢：每特征一次完整评估，还要重复多次求稳。相关特征间分数会互相分摊（打乱一列，模型还能从共线的那列补上信息，两列都显得不重要）。

### 2.8 方法对比与选择流程

| 方法 | 类型 | 速度 | 非线性 | 特征交互 |
|---|---|---|---|---|
| 方差阈值 | 过滤 | 极快 | 否 | 否 |
| 互信息 | 过滤 | 快 | 是 | 否 |
| 相关性过滤 | 过滤 | 快 | 否 | 否 |
| RFE | 包裹 | 慢 | 取决于模型 | 是 |
| L1 / Lasso | 嵌入 | 快 | 否（线性）| 否 |
| 树重要性 | 嵌入 | 中 | 是 | 是 |
| 置换重要性 | 模型无关 | 慢 | 是 | 是 |

原课决策流程（启发式）：<50 个特征先“方差阈值+互信息”；50–500 用“方差阈值 → L1 或树重要性”；>500 用“方差阈值 → 互信息过滤 → 幸存者上跑 RFE”。线性模型收尾用 L1；树模型用“树重要性 + 置换重要性”核对；其他模型用 RFE。最后一步永远相同：在保留集上对比“选中特征 vs 全部特征”的性能，没提升就换方法或保留全部。

### 2.9 用一个小例子把概念串起来（补充）

用 4.1 的“标准答案”数据走一遍：方差阈值先删——但这份合成数据所有列方差都不小（噪声列方差 ≈ 0.25），一轮下来几乎不删，这本身就说明“必要但不充分”。互信息接着上：info_0/1/2 与标签由 2x1−1.5x2+x3 决定，MI 高；noise 列 MI 接近 0。RFE 与 L1 在信息与噪声之间画线的方式不同：L1 直接把噪声权重压零；RFE 一轮轮把噪声往后排。最后用树重要性核对，发现某个 corr 列（与 info 高度相关）也有不低的分——它确实携带信息，只是冗余；要不要删取决于你更在乎精度还是可解释性。这就是为什么原课流程的最后一步是“对比选中 vs 全部的性能”而不是“相信任何单一方法”。

## 四、Build It：原课分步代码与中文讲解

### 4.1 合成数据：自带“标准答案”

5 列有信息（x4、x5 是 x1、x2 加小噪声的冗余拷贝）、5 列与前 5 列相关、10 列纯噪声（×0.5 缩放）；标签由 2x1−1.5x2+x3 加噪声后取阈值得到。选择方法好不好，看它能不能把 info 排最高、noise 排最低。

~~~python
# 本块中文说明：生成已知特征结构的合成分类数据。
import numpy as np


def make_feature_selection_data(n_samples=500, seed=42):
    rng = np.random.RandomState(seed)

    x1 = rng.randn(n_samples)
    x2 = rng.randn(n_samples)
    x3 = rng.randn(n_samples)
    x4 = x1 + 0.1 * rng.randn(n_samples)   # x1 的冗余拷贝
    x5 = x2 + 0.1 * rng.randn(n_samples)   # x2 的冗余拷贝

    informative = np.column_stack([x1, x2, x3, x4, x5])

    correlated = np.column_stack([
        x1 * 0.9 + 0.1 * rng.randn(n_samples),
        x2 * 0.8 + 0.2 * rng.randn(n_samples),
        x3 * 0.7 + 0.3 * rng.randn(n_samples),
        x1 * 0.5 + x2 * 0.5 + 0.1 * rng.randn(n_samples),
        x2 * 0.6 + x3 * 0.4 + 0.1 * rng.randn(n_samples),
    ])

    noise = rng.randn(n_samples, 10) * 0.5

    X = np.hstack([informative, correlated, noise])
    y = (2 * x1 - 1.5 * x2 + x3 + 0.5 * rng.randn(n_samples) > 0).astype(int)

    feature_names = (
        [f"info_{i}" for i in range(5)]
        + [f"corr_{i}" for i in range(5)]
        + [f"noise_{i}" for i in range(10)]
    )

    return X, y, feature_names
~~~

### 4.2 方差阈值

逐列算总体方差（`np.var` 默认 ddof=0），返回掩码与各列方差。对 4.1 的数据基本不会删列（见 2.9 的讨论）。

~~~python
# 本块中文说明：按方差阈值保留特征列。
def variance_threshold(X, threshold=0.01):
    variances = np.var(X, axis=0)
    mask = variances > threshold
    return mask, variances
~~~

### 4.3 离散互信息

`discretize` 用 `np.digitize` 等宽分箱（min=max 时全归 0 箱）；`mutual_information` 对每列分箱后统计联合与边缘频率，套 2.3 的公式累加。注意循环是“每特征 × 每箱 × 每类”，纯教学实现。

~~~python
# 本块中文说明：分箱 + 直方法互信息打分。
def discretize(x, n_bins=10):
    min_val, max_val = x.min(), x.max()
    if max_val == min_val:
        return np.zeros_like(x, dtype=int)
    bin_edges = np.linspace(min_val, max_val, n_bins + 1)
    binned = np.digitize(x, bin_edges[1:-1])   # 等宽分箱
    return binned


def mutual_information(X, y, n_bins=10):
    n_samples, n_features = X.shape
    mi_scores = np.zeros(n_features)

    y_vals, y_counts = np.unique(y, return_counts=True)
    p_y = y_counts / n_samples

    for f in range(n_features):
        x_binned = discretize(X[:, f], n_bins)
        x_vals, x_counts = np.unique(x_binned, return_counts=True)
        p_x = dict(zip(x_vals, x_counts / n_samples))

        mi = 0.0
        for xv in x_vals:
            for yi, yv in enumerate(y_vals):
                joint_mask = (x_binned == xv) & (y == yv)
                p_xy = np.sum(joint_mask) / n_samples
                if p_xy > 0:
                    mi += p_xy * np.log(p_xy / (p_x[xv] * p_y[yi]))
        mi_scores[f] = mi

    return mi_scores
~~~

### 4.4 RFE（包裹法）

`simple_logistic_importance` 是批量梯度下降的逻辑回归，返回权重与偏置（权重绝对值即“重要性”）；`rfe` 每轮在**剩余列**上重训、删 |w| 最小的一列并记排名（被删越早排名数字越大，1 表示留到最后），直到剩目标数量。注意：每轮只删一列——500 列留 10 列要 490 次训练，这是 2.4 说的成本来源。

~~~python
# 本块中文说明：逻辑回归权重当重要性，逐列递归消除。
def simple_logistic_importance(X, y, lr=0.1, epochs=100):
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0

    for _ in range(epochs):
        z = X @ w + b
        pred = 1.0 / (1.0 + np.exp(-np.clip(z, -500, 500)))
        error = pred - y
        w -= lr * (X.T @ error) / n_samples
        b -= lr * np.mean(error)

    return w, b


def rfe(X, y, n_features_to_select=5, lr=0.1, epochs=100):
    n_total = X.shape[1]
    remaining = list(range(n_total))
    rankings = np.ones(n_total, dtype=int)
    rank = n_total

    while len(remaining) > n_features_to_select:
        # 每轮在“剩余列”上重新训练——这是包裹法的关键
        X_subset = X[:, remaining]
        w, _ = simple_logistic_importance(X_subset, y, lr, epochs)
        importances = np.abs(w)

        least_idx = np.argmin(importances)
        original_idx = remaining[least_idx]
        rankings[original_idx] = rank   # 越早被删，排名数字越大
        rank -= 1
        remaining.pop(least_idx)

    for idx in remaining:
        rankings[idx] = 1               # 幸存者并列第 1

    selected_mask = rankings == 1
    return selected_mask, rankings
~~~

### 4.5 L1 特征选择（嵌入法）

梯度下降一步后接软阈值：`w = sign(w)·max(|w|−α', 0)`，向零收缩、过头归零。**核对（补充）**：阈值是 `lr * alpha`——惩罚强度与学习率耦合（步长变小，等效正则也变小），这是近端梯度的教学简化；调 alpha 时记得 lr 也在等效正则里。选中的定义是 |w| > 1e-6。

~~~python
# 本块中文说明：近端梯度下降的 L1 逻辑回归，权重归零即剔除。
def soft_threshold(w, alpha):
    return np.sign(w) * np.maximum(np.abs(w) - alpha, 0)


def l1_feature_selection(X, y, alpha=0.1, lr=0.01, epochs=500):
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0

    for _ in range(epochs):
        z = X @ w + b
        pred = 1.0 / (1.0 + np.exp(-np.clip(z, -500, 500)))
        error = pred - y

        gradient_w = (X.T @ error) / n_samples
        gradient_b = np.mean(error)

        w -= lr * gradient_w
        w = soft_threshold(w, lr * alpha)   # 阈值与学习率耦合（教学简化）
        b -= lr * gradient_b

    selected_mask = np.abs(w) > 1e-6
    return selected_mask, w
~~~

### 4.6 树重要性（嵌入法）

`gini_impurity` 与 `best_split`（相邻唯一值中点做阈值）是[第04课](<04：决策树与随机森林.md>)的套路；`tree_importance` 是简化随机森林：bootstrap 采样 + 每棵树随机抽 √特征数 个候选特征，`_build_tree_importance` 递归建树并把“增益 × 节点样本数”累加到对应特征上，最后归一化。停止条件：达深度上限、标签纯、或样本 < 4。

~~~python
# 本块中文说明：简化随机森林的 MDI 式特征重要性。
def gini_impurity(y):
    if len(y) == 0:
        return 0.0
    classes, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return 1.0 - np.sum(probs ** 2)


def best_split(X, y, feature_idx):
    values = np.unique(X[:, feature_idx])
    if len(values) <= 1:
        return None, -1.0

    best_threshold = None
    best_gain = -1.0
    parent_gini = gini_impurity(y)
    n = len(y)

    # 相邻唯一值的中点当候选阈值
    for i in range(len(values) - 1):
        threshold = (values[i] + values[i + 1]) / 2.0
        left_mask = X[:, feature_idx] <= threshold
        right_mask = ~left_mask

        n_left = np.sum(left_mask)
        n_right = np.sum(right_mask)

        if n_left == 0 or n_right == 0:
            continue

        gain = parent_gini - (n_left / n) * gini_impurity(y[left_mask]) - (n_right / n) * gini_impurity(y[right_mask])

        if gain > best_gain:
            best_gain = gain
            best_threshold = threshold

    return best_threshold, best_gain


def tree_importance(X, y, n_trees=50, max_depth=5, seed=42):
    rng = np.random.RandomState(seed)
    n_samples, n_features = X.shape
    importances = np.zeros(n_features)

    for _ in range(n_trees):
        # bootstrap 样本 + 每树随机特征子集（随机森林两随机）
        sample_idx = rng.choice(n_samples, size=n_samples, replace=True)
        feature_subset = rng.choice(n_features, size=max(1, int(np.sqrt(n_features))), replace=False)

        X_boot = X[sample_idx]
        y_boot = y[sample_idx]

        tree_imp = _build_tree_importance(X_boot, y_boot, feature_subset, max_depth)
        importances += tree_imp

    total = importances.sum()
    if total > 0:
        importances /= total

    return importances


def _build_tree_importance(X, y, feature_subset, max_depth, depth=0):
    n_features = X.shape[1]
    importances = np.zeros(n_features)

    # 停止条件：深度到顶 / 标签已纯 / 样本太少
    if depth >= max_depth or len(np.unique(y)) <= 1 or len(y) < 4:
        return importances

    best_feature = None
    best_threshold = None
    best_gain = -1.0

    for f in feature_subset:
        threshold, gain = best_split(X, y, f)
        if gain > best_gain:
            best_gain = gain
            best_feature = f
            best_threshold = threshold

    if best_feature is None or best_gain <= 0:
        return importances

    importances[best_feature] += best_gain * len(y)   # 增益 × 样本数

    left_mask = X[:, best_feature] <= best_threshold
    right_mask = ~left_mask

    importances += _build_tree_importance(X[left_mask], y[left_mask], feature_subset, max_depth, depth + 1)
    importances += _build_tree_importance(X[right_mask], y[right_mask], feature_subset, max_depth, depth + 1)

    return importances
~~~

## 七、失败模式、原文边界与工程注意

1. 过滤法看不到交互：两个特征单独都无信息、合起来才有用（XOR 类关系），互信息逐列打分会双双漏掉。
2. RFE 每轮只删一列时成本 O(N) 次训练；特征上千时先按 MI 粗筛或每轮删底部一批（原课自己建议 remove bottom 10%）。
3. L1 只在线性模型语境下做选择；高度相关的一组特征里它倾向任选一个、清零其余——选中的那个未必是“因果上更对”的那个。
4. 4.5 的阈值 `lr * alpha` 与学习率耦合：单独调 alpha 而不动 lr，等效正则强度并不按你直觉变化（核对，已在 4.5 标注）。
5. 树重要性有基数偏差：随机 ID 列会虚高；用置换重要性核对（原课强调，练习 5 让你实现）。
6. 置换重要性慢，且在相关特征间分数互相分摊——两列共线时各自都可能显得不重要，不代表都该删。
7. 选择本身也要防泄漏：在“训练+测试”全量数据上做选择再评估，是第08课同款泄漏；应配合[第09课](<09：模型评估——指标、交叉验证与数据泄漏.md>)的交叉验证在折内做选择。
8. 原课决策流程（按特征数选方法）是启发式起点，不是保证；最后一步“选中 vs 全部对比性能”不可省略。
9. “500 个特征”的场景描述、时间估计（~75 分钟）是课程层面的说法，不是本机实测。

## 九、Exercises：保留原课练习与验收方法

1. **前向选择（forward selection）**：与 RFE 相反，从零特征开始，每步加入“提升模型性能最多”的特征，直到不再提升。与 RFE 对比：哪个更快？哪个结果更好？验收：两种方法在同一数据上的选中集合、训练次数统计与性能对比，并解释差异来源。
2. **稳定性选择（stability selection）**：L1 跑 50 次，每次用 80% 随机子样本、略微不同的 alpha，统计每特征被选中频率；>80% 的算“稳定”。与单次 L1 对比哪个更可靠。验收：报告稳定特征清单与单次 L1 结果的差异，并讨论子采样为什么能抑制偶然选中。
3. **多重共线性检测**：算特征相关矩阵，实现“高相关对中保留 MI 更高的那个”的删除函数（阈值如 0.9）。在合成数据上验证 corr 组被删。验收：删除前后保留列清单 + 相关矩阵热点核对。
4. **选择流水线**：方差阈值 → MI 前 50% → RFE 串联，对比“流水线 vs 直接 RFE”。更快吗？同样准吗？验收：两种方式的时间与性能对比（自己实测），并解释流水线提速的来源。
5. **从零实现置换重要性**：每特征打乱 10 次、记录 F1 平均下降，与树重要性排名对比，找出分歧案例并解释（提示：相关特征）。验收：两份排名表 + 至少一个分歧案例的机理解释。
