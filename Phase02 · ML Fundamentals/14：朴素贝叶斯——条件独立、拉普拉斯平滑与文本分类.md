### 0.1 先理解这一课在做什么

判断一封邮件是不是垃圾邮件：朴素贝叶斯的思路是数数——垃圾邮件里“free”出现得多不多、正常邮件里“meeting”出现得多不多，再把这些证据连乘起来。它“朴素”在假设词与词互不影响（“machine”和“learning”显然总一起出现，假设错了），但分类只需要“哪一类得分最高”，不需要概率精确；错误的假设对各类的干扰差不多，名次常常照样对。于是这个“数学上站不住”的模型成了文本分类的常青树基线。

### 0.2 本课术语先翻成白话

- 贝叶斯定理=把“给类别求词的概率”翻转成“给词求类别的概率”的公式
- 先验（prior）=还没看内容前，这封邮件是垃圾的概率（垃圾邮件占比）
- 似然（likelihood）=假设是垃圾邮件，长成这样的概率
- 后验（posterior）=看完内容后更新的类别概率
- 条件独立（conditional independence）=在类别给定时，特征之间互不携带信息
- 朴素假设=把所有特征当成条件独立的那个（错的）简化
- 拉普拉斯平滑（Laplace smoothing）=每个词的计数都加一点 α，防止概率为 0
- 多项式朴素贝叶斯（MultinomialNB）=特征当“出现次数”的版本，文本标配
- 伯努利朴素贝叶斯（BernoulliNB）=特征当“出现/没出现”的版本，“没出现”也投票
- 高斯朴素贝叶斯（GaussianNB）=特征当连续数值、按正态分布建模的版本
- 对数概率（log probability）=把连乘换成连加，防浮点下溢
- 生成式模型=先学“每类数据长什么样”再反推类别（NB）
- 判别式模型=直接学“边界在哪”（逻辑回归）
- 校准（calibration）=模型说 0.95 时，真实是否十次里对九次半

### 0.3 用小数字走一遍

词表只有两个词：buy、meeting。训练集里垃圾邮件（spam）共出现 5 个词：buy×4、meeting×1；正常邮件（ham）共 6 个词：buy×1、meeting×5。两类各占一半，先验都是 0.5。

拉普拉斯平滑（α=1，词表大小 2）：

- P(buy|spam)=(4+1)/(5+1×2)=5/7≈0.714；P(meeting|spam)=(1+1)/7≈0.286
- P(buy|ham)=(1+1)/(6+2)=0.25；P(meeting|ham)=(5+1)/8=0.75

新邮件只含一个 buy。对数得分：log spam = ln(0.5)+ln(0.714)≈−0.693−0.337=−1.030；log ham = ln(0.5)+ln(0.25)≈−0.693−1.386=−2.079。spam 胜出——buy 是强垃圾信号。

再看没见过的词“win”（两类计数都是 0）：不平滑时 P(win|·)=0，一乘全盘归零，整封邮件的其他证据全被它毁掉；平滑后 P(win|spam)=1/7、P(win|ham)=1/8，只贡献一点温和的证据。

以上是用于理解的算例，不是新增的训练或性能实测。

### 0.4 怎样连接到正文代码

按顺序读：`MultinomialNB.fit`（数每类每词的频次 + 平滑 + 取对数）→ `GaussianNB.fit`（每类每特征记均值方差）→ 预测部分原文只讲思路没给代码，第五节补齐（一行矩阵乘法 + argmax）。核心数据结构：`feature_log_prob_` 是 (类别数×特征数) 的对数概率矩阵——训练的全部产出就是这张表加一个 `class_log_prior_` 向量；预测 = `X @ 表.T + 先验`，和一层线性模型同构。

### 0.5 理解检查（含参考答案）

**问题1：** 独立假设明明是错的，为什么分类还常常对？

**参考答案：** 分类只需要“哪类得分最高”，不需要概率数值正确。独立假设带来的误差在各类之间方向相似、大量抵消，名次常常保住；且强先验约束了模型，小数据上反而不易过拟合。

**问题2：** 不做拉普拉斯平滑会发生什么？

**参考答案：** 测试集出现训练中某类没见过的词时，该词概率为 0，连乘把整类得分清零，一个词毁掉全部其他证据。平滑给每个词留一点非零概率。

**问题3：** MultinomialNB 和 BernoulliNB 对“词没出现”的处理差别？

**参考答案：** Multinomial 只数出现的词，“没出现”不贡献任何项；Bernoulli 把“没出现”也当证据——垃圾邮件里常见的词若缺席，会作为反对 spam 的一票。

三问答对，就可以进正文了。

## 一、这一课解决什么问题？

要做文本分类：邮件分垃圾/正常、评论分正面/负面、工单分类别。特征成千上万（每个词一列），训练数据有限。多数分类器在这里吃不消：逻辑回归要可靠估计上千个权重需要足够样本；决策树一次切一个词、疯狂过拟合（见[第04课](<04：决策树与随机森林.md>)）；KNN 在上万维空间里“人人一样远”（见[第06课](<06：KNN与距离度量——近邻投票、K值与维度灾难.md>)）。朴素贝叶斯用一个数学上错误的假设（给定类别后特征相互独立）换来：一遍扫描训练完、扩展到百万级特征、小训练集上经常打赢“更聪明”的模型。原课的教学价值正在于：最好的模型不是假设最正确的模型，而是偏差—方差权衡最适合你数据的模型。

## 二、核心概念与推导

### 2.1 贝叶斯定理回顾

$$P(\text{class}\mid\text{features}) = \frac{P(\text{features}\mid\text{class})\cdot P(\text{class})}{P(\text{features})}$$

想要的是左边：看到这些词之后属于某类的概率。右边三项：似然（这类文档里出现这些词的概率）、先验（这类文档总体占比）、证据（分母，对所有类相同，比较时可以约掉）。得分最高的类获胜。

### 2.2 朴素独立假设

精确计算 $P(\text{features}\mid\text{class})$ 需要估计全部特征的联合分布：词表 1 万就要对 $2^{10000}$ 种组合建模，不可能。朴素假设：给定类别后各特征条件独立：

$$P(w_1,\ldots,w_n\mid c) = \prod_i P(w_i\mid c)$$

一个不可能的联合分布变成 n 个各需一个计数的小分布。“machine”和“learning”当然不独立——假设明显错，但分类要的是名次对，不是数值对（下节展开）。

### 2.3 为什么错了还管用

原课给三个原因加一个实践理由：

1. **要名次不要校准**：就算 $P(\text{spam})$ 报 0.99999 而真实是 0.7，只要 spam 排第一，分类就对。
2. **高偏差低方差**：独立性是强先验，重重约束模型，小数据上“稳定地略错”胜过“理论对但剧烈晃”。
3. **冗余证据相互抵消**：“machine”与“learning”总同现，NB 把证据记两遍——但对正确的类记两遍，名次不受影响。
4. **快**：训练是数一遍频次，预测是一次矩阵乘法，百万文档秒级训完，迭代速度本身就是优势。

### 2.4 数学一步一步走（原课数值例子）

两类：spam / not-spam，词表三词：free、money、meeting。训练计数：spam 里 free×80、money×60、meeting×10（共 150 词）；not-spam 里 free×5、money×10、meeting×100（共 115 词）；40% 邮件是 spam。拉普拉斯平滑 α=1：

$$P(\text{free}\mid\text{spam})=\frac{80+1}{150+3}=0.529,\quad P(\text{money}\mid\text{spam})=\frac{61}{153}=0.399,\quad P(\text{meeting}\mid\text{spam})=\frac{11}{153}=0.072$$

$$P(\text{free}\mid\text{not})=\frac{6}{118}=0.051,\quad P(\text{money}\mid\text{not})=\frac{11}{118}=0.093,\quad P(\text{meeting}\mid\text{not})=\frac{101}{118}=0.856$$

新邮件：free×2、money×1、meeting×0。对数得分（底为自然对数）：

$$\log P(\text{spam})=-0.916+2(-0.637)+(-0.919)+0=-3.109$$

$$\log P(\text{not})=-0.511+2(-2.976)+(-2.375)+0=-8.838$$

spam 大幅获胜：free 出现两次是强信号。注意 meeting 没出现贡献为 0（$0\cdot\log P$）——Multinomial 里缺席的词不起作用；显式建模“缺席”的是 Bernoulli（这些数值为原课演算，可手算复核）。

### 2.5 三个变体

**MultinomialNB**（多项式）：特征是计数，$P(w_i\mid c)=\frac{\text{count}(w_i,c)+\alpha}{\text{total}(c)+\alpha\cdot V}$。文本主力。

**GaussianNB**（高斯）：特征连续，按正态分布建模：$P(x_i\mid c)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x_i-\mu)^2}{2\sigma^2}\right)$，每类每特征一组均值方差。适合表格数据。

**BernoulliNB**（伯努利）：特征二值：$P(w_i\mid c)=\frac{\text{含 } w_i \text{ 的文档数}+\alpha}{\text{类内文档数}+2\alpha}$。它显式惩罚“该出现的词没出现”。

| 变体 | 特征类型 | 适用 | 例子 |
|---|---|---|---|
| Multinomial | 计数/频次 | 文本、词袋 | 垃圾邮件、主题分类 |
| Gaussian | 连续值 | 近似正态的表格特征 | 鸢尾花、传感器 |
| Bernoulli | 0/1 | 短文本、出现与否特征 | 短信 spam |

### 2.6 拉普拉斯平滑

某词在测试集出现但训练中该类计数为 0：$P=0$，连乘把整类清零，一个没见过的词毁掉全部证据。平滑给每个计数加 α（常取 1）：

$$P(w_i\mid c)=\frac{\text{count}(w_i,c)+\alpha}{\text{total}(c)+\alpha\cdot V}$$

α=1 时每个词都至少有一点点概率，“discombobulate”不再一票否决。贝叶斯解释：相当于给词分布加了均匀 Dirichlet 先验。α 大 → 分布更平、更信先验；α 小 → 更信数据。α 是要调的超参数：0.001（大数据、几乎不信有未见词）→ 1（默认）→ 10（小数据、未见词多）。

### 2.7 对数空间计算

几百个小于 1 的概率连乘会浮点下溢成 0。改用对数：$\log P(c\mid x)=\log P(c)+\sum_i\log P(x_i\mid c)$，连乘变连加。于是预测变成一次矩阵乘法：

~~~text
log_scores = X @ log_feature_probs.T + log_class_priors
prediction = argmax(log_scores)
~~~

这就是 NB 预测飞快的原因——它和一个单层线性模型的计算量相同。

### 2.8 朴素贝叶斯 vs 逻辑回归

| 维度 | 朴素贝叶斯 | 逻辑回归 |
|---|---|---|
| 类型 | 生成式（建模 $P(X\mid Y)$） | 判别式（建模 $P(Y\mid X)$） |
| 训练 | 数频次，一遍完成 | 迭代优化损失 |
| 小数据 | 更好（强先验帮忙） | 更差（样本不够估权重） |
| 大数据 | 更差（错误假设拖后腿） | 更好（边界更灵活） |
| 特征 | 假设独立 | 能处理相关 |
| 校准 | 概率差 | 概率较好 |

经验法则（原课）：先用 NB，数据够多且 NB 到顶了再换逻辑回归。（对照[第03课](<03：逻辑回归——sigmoid、交叉熵与决策边界.md>)：两者都是线性分类器，差别在学什么。）

### 2.9 分类流水线

原课流水线（文字版）：原始文本 → 分词 → 建词表 → 数词频 → 平滑 → 算对数概率 → argmax 预测。实践中全程在对数空间做，防下溢（即 2.7 节）。

### 2.10 用一个小例子把概念串起来（补充）

用 0.3 节的两词例子把全流程串起来：先验 0.5/0.5 → 平滑后的词概率（buy：spam 5/7、ham 1/4；meeting：spam 2/7、ham 3/4）→ 新邮件“buy”的对数得分 −1.030 vs −2.079 → argmax 判 spam。再验证三个性质：把“win”（两类计数 0）加进邮件，平滑后它给 spam 加 −ln 7≈−1.946、给 ham 加 −ln 8≈−2.079，两边都扣分但相对名次几乎不动（平滑的意义）；把邮件换成“buy meeting meeting”，ham 得分 = ln(0.5)+ln(0.25)+2·ln(0.75)≈−0.693−1.386−0.575=−2.654，spam 得分 = ln(0.5)+ln(0.714)+2·ln(0.286)≈−0.693−0.337−2.478=−3.508，ham 反超（meeting 连现两次压过 buy 的单票——频率在 Multinomial 里计次）；同样的邮件给 Bernoulli 看则是“buy 出现、meeting 出现”各记一票。训练（数数）与预测（矩阵乘）在这个两词世界里就是一张 2×2 的表，正文代码只是它的放大版。

### 4.1 MultinomialNB：训练就是数数 + 平滑 + 取对数

`fit` 对每个类：数该类文档数得先验（取对数）；把该类所有文档的词计数按列求和、加 α、归一化、取对数。整个训练产出就是 `class_log_prior_` 向量和 `feature_log_prob_` 矩阵。原文本块使用了 `np` 但未显示 import，需先执行 `import numpy as np`（原文边界，补充声明）。

~~~python
# 本块中文说明：从零实现多项式朴素贝叶斯的训练（数数+平滑+对数）。
class MultinomialNB:
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        classes = np.unique(y)
        n_classes = len(classes)
        n_features = X.shape[1]

        self.classes_ = classes
        self.class_log_prior_ = np.zeros(n_classes)
        self.feature_log_prob_ = np.zeros((n_classes, n_features))

        for i, c in enumerate(classes):
            X_c = X[y == c]
            self.class_log_prior_[i] = np.log(X_c.shape[0] / X.shape[0])
            counts = X_c.sum(axis=0) + self.alpha
            self.feature_log_prob_[i] = np.log(counts / counts.sum())

        return self
~~~

核对：`counts.sum()` = 类内总词数 + α×特征数，与 2.6 节公式分母一致；训练后预测只剩矩阵乘法（原课的关键洞见）。

### 4.2 GaussianNB：连续特征的版本

`fit` 对每个类、每个特征记均值与方差（方差加 1e-9 防除零）；先验按类样本占比。预测用高斯密度函数逐特征算、对数空间相加（代码见第五节补充）。

~~~python
# 本块中文说明：从零实现高斯朴素贝叶斯的训练（每类每特征的均值方差）。
class GaussianNB:
    def __init__(self):
        pass

    def fit(self, X, y):
        classes = np.unique(y)
        self.classes_ = classes
        self.means_ = np.zeros((len(classes), X.shape[1]))
        self.vars_ = np.zeros((len(classes), X.shape[1]))
        self.priors_ = np.zeros(len(classes))

        for i, c in enumerate(classes):
            X_c = X[y == c]
            self.means_[i] = X_c.mean(axis=0)
            self.vars_[i] = X_c.var(axis=0) + 1e-9
            self.priors_[i] = X_c.shape[0] / X.shape[0]

        return self
~~~

## 五、把代码运行起来：补充入口与检查

（补充）原文只给出两个类的 `fit`，预测部分按原课“预测 = 矩阵乘法 + argmax”的描述补齐：

~~~python
# 本块中文说明：补充 MultinomialNB 与 GaussianNB 的预测方法。
def predict_log_proba(self, X):
    # 原课公式：X @ log_feature_probs.T + log_class_priors
    return X @ self.feature_log_prob_.T + self.class_log_prior_

def predict(self, X):
    return self.classes_[np.argmax(self.predict_log_proba(X), axis=1)]

MultinomialNB.predict_log_proba = predict_log_proba
MultinomialNB.predict = predict


def gnb_predict(self, X):
    # 每类：log 先验 + 各特征高斯对数密度求和
    scores = np.zeros((X.shape[0], len(self.classes_)))
    for i in range(len(self.classes_)):
        log_pdf = (-0.5 * np.log(2 * np.pi * self.vars_[i])
                   - (X - self.means_[i]) ** 2 / (2 * self.vars_[i]))
        scores[:, i] = np.log(self.priors_[i]) + log_pdf.sum(axis=1)
    return self.classes_[np.argmax(scores, axis=1)]

GaussianNB.predict = gnb_predict
~~~

~~~python
# 本块中文说明：补充的两类两词手算检查入口。
import numpy as np

X = np.array([[4, 1],   # spam 文档：buy x4, meeting x1
              [1, 5]])  # ham  文档：buy x1, meeting x5
y = np.array(["spam", "ham"])

nb = MultinomialNB(alpha=1.0)
nb.fit(X, y)
# 可手算预期（注意 np.unique 按字母序：行 0=ham，行 1=spam）：
# P(buy|ham)=1/4=0.25，P(buy|spam)=5/7≈0.714（对照 0.3 节）
assert abs(np.exp(nb.feature_log_prob_[0][0]) - 0.25) < 1e-12
assert abs(np.exp(nb.feature_log_prob_[1][0]) - 5 / 7) < 1e-12
assert abs(np.exp(nb.class_log_prior_[0]) - 0.5) < 1e-12

# 新邮件 "buy" x1：spam 对数得分应约为 -1.030，ham 约 -2.079
# 注意 np.unique 按字母序排列类别：classes_[0]='ham'，classes_[1]='spam'
scores = nb.predict_log_proba(np.array([[1, 0]]))
assert abs(scores[0][1] - (-1.030)) < 0.001  # spam
assert abs(scores[0][0] - (-2.079)) < 0.001  # ham
assert nb.predict(np.array([[1, 0]]))[0] == "spam"
~~~

补充检查方法：与 sklearn 的 `MultinomialNB(alpha=1.0)` 在同一小数据上比对 `feature_log_prob_` 是否一致（近逐位）；GaussianNB 同理比对 `means_`/`vars_`。

## 七、失败模式、原文边界与工程注意

原课"When Naive Bayes Fails"节 + Common Gotchas 节合并整理：

1. **强特征交互（XOR 型）**：类别取决于两特征的组合而非任一单独，NB 完全抓不到——每个特征单独都无证据，NB 无法非线性组合它们。
2. **强相关特征给出相反证据**：A 说 spam、B 说 ham 且实际完全同涨同跌，NB 会看到“不存在的冲突”。
3. **超大训练集**：数据足够时判别式模型学到真边界、反超 NB；当初帮忙的独立假设开始拖后腿。原课同时指出这些失败在文本上少见（特征多而各自弱、误差抵消），表格数据里强相关特征多时应优先考虑逻辑回归或树模型。
4. **负特征值**：MultinomialNB 要求非负特征；有负值（某些 TF-IDF 设定、标准化后的特征）改用 GaussianNB 或先把特征平移为正。
5. **零方差特征**：GaussianNB 除以方差，某类某特征全同值会崩；原课加 1e-9 平滑防这一手（本课代码已有）。
6. **类别不平衡**：99% 是 ham 时先验 0.99 会压过似然证据；可手动设 class_prior 或重采样。
7. **概率不可信**：NB 说 0.95 时真实可能是 0.7——独立性假设系统性扭曲概率数值（名次常常对、数值常偏激）；要概率就校准（第 6 步的 CalibratedClassifierCV）。
8. **特征缩放**：NB 两个变体都不需要缩放（计数或每特征统计量），这是相对逻辑回归/SVM 的一个优势（原文观点，核对成立）。
9. **平滑 α 不是免费旋钮**：α 过大把分布压平、信息丢失；应作为超参数在验证集上调（补充）。

## 十、术语与完成标准

朴素贝叶斯（Naive Bayes）：带条件独立假设的贝叶斯分类器；条件独立：$P(A,B\mid C)=P(A\mid C)P(B\mid C)$；拉普拉斯平滑：计数加 α 防零概率；先验：$P(\text{class})$；似然：$P(\text{features}\mid\text{class})$；后验：$P(\text{class}\mid\text{features})$；生成式模型：学 $P(X\mid Y)$ 与 $P(Y)$ 再用贝叶斯反推；判别式模型：直接学 $P(Y\mid X)$；对数概率：用 $\log P$ 防连乘下溢。
