## 一、本课到底在解决什么

用户写“付款没成功”，历史工单写“交易被拒绝”。直接查相同词可能找不到，语义检索希望在表达不同而意思接近时仍能匹配。**Embedding（嵌入）**把输入变成一组固定长度数字，之后程序比较数字表示的距离或方向。

本课理论讲神经嵌入和生产检索，Build It 用 TF-IDF 练习相同的数据接口。**用浮点数组存储 TF-IDF，不会让它自动具备理解同义词的能力**。这一界限非常重要。

## 二、从数组到向量空间

`[3,4]` 是二维向量，维度是元素个数，不是文档数量。向量长度（L2 范数）为 `sqrt(3²+4²)=5`；归一化后 `[0.6,0.8]` 的长度是 1。

同一个嵌入模型把每篇文本映射到相同维数 d。N 篇文档组成 `N×d` 的矩阵，查询向量形状是 `d`。数值各维通常没有人能直接命名的独立语义，不能把第一维理解成“猫”、第二维理解成“狗”。同维度但不同模型生成的向量也不能随意混用：它们的坐标系没有对齐。

**稀疏**指大部分坐标为零，典型例子是词袋；**稠密**指信息分布在较多坐标上，常见于神经模型。不能说稠密向量每一维都必然独立承载可解释语义。

## 三、文本表示如何演进

1. **Word2Vec**：通过上下文预测学习单词向量。经典“king−man+woman≈queen”说明可能学习到关系，但不是每个词、每个数据集都成立。一个词只有一个静态向量，难以区分 bank 的河岸/银行含义。
2. **词向量平均**：逐维平均句子中的词。简单，但“狗咬人”和“人咬狗”词相同，平均就相同，丢失顺序。
3. **Transformer/CLS 或 pooling**：模型结合上下文生成 token 表示，再用特殊位置或池化变成句向量。未经相似度任务训练的 CLS 不自动等于好用的检索向量。
4. **Sentence-BERT / 对比学习**：让匹配问题与段落的表示靠近，让不匹配的分开。**正样本对**是应该相似的两段内容，**负样本对**是应该区分的内容。
5. **指令化嵌入**：用 query/document 等任务信息区分用途。前缀按模型说明使用，不能把不同模型的 `query:`、`search_query:` 任意互换。

原课列举 OpenAI、Gemini、Voyage、Cohere、BGE、Qwen、Nomic 等模型和 MTEB 分数。理解比较轴即可：语言、领域、输入长度、维数、部署方式、费用、实际检索质量。排行榜版本和任务权重不同，数字不可直接混比；本文不把原课的旧价格/榜单复述成当前选型结论。

## 四、三种相似度，亲手算一次

设 a=[1,0]，b=[2,0]，c=[0,1]：

| 指标 | 定义与直觉 | a 和 b | a 和 c |
|---|---|---:|---:|
| 点积 | 对应位置相乘后求和 | 2 | 0 |
| 余弦相似度 | 点积除以两者长度，只看方向 | 1 | 0 |
| 欧氏距离 | 对应差值平方求和再开方 | 1 | √2 |

余弦公式为 `sum(a_i*b_i)/(sqrt(sum(a_i²))*sqrt(sum(b_i²)))`。相似度通常越大越近，距离越小越近。原文搜索器把 L2 距离取负，再统一降序排序。零向量的余弦数学上未定义，程序约定返回 0 是工程选择。

单位向量有 `||a−b||²=2−2(a·b)`。因此全部向量归一化且非零时，余弦、点积和负 L2 通常给出同样的排序。原文 demo 三种排名相同是合理结果，不是程序没有运行。

## 五、文档切块、索引与检索

**Chunk** 是可单独检索的文档片段。固定长度切块简单；句子切块保留句界；递归切块先按章节，再按段落/句子继续拆；语义切块根据相邻句子的表示变化找边界。语义切块也有计算成本，不保证总是最好。

原课例：块长 512、重叠 50，移动步长是 462。重叠能缓解边界信息丢失，但不能保证句子绝不切断。太短可能丢失主语、条件，太长可能混合多个主题；256～512 token 只是可试的起点。**原代码用 `split()`，长度单位实际是空白分隔的词，不是模型 token**；中文没有空格时必须换分词方法。

**Index（索引）**是为快速查找准备的数据结构。教学版存向量、文本、来源三个列表，逐个算分，时间约 O(Nd)。HNSW 则用多层邻居图近似搜索：先粗定位再细找；ANN（近似最近邻）以可能漏掉部分真近邻换速度，不承诺普遍固定 O(log N) 或固定召回率。FAISS 是检索库，Chroma/Qdrant/Weaviate 等承担数据库功能，pgvector 是 PostgreSQL 的扩展；是否需要数据库取决于持久化、更新、权限、过滤等需求。

**Bi-encoder（双编码器）**分别编码查询和文档，文档可以提前计算；**Cross-encoder（交叉编码器）**把查询和候选文档一起输入模型，直接评分。常用流水线是先检索几十或上百候选，再重排留下少数，数量需要实验。

## 六、存储优化与质量指标

**Matryoshka（套娃表示）**在训练时让多个前缀维度都可用于任务。支持这种训练的模型可以截取前 d' 维，随后按要求归一化。普通 TF-IDF 截掉后半词表是在删除词，不是复现套娃训练。

float32 每数 4 字节，1536 维向量占 6144 字节；一千万条是 61.44 GB（十进制，未计索引/元数据）。256 维占 1024 字节，原始向量存储缩小 6 倍。二值量化按符号存 1 位，1536 位是 192 字节；只有真正打包成 bit 才实现 32 倍缩小，Python 的整数列表不会自动省到这个大小。**Hamming 距离**是不同 bit 的数量。

相关文档集合 R，返回前 k 个为 S：`Precision@k=|R∩S|/|S|`（固定返回 k 条时分母是 k），`Recall@k=|R∩S|/|R|`。例如共 4 条相关文档，返回 3 条其中 2 条相关，精确率 2/3，召回率 2/4。语义分数高不等于这些指标高。

## 七、原文 Build It：从切块到检索

### 步骤 1：切块

按空白切词，start 每次移动 chunk_size-overlap；句子版按英文句点聚合。词不是模型token，必须检查步长为正。

````python
# 本块中文说明：切块
# 用空白分词并滑窗切块；chunk_size 是词数而非模型 token。
def chunk_text(text, chunk_size=200, overlap=50):
    words = text.split()
    chunks = []
    start = 0
    while start < len(words):
        end = start + chunk_size
        chunk = " ".join(words[start:end])
        chunks.append(chunk)
        start += chunk_size - overlap
    return chunks


def chunk_by_sentences(text, max_chunk_tokens=200):
    sentences = text.replace("\n", " ").split(".")
    sentences = [s.strip() + "." for s in sentences if s.strip()]
    chunks = []
    current_chunk = []
    current_length = 0
    for sentence in sentences:
        sentence_length = len(sentence.split())
        if current_length + sentence_length > max_chunk_tokens and current_chunk:
            chunks.append(" ".join(current_chunk))
            current_chunk = []
            current_length = 0
        current_chunk.append(sentence)
        current_length += sentence_length
    if current_chunk:
        chunks.append(" ".join(current_chunk))
    return chunks
````

### 步骤 2：词表、IDF和向量

fit 统计语料词表和每词的文档频率；embed 为当前文本生成与词表一一对应的TF-IDF坐标并L2归一化。fit学习的是统计量，不是神经网络权重。

````python
# 本块中文说明：词表、IDF和向量
import math
import numpy as np
from collections import Counter

class SimpleEmbedder:
    # 初始化本实例保存的配置和状态；self 指当前对象。
    def __init__(self):
        self.vocab = []
        self.idf = []
        self.word_to_idx = {}

    # 根据整批语料建立词表/统计量；后续查询使用同一套坐标。
    def fit(self, documents):
        vocab_set = set()
        for doc in documents:
            vocab_set.update(doc.lower().split())
        self.vocab = sorted(vocab_set)
        self.word_to_idx = {w: i for i, w in enumerate(self.vocab)}
        n = len(documents)
        self.idf = np.zeros(len(self.vocab))
        for i, word in enumerate(self.vocab):
            doc_count = sum(1 for doc in documents if word in doc.lower().split())
            self.idf[i] = math.log((n + 1) / (doc_count + 1)) + 1

    # 把当前文本编码为与已有词表一致的向量。
    def embed(self, text):
        words = text.lower().split()
        count = Counter(words)
        total = len(words) if words else 1
        vec = np.zeros(len(self.vocab))
        for word, freq in count.items():
            if word in self.word_to_idx:
                tf = freq / total
                vec[self.word_to_idx[word]] = tf * self.idf[self.word_to_idx[word]]
        norm = np.linalg.norm(vec)
        if norm > 0:
            vec = vec / norm
        return vec
````

### 步骤 3：三个距离函数

np.dot 求点积，np.linalg.norm 求范数，零范数时返回约定的0。输入维数必须一致。余弦关注方向，欧氏距离关注差值。

````python
# 本块中文说明：三个距离函数
# 点积除以两向量范数；零向量按代码约定处理。
def cosine_similarity(a, b):
    dot = np.dot(a, b)
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return float(dot / (norm_a * norm_b))


def dot_product(a, b):
    return float(np.dot(a, b))


def euclidean_distance(a, b):
    return float(np.linalg.norm(a - b))
````

### 步骤 4：向量索引

vectors/texts/metadata 三个列表的同一位置属于同一条记录。search逐条算分，用负L2将越小越好转为越大越好，再按降序取前top_k。

````python
# 本块中文说明：向量索引
class VectorIndex:
    # 初始化本实例保存的配置和状态；self 指当前对象。
    def __init__(self):
        self.vectors = []
        self.texts = []
        self.metadata = []

    # 向当前集合加入一项数据。
    def add(self, vector, text, meta=None):
        self.vectors.append(vector)
        self.texts.append(text)
        self.metadata.append(meta or {})

    # 计算候选得分并排序，返回前 top_k 项；返回结果不等于已经生成答案。
    def search(self, query_vector, top_k=5, metric="cosine"):
        scores = []
        for i, vec in enumerate(self.vectors):
            if metric == "cosine":
                score = cosine_similarity(query_vector, vec)
            elif metric == "dot":
                score = dot_product(query_vector, vec)
            elif metric == "euclidean":
                score = -euclidean_distance(query_vector, vec)
            else:
                raise ValueError(f"Unknown metric: {metric}")
            scores.append((i, score))
        scores.sort(key=lambda x: x[1], reverse=True)
        results = []
        for idx, score in scores[:top_k]:
            results.append({
                "text": self.texts[idx],
                "score": score,
                "metadata": self.metadata[idx],
                "index": idx
            })
        return results

    def size(self):
        return len(self.vectors)
````

### 步骤 5：搜索引擎组合

index_documents 把文档切块并配来源，统一拟合词表后逐块编码。search只编码查询并搜索。重复建库需重建索引，避免旧坐标与新坐标混在一起。

````python
# 本块中文说明：搜索引擎组合
class SemanticSearchEngine:
    # 初始化本实例保存的配置和状态；self 指当前对象。
    def __init__(self, chunk_size=200, overlap=50):
        self.embedder = SimpleEmbedder()
        self.index = VectorIndex()
        self.chunk_size = chunk_size
        self.overlap = overlap

    def index_documents(self, documents, source_names=None):
        all_chunks = []
        all_sources = []
        for i, doc in enumerate(documents):
            chunks = chunk_text(doc, self.chunk_size, self.overlap)
            all_chunks.extend(chunks)
            name = source_names[i] if source_names else f"doc_{i}"
            all_sources.extend([name] * len(chunks))
        self.embedder.fit(all_chunks)
        for chunk, source in zip(all_chunks, all_sources):
            vec = self.embedder.embed(chunk)
            self.index.add(vec, chunk, {"source": source})
        return len(all_chunks)

    # 计算候选得分并排序，返回前 top_k 项；返回结果不等于已经生成答案。
    def search(self, query, top_k=5, metric="cosine"):
        query_vec = self.embedder.embed(query)
        return self.index.search(query_vec, top_k, metric)

    def search_with_scores(self, query, top_k=5):
        results = self.search(query, top_k)
        return [
            {
                "text": r["text"][:200],
                "source": r["metadata"].get("source", "unknown"),
                "score": round(r["score"], 4)
            }
            for r in results
        ]
````

### 步骤 6：比较指标

对同一个问题运行三种指标，保留分数和片段预览。已单位归一化的向量可能排名相同，分数本身量纲不同，不直接比较数值大小。

````python
# 本块中文说明：比较指标
def compare_metrics(engine, query, top_k=3):
    results = {}
    for metric in ["cosine", "dot", "euclidean"]:
        hits = engine.search(query, top_k=top_k, metric=metric)
        results[metric] = [
            {"score": round(h["score"], 4), "preview": h["text"][:80]}
            for h in hits
        ]
    return results
````


## 八、运行方法、输出与边界

在课程环境安装 numpy，进入本课目录执行 `python code/embeddings.py`。程序会索引内置文档，打印查询的候选片段、来源、相似度，并比较指标和压缩表示。它不会训练神经模型，也不会下载语言模型。

逐步看数据：`fit` 建词表和 IDF→`embed` 统计 TF×IDF 并归一化→`add` 存文档→`search` 给查询算同坐标系向量→排序取前 k。`word_to_idx` 决定每个词对应哪个坐标。源代码完整 demo 还包括二值化与截断实验。

**核对/补充：**必须保证 `chunk_size>0` 且 `0<=overlap<chunk_size`，否则原 while 循环可能不前进。句子切分按英文句点，不能正确处理所有缩写和中文标点。原 `index_documents` 再次调用会拟合新词表但不清空旧索引，应新建引擎或同时清空重建。全未知词查询变成零向量，即使返回 top-k 也可能全是无意义的零分结果。二值化非负 TF-IDF 主要变成“词是否出现”，不能用这个实验推断神经向量量化效果。

本次不把未运行的 NumPy demo 当实测；验证范围见章导航。下面是可独立理解的补充计算：

```python
import math

a, b = [3, 4], [6, 8]
dot = sum(x*y for x, y in zip(a, b))
na = math.sqrt(sum(x*x for x in a))
nb = math.sqrt(sum(x*x for x in b))
print(dot, dot/(na*nb))  # 预期：50 1.0；长度不同，方向相同
```

真实模型接入时替换 embedder 并重建索引，固定模型版本、维度、预处理、归一化和距离配置。Sentence Transformers 提供本地神经嵌入，Cohere 等提供重排接口；更换它们不改变“先编码再检索”的结构。不能在旧向量库里混入新模型的向量。

## 九、交付物与原文五项练习

在笔记中写一张“嵌入方案卡”：语料语言/类型、块长单位、模型和版本、维度、指标、存储、更新策略、测试集。它对应原文的 embedding advisor 和 patterns 交付物。

1. 固定五个查询，比较三种距离的 top-3；解释归一化后为何可能一致，额外构造非单位向量观察差异。
2. 块长试 50/100/200/500 **词**，比较检索相关性。原课让看最高相似度，但应另标真正相关块，分数涨不等于质量涨。
3. TF-IDF 500 维截成 50/100/200/500，测召回变化，并明确这只是删特征对照，不是 Matryoshka 训练。
4. 正值置 1，零/负值置 0，比较 Hamming top-10 与浮点排名重合度；解释存储打包与语义损失。
5. 换句子切块后比较相关性，添加超长句测试；句子切块也可能超限，需要后备拆分。

学会的标志：能手算余弦，能说明查询与文档为何必须同一套表示，能解释“分词→切块→嵌入→索引”分别做什么。
