## 一、这一课解决什么问题？

聊天系统不只是一段生成回复代码。规则负责确定路径、检索利用固定知识、神经模型生成语言、工具循环连接受控功能。本课把这些路线拆开，再理解何时组合。

## 二、核心概念与推导

从ELIZA模式匹配到PARRY内部状态、ALICE规则库，再到接入后端服务的聊天助手，演进主线是表示、记忆、生成与行动能力的变化，不是旧方法全部失效。历史测试不等于机器人具备通用智能，更不能把模拟心理咨询当真实治疗。

规则式：匹配模式返回模板，可解释但覆盖有限。检索式：匹配已有问答，知识边界清楚但可能检错、过期。seq2seq：直接生成回复，灵活但可能不实。LLM+工具：生成工具请求，执行结果再回到上下文，必须管理权限、参数和终止。

混合架构可将高风险流程交给明确业务逻辑，FAQ优先检索，开放问题再进入生成与工具。检索和RAG都不能保证零幻觉；是否需要混合架构应看任务，不是所有项目一律相同。

### 2.9 用一个小例子把概念串起来（补充）

工具循环的一次完整轨迹：user请求2+3→适配器返回name=add、arguments={a:2,b:3}→程序验证并执行本地加法→tool结果5加入history→模型再返回最终文本。模型说“需要调用”与程序已经执行是两个事件。max_steps只限制调用轮数，授权与真正副作用仍由程序负责。

## 四、Build It：原课分步代码与中文讲解

### 4.1 模板规则回复

RulePattern编译正则，按顺序.match并格式化捕获组。最后(.*)兜底，因此先匹配宽泛规则可能遮挡具体规则。模板不会理解真实意图，大小写忽略也不等于同义表达处理。

~~~python
import re


class RulePattern:
    def __init__(self, pattern, response_template):
        self.regex = re.compile(pattern, re.IGNORECASE)
        self.template = response_template


PATTERNS = [
    RulePattern(r"my name is (\w+)", "Nice to meet you, {0}."),
    RulePattern(r"i (need|want) (.+)", "Why do you {0} {1}?"),
    RulePattern(r"i feel (.+)", "Why do you feel {0}?"),
    RulePattern(r"(.*)", "Tell me more about that."),
]


# 依次匹配规则并返回模板，不是语义推理。
def rule_based_respond(user_input):
    for pattern in PATTERNS:
        m = pattern.regex.match(user_input.strip())
        if m:
            return pattern.template.format(*m.groups())
    return "I don't understand."
~~~

### 4.2 句向量FAQ检索

对FAQ问题预编码，输入向量归一化后点积找最高相似度。低于阈值返回None，让上层决定澄清或转生成；阈值不是置信概率，需用领域验证集标定。

~~~python
from sentence_transformers import SentenceTransformer
import numpy as np


FAQ = [
    ("how do i reset my password", "Go to Settings > Security > Reset Password."),
    ("how do i cancel my order", "Go to Orders, find the order, click Cancel."),
    ("what is your return policy", "30-day returns on unused items, original packaging."),
]


encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
faq_questions = [q for q, _ in FAQ]
faq_embeddings = encoder.encode(faq_questions, normalize_embeddings=True)


# 低相似度返回None，由上层处理未知问题。
def faq_respond(user_input, threshold=0.5):
    q_emb = encoder.encode([user_input], normalize_embeddings=True)[0]
    sims = faq_embeddings @ q_emb
    best = int(np.argmax(sims))
    if sims[best] < threshold:
        return None
    return FAQ[best][1]
~~~

### 4.4 带工具调用的循环

llm是自定义适配器，返回content或单个tool_call字典；这不是任何供应商SDK的即用消息格式。代码检查工具名和args类型，再执行tools[name](**args)并将结果放回history。max_steps限制循环，但工具异常、权限与执行幂等性还需补全。

~~~python
# 教学工具循环，真实操作前必须补权限、schema与异常处理。
def agent_loop(user_message, tools, llm, max_steps=5):
    history = [{"role": "user", "content": user_message}]
    for _ in range(max_steps):
        response = llm(history, tools=tools)
        tool_call = response.get("tool_call")
        if tool_call:
            tool_name = tool_call.get("name")
            args = tool_call.get("arguments")
            if not isinstance(tool_name, str) or tool_name not in tools:
                history.append({"role": "assistant", "tool_call": tool_call})
                history.append({"role": "tool", "name": str(tool_name), "content": f"error: unknown tool {tool_name!r}"})
                continue
            if not isinstance(args, dict):
                history.append({"role": "assistant", "tool_call": tool_call})
                history.append({"role": "tool", "name": tool_name, "content": f"error: arguments must be a dict, got {type(args).__name__}"})
                continue
            fn = tools[tool_name]
            result = fn(**args)
            history.append({"role": "assistant", "tool_call": tool_call})
            history.append({"role": "tool", "name": tool_name, "content": result})
        else:
            return response["content"]
    return "I could not complete the task in the step budget."
~~~

### 4.5 组合为混合聊天

原示例的structured_flow、tools、llm等需要自己提供。用关键词检测危险操作只是教学路由，不是安全边界；否定、隐含意图、多语言都可能绕过或误判。

~~~python
# 关键词分流仅为演示，不能作为安全边界。
def hybrid_chat(user_input):
    if is_destructive_action(user_input):
        return structured_flow(user_input)

    faq_answer = faq_respond(user_input, threshold=0.6)
    if faq_answer:
        return faq_answer

    return agent_loop(user_input, tools, llm)


def is_destructive_action(text):
    danger_words = ["delete", "cancel", "charge", "refund", "transfer"]
    return any(w in text.lower() for w in danger_words)
~~~

## 七、失败模式、原文边界与工程注意

1. 原agent_loop没有完整异常捕获、参数schema校验、身份鉴权和幂等处理，不能直接上线。
2. assistant声称“已发送/已取消”必须与真实工具结果核对。
3. 外部文档也可能包含提示注入；系统提示、简单过滤和计划检查不能保证免疫。
4. 高风险操作需要权限与明确确认；练习只使用mock发送邮件，不实际发送。
5. 工具结果要带来源/调用ID，真实供应商消息协议需另写适配层。
6. max_steps之外仍要管超时、token预算、重试与日志隐私。
7. 来源中的攻击成功率和案例数字属于特定实验背景，不可当作本项目风险概率。
