## 一、这一课解决什么问题？

用户需要直接且有根据的答案，而不是一段貌似相关的文字。本课区分给定篇章抽取、开放域检索+阅读器，以及参数记忆闭卷生成，再把检索与生成接成RAG。

## 二、核心概念与推导

抽取式QA联合编码question/context，预测答案起止位置；输出虽来自上下文，仍可能选错片段或脱离语境，不能说不可能给错误答案。SQuAD2训练包括无答案问题，可结合空答案分数拒答。

RAG先检索top-k，再阅读/生成。检索漏证据与阅读错证据是两类错误，要分开测。dense retriever分别编码query和文档，normalize后点积为余弦。

EM是规范化后的完全匹配，token-F1给重叠部分分。支持问题回答质量、检索召回、引用支持和拒答校准不能用一个相似度代替。RAGAS等框架各指标需要的字段与裁判依版本/配置而不同，不能统称“都不需要gold”。

### 2.9 用一个小例子把概念串起来（补充）

若检索首先没找到发布日期所在文档，reader即使完美也无法从证据抽到日期；这叫召回失败。若文档已含日期但reader选成宣布日期，是阅读错误。原文给定passage中June 29, 2007的字符区间实际为[40,53)，这是字符串计算结果，不需要模型推理。

## 四、Build It：原课分步代码与中文讲解

### 4.1 预训练抽取式QA

qa返回score、字符start/end和answer。原课所示偏移57～70与给定字符串并不一致，应以实际context[start:end]核对；不能照抄参考偏移当标注。SQuAD2管线要显式handle_impossible_answer=True才把空答案候选纳入相应返回行为；score不是跨域可直接当置信概率的标尺。

~~~python
from transformers import pipeline

qa = pipeline("question-answering", model="deepset/roberta-base-squad2")

passage = (
    "Apple Inc. released the first iPhone on June 29, 2007. "
    "The device was announced by Steve Jobs at Macworld in January 2007."
)
question = "When was the first iPhone released?"

answer = qa(question=question, context=passage)
print(answer)
~~~

~~~python
{'score': 0.98, 'start': 57, 'end': 70, 'answer': 'June 29, 2007'}
~~~

### 4.2 稠密检索接抽取阅读器

corpus_embeddings为(N,D)，q_emb为(1,D)，相乘后得到每文档分数。取前k再拼接给qa。拼接后的字符偏移属于combined字符串，不是原文档偏移，需要保存文档与片段映射。原示例question只有四个候选文档，不涉及向量库。

~~~python
from sentence_transformers import SentenceTransformer
import numpy as np

encoder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")

corpus = [
    "Apple Inc. released the first iPhone on June 29, 2007.",
    "Macworld 2007 featured the iPhone announcement by Steve Jobs.",
    "Android launched in 2008 as Google's mobile operating system.",
    "The first iPod was released in 2001.",
]
corpus_embeddings = encoder.encode(corpus, normalize_embeddings=True)


# 原文真实检索：对query编码，与归一化文档向量点积排序。
def retrieve(question, top_k=2):
    q_emb = encoder.encode([question], normalize_embeddings=True)
    sims = (corpus_embeddings @ q_emb.T).squeeze()
    order = np.argsort(-sims)[:top_k]
    return [corpus[i] for i in order]


# 拼接检索段落交给抽取器；返回偏移属于拼接字符串。
def answer(question):
    passages = retrieve(question, top_k=2)
    combined = " ".join(passages)
    return qa(question=question, context=combined)


print(answer("When was the first iPhone released?"))
~~~

### 4.3 生成式RAG接口

检索3段拼进提示词，llm(prompt)负责调用。提示词要求“仅上下文、不知道就说不知道”是约束意图，不是技术保证。外部文档也可能含提示注入，应作为数据而非系统命令；回答需可追溯证据与拒答校准。

~~~python
# llm是外部可调用接口，提示词本身不保证正确或拒答。
def rag_generate(question, llm):
    passages = retrieve(question, top_k=3)
    prompt = f"""Context:
{chr(10).join('- ' + p for p in passages)}

Question: {question}

Answer using only the context above. If the context does not contain the answer, say "I don't know."
"""
    return llm(prompt)
~~~

### 4.4 真实评估维度

除了EM/token-F1，还要看人工语义正确、引用是否支持、可答/不可答拒答错误及检索召回。引用字符串确实来自检索结果，只证明引用存在，不证明它蕴含回答；需语义/人工核验。



### 4.5 RAGAS与指标条件

faithfulness检查回答断言与上下文支持；answer relevance看是否回答问题；context precision/recall衡量证据质量。某些context recall指标需要参考答案或标注；原文“一律reference-free”的表述不准确。框架名不是已完成评估的证明。

## 七、失败模式、原文边界与工程注意

1. 无证据时不应强抽一个跨度；应有无答案集和阈值校准。
2. cosine=0.3不能跨embedding模型通用，要在留出问题上调。
3. 检索引用命中不等于断言被支持；句子可能含否定或条件。
4. 单段抽取也会选错人物/时间，不能把“来自源文”当正确充分条件。
5. 40～60%幻觉减少、7～9题正确等均非本文实验结论。
6. 有拒答提示词不等于已经有安全拒答机制。

## 九、Exercises：保留原课练习与验收方法

1. Easy：10段维基+10问，另加不可答问题，保存答案跨度、字符偏移和人工判定。
2. Medium：加检索阈值拒答，在留出集画覆盖率—错误率，不把0.3当固定答案。
3. Hard：约1万文档构建BM25+dense+RRF，对比同一阅读器下的回答与检索指标；分类记录哪类问题受益。

## 十、术语与完成标准

reader：基于证据读出答案；retriever：候选证据检索；EM：规范化完全匹配；token-F1：答案词重叠；faithfulness：相对给定证据的支持；拒答校准：可答性与风险权衡。

完成检查：

- 能说明RAG的检索与阅读两层错误。
- 能用字符串切片核对答案偏移。
- 能区分引文存在与引文支持。
- 能设计不可答集而不只展示成功问答。
