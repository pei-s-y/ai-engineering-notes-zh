### 0.1 先理解这一课在做什么

原课开头的三个问题其实是一个问题：“A是否支持B？”——摘要里有没有幻觉（原文A是否支持摘要B）、聊天机器人答的“是”有没有依据（检索段落A是否支持回答B）、一万篇没有标注的文章怎么分类（文章A是否支持“这是体育新闻”这个说法B）。NLI（Natural Language Inference，自然语言推断）就是把这个判断做成一个三分类器：给一对句子，输出“支持/反对/无关”。对应关系一张表看齐：

| 生产问题 | 前提A | 假设B | 用NLI怎么答 |
|---|---|---|---|
| 摘要有幻觉吗 | 原文档 | 摘要的每条断言 | 不是蕴含→疑似幻觉 |
| 回答有据吗 | 检索段落 | 生成的回答 | 不是蕴含→疑似编造 |
| 没标注怎么分类 | 待分类文档 | “这是关于X的” | 逐标签比蕴含分，取最大 |

这也是原课说“每个RAG评估框架都内嵌一个NLI模型”的原因——三个问题共用一个判断器。

类比：NLI像一个只回三个字的法官。你递上去两份材料——第一份叫**前提**（premise，当证词读），第二份叫**假设**（hypothesis，当断言读）——法官只回三个词之一：**“成立”**（读了证词必然承认断言，蕴含entailment）、**“不成立”**（读了证词必然否认断言，矛盾contradiction）、**“无关”**（证词没提这事，中立neutral）。

注意它判的是“普通人读出来的意思”，不是形式逻辑证明：John walked his dog在NLI里蕴含John has a dog，但严格的一阶逻辑要你先公理化“遛狗者拥有狗”——NLI把语用常识打包进了标注约定。这也是它“既能用又不能全信”的根源。与[第03课](<03：词向量与从零实现 Word2Vec.md>)相似度的对照：相似度是对称的、只问“像不像”；NLI有方向、问“能不能推出”——0.3给方向的例子。

### 0.2 本课术语先翻成白话

- premise（前提）=第一句话，被当作证据的一边
- hypothesis（假设）=第二句话，被检验的断言
- entailment（蕴含）=读前提必然承认假设为真
- contradiction（矛盾）=读前提必然认定假设为假
- neutral（中立/信息不足）=前提信息不够，两个方向都推不出
- RTE=Recognizing Textual Entailment，NLI的旧名字、同一任务
- hypothesis-only捷径=模型只看假设就能猜对标签（假设带not就猜矛盾）——数据集标注漏洞
- 词面重合 lexical overlap=两句话字面重叠多，容易被误当蕴含
- 零样本分类 zero-shot classification=没有训练标签，把候选标签写成假设来比蕴含分
- 忠实性 faithfulness=答案对“给定来源”的忠实程度
- 真实性 truthfulness=答案对“真实世界”的忠实程度——两者不是一回事
- 原子claim（atomic claim）=把长答案拆成一条条可独立核对的小断言
- SNLI/MultiNLI/ANLI/DocNLI=数据集家族：图像说明→十种文体→人工对抗→长文档，一个比一个难
- 模板 hypothesis template=零样本分类里把标签写成句子的句式；换句式结果能差10点以上（原课参考）

### 0.3 用小数字走一遍

三对句子，前提固定为“猫在沙发上睡觉”（The cat is sleeping on the couch），换三个假设：

| # | 假设 | 人工判定 | 模型三分数（示例） |
|---|---|---|---|
| 1 | 房间里有一只猫 | 蕴含 | E=0.91、N=0.06、C=0.03 |
| 2 | 猫正在院子里疯跑 | 矛盾 | C=0.94、N=0.04、E=0.02 |
| 3 | 猫饿了 | 中立 | N=0.72、E=0.21、C=0.07 |

三个读法：（1）每行三分数之和=1（softmax归一化，与0.3表内数字一致），决策取最大者——0.91对0.06的碾压对应“读起来必然承认”；（2）第3行别小看E=0.21：睡觉的猫和饿不饿有点弱关联，但“有点可能”不等于“能推出”，这正是neutral和entailment的分界；（3）分数不是校准好的事实概率——0.91不等于“91%为真”（第七节第3条），is_faithful里那个threshold=0.5要按任务校准。注意本表数字是本节的示例值，与4.1代码注释里的0.97/0.02/0.01（原课参考）不是同一次输出——形态相同、数值不必对齐。

方向性小实验：把第1对反过来——“房间里有一只猫”当前提、“猫在沙发上睡觉”当假设——判定立刻从蕴含变成中立：房间里有猫推不出它正在沙发上睡觉。前提和假设不能随便交换，这是NLI与相似度（相似度对称）的本质区别。

再放一个陷阱对：前提“The dog chased the cat.”、假设“The cat chased the dog.”——词面几乎全部重合，但主宾互换后不能判蕴含（模型若靠词面重合走捷径，这里必错）；这类样本是HANS/ANLI数据集专门用来打词面启发式的。

以上是用于理解的算例，不是新增的训练或性能实测。读下面的公式时，把每个符号先对应回这里的对象。

### 0.4 怎样连接到正文代码

4.1 nli pipeline把（前提，假设）送进bart-large-mnli、返回三分数列表——0.3的三分数就是它的输出形态（top_k=None拿全标签）。4.2 zs zero-shot pipeline把候选标签写成假设、逐个跑4.1、比蕴含分——0.3表第1行用法的放大。4.3 is_faithful是最小版忠实性检查（整句当假设、阈值0.5）；实际要做的是拆原子claim再逐条核对。4.4是词面重合+否定检测的基线——0.3的陷阱对就是它的死穴。第五节unwrap_scores处理pipeline返回的嵌套结构。

**参考答案：** 不是。前者是neutral（信息不足），后者是contradiction（矛盾）；混为一谈会损失诊断信息——第七节第6条“合称幻觉损失诊断信息”说的就是这个。

## 一、这一课解决什么问题？

判断A是否支持B，比判断两句话是否相似更细。本课将NLI用于零样本分类和回答证据检查，同时明确“没有证据支持”与“已经证明是假的”并不一样。

## 二、核心概念与推导

输入premise前提与hypothesis假设，输出三类：entailment蕴含；contradiction矛盾；neutral中立/信息不足。例如“猫在垫子上”支持“存在一只猫”，反对“不存在猫”，但不能推断“猫饿了”。方向不能反过来随意交换。

（补充 2026-11-06）“方向不能反过来”给一个可手查的直觉：蕴含像“从具体场面到必然事实”——“猫在沙发上睡觉”描述世界的某个具体场面，而“房间里有一只猫”是这个场面必然带来的一般事实。反过来问就变成“从一般推具体”（房间里有猫→它在沙发上睡觉），信息不够、只能neutral。记一个方向口诀：**蕴含沿“具体→一般”成立，反向多半中立**。三分类的判定可以用“两问法”自测：先问“前提为真时，假设还可能为假吗？”——不可能为假→蕴含；必然为假→矛盾；可能真也可能假→中立。0.3表的三行都能用这两问复判一遍。

NLI是带语用与数据集约定的自然语言判断，不是完整形式逻辑证明器。编码器将文本对送入分类头；SNLI偏图像描述，MultiNLI跨文体，ANLI对抗样本更难，DocNLI/ConTRoL涉及更长文档。跨领域性能不能由训练集内成绩保证。

（补充 2026-11-06）四个数据集按难度和用途排队，方便记忆：

| 数据集 | 前提来源 | 特点 |
|---|---|---|
| SNLI | 图像说明文字 | 域窄、量大、带标注捷径 |
| MultiNLI | 十种文体 | 通用训练主力 |
| ANLI | 人工对抗构造 | 专门骗模型，最难 |
| DocNLI/ConTRoL | 长文档 | 测多跳与长程推理 |

（补充 2026-11-06）hypothesis-only捷径为什么值得单独警惕：SNLI的假设里，带not/nobody/never的句子高频对应矛盾标签——模型只看假设、遮住前提也能拿约60分（原课参考），等于考试只读了半张卷子。这提醒两件事：评估时要跑hypothesis-only基线（把前提遮住测一遍，比较掉多少分）；训练集的统计捷径会以“高准确率”的面目出现，越好看越可疑。词面重合启发式（“前提的词大多出现在假设里就判蕴含”）同理：在SNLI上不差，在HANS/ANLI上崩——数据集按“专门打某种捷径”设计时，捷径的得分就是作弊得分。

零样本分类：把候选类别写成假设，比较蕴含分数。标签措辞、模板、单标签/多标签归一化都影响结果。

忠实性：先拆原子claim，再检查每条是否被检索内容支持。未被支持可能是检索漏证、截断、表达变化或分类器错误，不能直接断言现实中为假。faithfulness针对给定来源，truthfulness针对真实世界，二者有区别。

（补充 2026-11-06）faithfulness与truthfulness的区分用两个场景记牢：模型严格按检索到的错误资料作答——对来源忠实（faithful）、对世界不真（not truthful）；模型跳过资料直接给出正确答案——对世界真、对来源不忠实（若业务要求“只依据资料作答”，这就是违规）。所以faithfulness回答的是“有没有越出证据说话”，不是“说的是不是实话”；资料本身的质量是[第14课](<14：信息检索——BM25、稠密向量、RRF与重排.md>)和[第23课](<23：RAG切块——固定、递归、语义、父子与上下文增强.md>)的领地。“未被支持≠现实中为假”的处置动作再列一遍：补检索、查截断、改写法、人工复核——唯独不要直接判假。[第27课](<27：LLM评估——RAGAS、DeepEval、G-Eval与人工校准.md>)的faithfulness指标正是本课is_faithful的工业版：拆原子claim、逐条NLI、按支持比例汇总（2.9的0.75就是那个比例）。

### 2.9 用一个小例子把概念串起来（补充）

前提Alice gave Bob a book支持Bob received a book，不能支持Bob gave Alice a book。三句话大部分词相同，说明相似度不是推断。若回答含4条claim，3条有证据，教学faithfulness=0.75；这不表示剩下那条现实中有75%概率为真，也不表示整篇答案满足业务要求。

## 四、Build It：原课分步代码与中文讲解

### 4.1 运行NLI模型

top_k=None希望拿到全部类别。原例后面[0]取值依赖pipeline返回是否有batch嵌套；不同调用形态可能得到list[dict]或list[list[dict]]，应先打印type与结构再访问。原注释0.97等是示意，不能照抄为实测。

~~~python
from transformers import pipeline

nli = pipeline("text-classification",
               model="facebook/bart-large-mnli",
               top_k=None)  # return all labels; replaces deprecated return_all_scores=True

premise = "The cat is sleeping on the couch."
hypothesis = "There is a cat in the room."

result = nli({"text": premise, "text_pair": hypothesis})[0]
print(result)
# [{'label': 'entailment', 'score': 0.97},
#  {'label': 'neutral', 'score': 0.02},
#  {'label': 'contradiction', 'score': 0.01}]
~~~

### 4.2 NLI变零样本分类

按candidate_labels分别构造假设。默认单标签分数在候选之间归一化；多标签设置与逐对三类softmax含义不同。没有用于微调的新标签不等于完全不需要标注验证集。

~~~python
zs = pipeline("zero-shot-classification", model="facebook/bart-large-mnli")

text = "The stock market rallied after the central bank cut interest rates."
labels = ["finance", "sports", "politics", "technology"]

result = zs(text, candidate_labels=labels)
print(result)
# {'labels': ['finance', 'politics', 'technology', 'sports'],
#  'scores': [0.92, 0.05, 0.02, 0.01]}
~~~

### 4.3 检查回答支持度

源码把整个answer当一条假设且固定找entailment字符串，因此不等于完整原子claim评估。需检查label大小写、返回结构与长上下文截断；阈值0.5应校准。不同版本RAGAS可能用LLM判别，不是所有框架都内置同一NLI模型。

~~~python
# 整句教学判断，实际应拆claim并核对标签与输出结构。
def is_faithful(answer, context, threshold=0.5):
    result = nli({"text": context, "text_pair": answer})[0]
    entail = next(s for s in result if s["label"] == "entailment")
    return entail["score"] > threshold
~~~

### 4.4 理解词面启发式基线

原课指向仓库标准库toy，不是神经训练实现。词重合+否定检测可演示输入输出，但遇到主客体交换与双重否定容易错；不能把它当真正逻辑证明。

## 七、失败模式、原文边界与工程注意

1. hypothesis-only基线能揭示标注捷径，不代表模型学会推理。
2. 词重合、子序列与否定规则在HANS/ANLI类困难样本容易失效。
3. 蕴含分数不是校准好的事实概率。
4. 原文90%准确率、20F1下降与模板10点波动属于来源描述，不是所有任务定律。
5. 文档长度超上限的截断可能恰好删掉证据或假设，需分段证据检索与覆盖检查。
6. neutral与contradiction必须分开；合称“幻觉”会损失诊断信息。
