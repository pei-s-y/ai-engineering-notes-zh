> 整理日期：2026-10-25。按原项目第五阶段全部29课整理，不按研究方向删课。原有第01、02课保留，本次新增第03—29课。必要代码在对应Markdown正文内，不创建代码附件、独立脚本或独立Ship It文件。

## 一、从哪里开始

直接按01→29顺序学习即可。下面分类只帮助理解关系，不要求跳过任何课：

- 01—04：文字怎样变成词和向量。
- 05—07：情感、实体、词性与句法等理解任务。
- 08—12：从序列网络到注意力、翻译与摘要。
- 13—17：问答、搜索、主题、传统生成与聊天。
- 18—23：多语言、子词、结构化、NLI、embedding和切块。
- 24—26：把跨句实体与关系变成可溯源的知识。
- 27—29：评价、长上下文与多轮状态管理。

你已学过的课可以先用完成清单复盘，再继续下一课；是否加深或略读由你决定。本章按NLP课程本身组织，保留完整内容供学习者自行选择。

## 三、每课怎样使用这份笔记

新增各课均按以下结构编排：问题→概念与算例→操作前准备→Build It逐步讲解和代码→补充入口与结果检查→Use It→失败模式/纠错→中文Ship It模板→原课练习→术语与完成清单→验证范围/许可。前两篇保留已有细化结构。

学习时可以分三遍：

1. 先读问题、概念和小例子，自己说出输入/输出是什么，尤其分清字符、token、向量和标签。
2. 再看Build It，按依赖顺序在自己的WSL练习环境里逐块运行；把补充入口中的变量先准备好。不要把包含>>>的交互展示、注释占位或省略号当完整脚本直接执行。
3. 最后核对结果、失败模式与练习。先完成Easy；Medium/Hard也完整保留，等数据、算力或前置知识具备再做，不要求首次读完就全部训练成功。

原文代码与修正版分开标识。保留来源代码不代表它无错；紧接的解释会指出缺变量、伪接口、API版本或逻辑问题。练习中涉及发送邮件、预订、付款等一律先使用mock，本套笔记没有执行外部动作。

## 四、WSL操作和依赖约定

在Ubuntu中，先进入课程仓库；下面使用通用示例目录，请按实际位置替换：

~~~bash
cd ~/projects/ai-engineering-from-scratch
python3 --version
python3 -m pip --version
~~~

先激活你原有的虚拟环境，再检查python和pip是否属于同一环境。不确定环境名时不要照抄不存在的激活路径。若确实还没有环境，可在自己的练习项目中创建一次：

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version
~~~

笔记里的python -m pip install只供你按课选择安装，本次未替你安装。Windows Python与WSL Python的包、GPU配置不共享；看到Windows里已经安装，不等于Ubuntu也有。GPU版本PyTorch要结合你WSL驱动与官方安装配置，不能将一条通用pip命令当GPU必定可用保证。

建议先跑标准库小例子，再按课安装NumPy/scikit-learn等，最后才下载预训练模型。不要为了这一章把全部大型模型一次下载。原文模型名、库版本与下载权限可能变化，笔记已标出易漂移部分；遇到报错请保留完整错误、Python版本、所在系统及包版本。

## 六、阅读中反复注意的区别

- 形状正确不等于训练成功；训练集拟合不等于泛化。
- 相似度不等于概率，NLI支持不等于现实事实已证明。
- 合法JSON/schema不等于正确内容、无幻觉或操作已获授权。
- 字符数、空格词数、模型token数不能混用。
- 命中至少一条的hit rate与多相关证据的严格Recall不是同一个指标。
- 原文效果数字、成本、排行榜与固定阈值是来源背景，不是本次实测，也不是通用定律。
