## 零、初学者先读：为什么“判断正负面”是个好练兵场

> 2026-11-04 新增的教学补充。首次学习先读本节，再进入后面的公式、原课代码与纠错。需要回看词袋与TF-IDF时，先读[第02课](<02：词袋模型、TF-IDF与文本表示.md>)。

### 0.1 先理解这一课在做什么

"The food was not great."是正面还是负面？情感分析看起来只是给评论贴正/负标签，它成为NLP“标准任务”的原因恰恰是：每个看似简单的例子都藏着一个难题。否定翻转意思（not good）；讽刺整个反转（“哦这电影真是太棒了”）；"Not bad at all"有两个负面词却整体是正面；同一个词在不同领域褒贬相反（tight在音乐评测是好评，在时装评测是差评）。

经典做法只有两步：**表示**——用第02课的BoW/TF-IDF把文本变成特征向量；**分类**——在标注好的样本上拟合一个线性模型（朴素贝叶斯或逻辑回归）。本课是前面几课的“表示”第一次真正接到“预测”上，也是你第一次完整走完训练→推理→评估的闭环。

### 0.2 本课术语先翻成白话

- polarity（极性）=正面/负面这个标签本身
- aspect（方面）=评价针对的对象；“相机很好但电池糟糕”是两个方面两种极性
- 先验 P(c)=训练数据里类别c占的比例
- 条件概率 P(w|c)=在c类文本里，词w出现的频率
- 朴素（naive）=给定类别后假设词与词独立——一个明知不对的简化
- 平滑 smoothing=给没见过的词留一个小概率，避免概率为0
- 下溢 underflow=许多小数连乘后小于浮点数下限、变成0.0的数值问题
- logit=过sigmoid之前的原始分数
- L2正则=在损失里惩罚大权重，防止模型记忆训练样本
- macro-F1=每个类的F1各自算完再等权平均

### 0.3 用小数字走一遍

两类各5句的训练集。预测"terrible acting"：NB分别算logP(负)+logP(terrible|负)+logP(acting|负)与正类的对应分数，选大的。为什么取log：P通常是0.001量级，连乘几十次就会小于计算机能表示的最小正数；log把连乘变成连加，数值就稳了。

评估小例：y_true=[1,1,0,0]、y_pred=[1,0,1,0] → TP=FP=FN=TN各1 → P=R=F1=0.5。

否定处理："not good"在词袋里只是{not, good}，good的正面权重会把它拉向正面；把否定词之后的词改写成NOT_good，就多了一个可以单独学负权重的特征。

以上是用于理解的算例，不是新增的训练或性能实测。读下面的公式时，把每个符号先对应回这里的对象。

### 0.5 理解检查（含参考答案）

**问题1：** NB的“朴素”指什么？为什么明知假设不对还能用？

**参考答案：** 给定类别后假设词与词条件独立。文本特征稀疏、数据量中等时，分类器关心每个词往哪边倒多过于词之间怎样联动，错误假设的影响常被抵消，所以结果意外地强。

**问题2：** 预测时为什么用log相加而不是概率相乘？

**参考答案：** 避免下溢——多个小概率连乘会小于浮点数最小值变成0；取log把乘法变加法，argmax结果不变。

**问题3：** 训练集90%是正面时，恒预测“正面”的模型accuracy是多少？说明什么？

**参考答案：** 90%。所以不平衡数据不能只看accuracy，要用macro-F1、逐类P/R、混淆矩阵，并亲自读错误样本。

## 一、这一课解决什么问题？

本课把文本表示接到分类器上：判断一段评论的情感。否定、讽刺、领域词义和方面评价让“正/负”看似简单的任务变复杂。先建立可解释基线，再用错误样本说明是否需要更丰富的表示。

## 二、核心概念与推导

### 2.1 两步流程，与NB为什么“笨但能用”

经典情感分析=表示+分类：先用BoW/TF-IDF或n-gram把文本变特征向量，再在标注样本上拟合线性模型。朴素贝叶斯是“能用的最笨模型”：给定类别后假设所有特征条件独立——这假设明显错误（good和great常一起出现在正面影评里），效果却惊人地强。原课的解释：稀疏文本特征加中等数据量时，分类器关心**每个词往哪边倒**，多于词与词之间怎样联动。

使用类先验P(c)与词条件概率P(w|c)，预测用对数相加避免大量小概率相乘下溢：
$$score(c)=\log P(c)+\sum_w count(w,d)\log P(w|c)$$
加alpha平滑让某类别未见的词仍有非零概率，否则某词概率为0会让log爆炸；alpha=1.0是教学默认，实践常用0.01。这个“朴素”的具体代价：模型无法自己表达not good这种**组合特征**（除非把它当bigram特征输入）——这正是否定处理与逻辑回归的切入点。

### 2.2 逻辑回归：每个特征学一个带符号的权重

逻辑回归用z=Xw+b，σ(z)给出二分类概率，通过交叉熵训练。梯度Xᵀ(p−y)/N加L2项；L2对稀疏文本特征尤其重要，没有它模型容易记忆训练样本（从0.01开始调）。它不作朴素贝叶斯的条件独立假设，每个特征可以学到负权重——not good作为bigram特征能拿到负权重，这是NB对没标注过的bigram做不到的。但它也不会从unigram向量中恢复已丢失的词序；NB同样能使用bigram特征，不是只有LR可以。

### 2.3 评估：不平衡时accuracy会说谎

真实情感语料常70～80%偏一类，恒预测多数类的分类器就有80% accuracy却毫无价值。原课evaluate只计算“1类”为正类的precision、recall、F1和混淆计数，不等于macro-F1。macro-F1要分别算各类F1再等权平均，不能先平均P/R再算。单标签全类别micro-F1等于accuracy；不平衡数据上报micro-F1会得到一个被多数类主导的虚高数字。95:5的严重不平衡要改看AUROC/AUPRC，AUPRC对少数类更敏感。

### 2.4 用一个小例子把概念串起来（补充）

用两个正面词good/great、两个负面词bad/awful构成小数据。NB遇到good时比较logP(正)+logP(good|正)与负类对应分数，不需要把整句概率连乘。若4条评价里TP=FP=FN=TN=1，则正类precision=recall=F1=0.5；这不是宏F1的定义。反例not good展示词袋忽略否定为什么会错。

### 4.2 从零实现多项式朴素贝叶斯

train_nb接收类别→分词文档列表，统计先验和每类词总数；alpha×|V|构成平滑分母。predict_nb对已知词累加对数概率，忽略OOV，最后选分数最大类；返回类名，不返回校准概率。需要每类有数据、总语料非空、alpha>0。

~~~python
import math
from collections import Counter


# 按类别统计先验与加alpha平滑的词条件概率。
def train_nb(docs_by_class, vocab, alpha=1.0):
    class_priors = {}
    class_word_probs = {}
    total_docs = sum(len(d) for d in docs_by_class.values())

    for cls, docs in docs_by_class.items():
        class_priors[cls] = len(docs) / total_docs
        counts = Counter()
        for doc in docs:
            for token in doc:
                counts[token] += 1
        total = sum(counts.values()) + alpha * len(vocab)
        class_word_probs[cls] = {
            w: (counts[w] + alpha) / total for w in vocab
        }
    return class_priors, class_word_probs


# 累加对数概率并返回最大分数类别，不直接输出概率。
def predict_nb(doc, class_priors, class_word_probs):
    scores = {}
    for cls in class_priors:
        s = math.log(class_priors[cls])
        for token in doc:
            if token in class_word_probs[cls]:
                s += math.log(class_word_probs[cls][token])
        scores[cls] = s
    return max(scores, key=scores.get)
~~~

### 4.3 从零实现二分类逻辑回归

X形状(N,V)，y形状(N,)，标签为0/1。初始化全0，批量梯度下降更新w和b。l2*w对应损失中(l2/2)||w||²。clip让sigmoid数值更稳定，但不应把它当完整优化器。阈值0.5可调，是否调整须在验证集确定。

~~~python
import numpy as np


def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-np.clip(x, -20, 20)))


# X为N×V矩阵，y为0/1向量；进行批量梯度下降。
def train_lr(X, y, epochs=500, lr=0.05, l2=0.01):
    n_features = X.shape[1]
    w = np.zeros(n_features)
    b = 0.0
    for _ in range(epochs):
        logits = X @ w + b
        preds = sigmoid(logits)
        err = preds - y
        grad_w = X.T @ err / len(y) + l2 * w
        grad_b = err.mean()
        w -= lr * grad_w
        b -= lr * grad_b
    return w, b


def predict_lr(X, w, b):
    return (sigmoid(X @ w + b) >= 0.5).astype(int)
~~~

### 4.4 处理否定作用域

遇到否定词后给后续词加NOT_前缀，直到终止标点。这是启发式，不理解双重否定、从句或转折。tokenizer若提前删掉标点，作用域重置就会失效；若统一小写，别在后续处理中不小心丢掉特征约定。

~~~python
NEGATION_WORDS = {"not", "no", "never", "nor", "none", "nothing", "neither"}
NEGATION_TERMINATORS = {".", "!", "?", ",", ";"}


# 否定词后加前缀，遇到指定标点重置。
def apply_negation(tokens):
    out = []
    negate = False
    for token in tokens:
        if token in NEGATION_TERMINATORS:
            negate = False
            out.append(token)
            continue
        if token in NEGATION_WORDS:
            negate = True
            out.append(token)
            continue
        out.append(f"NOT_{token}" if negate else token)
    return out
~~~

~~~pycon
>>> apply_negation(["not", "good", "at", "all", ".", "but", "funny"])
['not', 'NOT_good', 'NOT_at', 'NOT_all', '.', 'but', 'funny']
~~~

### 4.5 评估而非只看准确率

TP、FP、FN、TN按1类为正统计，分母为0时约定返回0。原文强调逐类P/R、macro与weighted-F1、混淆矩阵和错误样本；极端不平衡时再结合PR曲线/AUPRC等。AUPRC依赖正类定义与基线比例；不能只传离散标签就声称评估了完整排序曲线。

~~~python
# 这里只计算1类的二分类指标，不是macro平均。
def evaluate(y_true, y_pred):
    tp = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 1)
    fp = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 1)
    fn = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 0)
    tn = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 0)
    precision = tp / (tp + fp) if tp + fp else 0
    recall = tp / (tp + fn) if tp + fn else 0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0
    return {"tp": tp, "fp": fp, "tn": tn, "fn": fn, "precision": precision, "recall": recall, "f1": f1}
~~~

## 六、Use It：使用现成工具

Pipeline把fit时学习的TF-IDF与分类器绑定，防止部署重写分词/词表。下方pipe.score返回accuracy，不是F1；原文强调的完整评估要另算。C越小通常正则越强，不要把它与手写l2参数同方向对应。原文的75%→85%等是未在本文复现的参考，不能当这套参数的性能保证。

~~~python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

pipe = Pipeline([
    ("tfidf", TfidfVectorizer(ngram_range=(1, 2), min_df=2, sublinear_tf=True, stop_words=None)),
    ("clf", LogisticRegression(C=1.0, max_iter=1000)),
])
pipe.fit(X_train, y_train)
print(pipe.score(X_test, y_test))
~~~

原课对Pipeline三个参数的解释（数字未在本文复现，仅作思路参考）：stop_words=None保留停用词，因为not本身携带否定信息，删掉会破坏not_good这类特征；ngram_range=(1,2)引入bigram，not good成为独立特征（sklearn用空格连接两词）；sublinear_tf=True压低同一词重复出现的增益。原课称这三个开关是SST-2上75%与85%基线的差别。

**何时换Transformer**（原课标准，思路参考）：讽刺检测；长评论中途情感转折；方面级情感（“相机很好但电池糟糕”要把情感归属到方面）；低资源语言的零样本基线（多语BERT免费给一个起点）。都不涉及的话，TF-IDF+bigram+否定处理的NB/LR仍是2026年的生产基线。

## 七、失败模式、原文边界与工程注意

1. 停用词删除可能误删否定；保留并非保证理解否定。
2. L2不是没有它就必然记忆训练集，强度要验证；class_weight也不是自动修复所有不平衡。
3. 原文说讽刺、方面情感“只能Transformer”过于绝对；也不能说未在情感数据上训练的多语BERT自动具有可靠零样本情感能力。
4. 类别比例70～80%不是所有语料的固定规律，应先看实际标签分布。
5. 二分类随机基线不一定50%，要说明平衡与抽样方式；多数类基线同样要报告。
6. 只在同一划分、预处理和指标上比较实验，别把论文数值当自己的基线。
