## 一、这一课解决什么问题？

本课把文本表示接到分类器上：判断一段评论的情感。否定、讽刺、领域词义和方面评价让“正/负”看似简单的任务变复杂。先建立可解释基线，再用错误样本说明是否需要更丰富的表示。

## 二、核心概念与推导

两步：表示文本→预测标签。多项式朴素贝叶斯使用类先验P(c)与词条件概率P(w|c)，在给定类别下假设词出现条件独立。预测用对数相加避免大量小概率相乘下溢：
$$score(c)=\log P(c)+\sum_w count(w,d)\log P(w|c)$$
加alpha平滑让某类别未见的词仍有非零概率。

逻辑回归用z=Xw+b，σ(z)给出二分类概率，通过交叉熵训练。梯度Xᵀ(p−y)/N加L2项；它不作朴素贝叶斯的条件独立假设，但也不会从unigram向量中恢复已丢失的词序。NB同样能使用bigram特征，不是只有LR可以。

原课evaluate只计算“1类”为正类的precision、recall、F1和混淆计数，不等于macro-F1。macro-F1要分别算各类F1再平均，不能先平均P/R再算。单标签全类别micro-F1等于accuracy。

### 2.9 用一个小例子把概念串起来（补充）

用两个正面词good/great、两个负面词bad/awful构成小数据。NB遇到good时比较logP(正)+logP(good|正)与负类对应分数，不需要把整句概率连乘。若4条评价里TP=FP=FN=TN=1，则正类precision=recall=F1=0.5；这不是宏F1的定义。反例not good展示词袋忽略否定为什么会错。

### 4.2 从零实现多项式朴素贝叶斯

train_nb接收类别→分词文档列表，统计先验和每类词总数；alpha×|V|构成平滑分母。predict_nb对已知词累加对数概率，忽略OOV，最后选分数最大类；返回类名，不返回校准概率。需要每类有数据、总语料非空、alpha>0。

~~~python
import math
from collections import Counter


# 按类别统计先验与加alpha平滑的词条件概率。
def train_nb(docs_by_class, vocab, alpha=1.0):
    class_priors = {}
    class_word_probs = {}
    total_docs = sum(len(d) for d in docs_by_class.values())

    for cls, docs in docs_by_class.items():
        class_priors[cls] = len(docs) / total_docs
        counts = Counter()
        for doc in docs:
            for token in doc:
                counts[token] += 1
        total = sum(counts.values()) + alpha * len(vocab)
        class_word_probs[cls] = {
            w: (counts[w] + alpha) / total for w in vocab
        }
    return class_priors, class_word_probs


# 累加对数概率并返回最大分数类别，不直接输出概率。
def predict_nb(doc, class_priors, class_word_probs):
    scores = {}
    for cls in class_priors:
        s = math.log(class_priors[cls])
        for token in doc:
            if token in class_word_probs[cls]:
                s += math.log(class_word_probs[cls][token])
        scores[cls] = s
    return max(scores, key=scores.get)
~~~

### 4.3 从零实现二分类逻辑回归

X形状(N,V)，y形状(N,)，标签为0/1。初始化全0，批量梯度下降更新w和b。l2*w对应损失中(l2/2)||w||²。clip让sigmoid数值更稳定，但不应把它当完整优化器。阈值0.5可调，是否调整须在验证集确定。

~~~python
import numpy as np


def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-np.clip(x, -20, 20)))


# X为N×V矩阵，y为0/1向量；进行批量梯度下降。
def train_lr(X, y, epochs=500, lr=0.05, l2=0.01):
    n_features = X.shape[1]
    w = np.zeros(n_features)
    b = 0.0
    for _ in range(epochs):
        logits = X @ w + b
        preds = sigmoid(logits)
        err = preds - y
        grad_w = X.T @ err / len(y) + l2 * w
        grad_b = err.mean()
        w -= lr * grad_w
        b -= lr * grad_b
    return w, b


def predict_lr(X, w, b):
    return (sigmoid(X @ w + b) >= 0.5).astype(int)
~~~

### 4.4 处理否定作用域

遇到否定词后给后续词加NOT_前缀，直到终止标点。这是启发式，不理解双重否定、从句或转折。tokenizer若提前删掉标点，作用域重置就会失效；若统一小写，别在后续处理中不小心丢掉特征约定。

~~~python
NEGATION_WORDS = {"not", "no", "never", "nor", "none", "nothing", "neither"}
NEGATION_TERMINATORS = {".", "!", "?", ",", ";"}


# 否定词后加前缀，遇到指定标点重置。
def apply_negation(tokens):
    out = []
    negate = False
    for token in tokens:
        if token in NEGATION_TERMINATORS:
            negate = False
            out.append(token)
            continue
        if token in NEGATION_WORDS:
            negate = True
            out.append(token)
            continue
        out.append(f"NOT_{token}" if negate else token)
    return out
~~~

~~~pycon
>>> apply_negation(["not", "good", "at", "all", ".", "but", "funny"])
['not', 'NOT_good', 'NOT_at', 'NOT_all', '.', 'but', 'funny']
~~~

### 4.5 评估而非只看准确率

TP、FP、FN、TN按1类为正统计，分母为0时约定返回0。原文强调逐类P/R、macro与weighted-F1、混淆矩阵和错误样本；极端不平衡时再结合PR曲线/AUPRC等。AUPRC依赖正类定义与基线比例；不能只传离散标签就声称评估了完整排序曲线。

~~~python
# 这里只计算1类的二分类指标，不是macro平均。
def evaluate(y_true, y_pred):
    tp = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 1)
    fp = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 1)
    fn = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 0)
    tn = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 0)
    precision = tp / (tp + fp) if tp + fp else 0
    recall = tp / (tp + fn) if tp + fn else 0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0
    return {"tp": tp, "fp": fp, "tn": tn, "fn": fn, "precision": precision, "recall": recall, "f1": f1}
~~~

## 五、把代码运行起来：补充入口与检查

补充的标准库端到端入口，先执行数据、NB函数及prep中的tokenize：
~~~python
train_docs = {
    "positive": [tokenize(t) for t in POSITIVE],
    "negative": [tokenize(t) for t in NEGATIVE],
}
vocab = build_vocab([d for group in train_docs.values() for d in group])
priors, probs = train_nb(train_docs, vocab, alpha=1.0)
print(predict_nb(tokenize("terrible acting"), priors, probs))
print(apply_negation(["not", "good", ".", "but", "funny"]))
print(evaluate([1, 1, 0, 0], [1, 0, 1, 0]))
~~~

## 六、Use It：使用现成工具

Pipeline把fit时学习的TF-IDF与分类器绑定，防止部署重写分词/词表。下方pipe.score返回accuracy，不是F1；原文强调的完整评估要另算。C越小通常正则越强，不要把它与手写l2参数同方向对应。原文的75%→85%等是未在本文复现的参考，不能当这套参数的性能保证。

~~~python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

pipe = Pipeline([
    ("tfidf", TfidfVectorizer(ngram_range=(1, 2), min_df=2, sublinear_tf=True, stop_words=None)),
    ("clf", LogisticRegression(C=1.0, max_iter=1000)),
])
pipe.fit(X_train, y_train)
print(pipe.score(X_test, y_test))
~~~

## 七、失败模式、原文边界与工程注意

1. 停用词删除可能误删否定；保留并非保证理解否定。
2. L2不是没有它就必然记忆训练集，强度要验证；class_weight也不是自动修复所有不平衡。
3. 原文说讽刺、方面情感“只能Transformer”过于绝对；也不能说未在情感数据上训练的多语BERT自动具有可靠零样本情感能力。
4. 类别比例70～80%不是所有语料的固定规律，应先看实际标签分布。
5. 二分类随机基线不一定50%，要说明平衡与抽样方式；多数类基线同样要报告。
6. 只在同一划分、预处理和指标上比较实验，别把论文数值当自己的基线。
