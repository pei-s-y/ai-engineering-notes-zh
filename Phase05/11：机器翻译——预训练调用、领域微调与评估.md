## 一、这一课解决什么问题？

翻译把可变长源序列映射到目标语言，词序、习语与信息对应关系不同。本课关注可操作流水线：语言代码、配套分词器、生成参数、参考指标和上线错误检查，而不是词对词替换。

## 二、核心概念与推导

源文本→模型配套tokenizer与源语言标识→encoder→decoder cross-attention→目标子词→detokenize。NLLB的eng_Latn/fra_Latn是语言与文字系统标记，不是普通英语缩写。

BLEU用n-gram精确率的几何平均与短译惩罚；sacrebleu通常报告0～100，别和某些实现的0～1混用。chrF基于字符n-gram的precision/recall/F分数，对词形变化较敏感。需要说明参考译文、tokenization、大小写和评估签名。

评价三层：BLEU/chrF等表面重叠；COMET等学习式评价；人工或LLM按充分性、流畅性、语域等rubric打分。各指标所需source/reference不同；“reference-free”不是所有COMET/BLEURT配置都自带的属性。

### 2.9 用一个小例子把概念串起来（补充）

一句英文送NLLB英→法时，tokenizer要有源语言配置，generate要有目标语言标记。得到法语后先核对人物、日期、否定和{name}等变量，再看BLEU/chrF。即使句子很流畅，June误成July仍是事实错误；即使表达与参考不同，也可能正确，因此自动指标和人工审查各有职责。

## 四、Build It：原课分步代码与中文讲解

### 4.1 调用预训练NLLB

src_lang设源语言，forced_bos_token_id约束生成的目标语言标记。num_beams与length_penalty控制搜索，不是训练。原文法语句子是参考，实际输出受模型版本与设置影响。模型.eval与无梯度有助于明确推理语义。

~~~python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

model_id = "facebook/nllb-200-distilled-600M"
tok = AutoTokenizer.from_pretrained(model_id, src_lang="eng_Latn")
model = AutoModelForSeq2SeqLM.from_pretrained(model_id)

src = "The cats are running."
inputs = tok(src, return_tensors="pt")

out = model.generate(
    **inputs,
    forced_bos_token_id=tok.convert_tokens_to_ids("fra_Latn"),
    num_beams=5,
    length_penalty=1.0,
    max_new_tokens=64,
)
print(tok.batch_decode(out, skip_special_tokens=True)[0])
~~~

~~~text
Les chats courent.
~~~

### 4.2 BLEU与chrF

references外层是一组参考译文流，每条流与hypotheses对齐；不是把每个句子随意嵌套。单句且不足4-gram的BLEU可能受有效阶数与平滑设置影响，即使完全相同也不要机械要求默认corpus BLEU必为100；chrF的表现约定另看接口。

~~~python
import sacrebleu

hypotheses = ["Les chats courent."]
references = [["Les chats courent."]]

bleu = sacrebleu.corpus_bleu(hypotheses, references)
chrf = sacrebleu.corpus_chrf(hypotheses, references)
print(f"BLEU: {bleu.score:.1f}  chrF: {chrf.score:.1f}")
~~~

### 4.3 三类评价与校准

原文列传统指标、学习指标和LLM裁判，均需在你的语言/领域人工样本上核对。原文COMET排名、80%一致率及“生产默认”无本次复现实验支持；不是一套工具名就能消除评估偏差。



### 4.4 生产错误分类

分别检查内容捏造、目标语言错误、术语不一致、礼貌/语域和长度异常。输出长度异常只是报警信号，不能自动证明幻觉；只靠输入长度比例也可能误伤合法扩写语言。



### 4.5 领域微调

原文只有一条平行句，是接口草图不是可用训练集。tok(text_target=...)会产生labels，但需明确目标语言，并把目标PAD改为-100以免把PAD当训练目标。领域数据质量重要，仍需独立验证，不能用“一条训练成功”证明效果。

~~~python
from transformers import Trainer, TrainingArguments
from datasets import Dataset

pairs = [
    {"src": "The defendant pleaded guilty.", "tgt": "L'accusé a plaidé coupable."},
]

ds = Dataset.from_list(pairs)


# 需核对目标语言与目标PAD的-100处理，原片段只是接口示范。
def preprocess(ex):
    return tok(
        ex["src"],
        text_target=ex["tgt"],
        truncation=True,
        max_length=128,
        padding="max_length",
    )


ds = ds.map(preprocess, remove_columns=["src", "tgt"])

args = TrainingArguments(output_dir="out", per_device_train_batch_size=4, num_train_epochs=3, learning_rate=3e-5)
Trainer(model=model, args=args, train_dataset=ds).train()
~~~

## 五、把代码运行起来：补充入口与检查

先运行原课翻译调用，再检查语言标记与占位符是否保留。微调前的补充核对：
~~~python
tok.tgt_lang = "fra_Latn"
# 对原文preprocess函数生成的一条结果检查目标标签
example = preprocess({"src": "The cats run.", "tgt": "Les chats courent."})
example["labels"] = [
    -100 if t == tok.pad_token_id else t
    for t in example["labels"]
]
assert len(example["input_ids"]) == len(example["attention_mask"])
~~~

## 七、失败模式、原文边界与工程注意

1. BLEU30/40/50不能跨语言、语料和分词当统一质量等级；小于1分也不必然只是噪声，应做置信区间或配对检验。
2. 没有参考不能猜BLEU范围来冒充自动评分。
3. 回译相似不代表原译完全正确，两个方向可能共享偏差。
4. 原文80%成功、20%失败等比例未在本次验证。
5. 医疗/法律等译文的事实审查需要合格人工或领域流程，本文只是技术学习，不构成专业内容审查。
6. 某个模型“支持200语言”不等于所有方向都同样可靠。

## 九、Exercises：保留原课练习与验收方法

## 十、术语与完成标准

NMT：神经机器翻译；parallel：对齐源/目标语料；BLEU：带短译惩罚的n-gram指标；chrF：字符F指标；register：语域；constrained decoding：施加词/格式约束的生成。

完成检查：

- 能区分源语言标识和目标语言控制。
- 能解释指标参考的嵌套形状。
- 能指出PAD标签与训练样本不足问题。
- 能审查实体、数字和占位符而非只看流畅度。
