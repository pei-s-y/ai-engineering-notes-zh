### 0.1 先理解这一课在做什么

训练时不仅要有最终答案，还要知道每个参数怎样影响误差。反传会用前向的中间量。全部保存省重算但占空间；checkpoint只保存部分入口，反传时从这些入口重新算中间结果。

### 0.2 本课术语先翻成白话

- 链式法则=把多步影响的变化率相乘

- activation=前向中间量

- recompute=重算

- segment=一段连续层

- checkpoint在这里=激活检查点，不是模型存盘

- offload=搬到CPU等地方暂存。

### 0.3 用小数字走一遍

标量y=wx，loss=(y-t)^2，x2、w3、目标t5：y6、loss1，dL/dy=2，dy/dw=x=2，所以dL/dw=4。反传要用x。若没保存某段中间量，可以从保存的入口重新算出来，再应用同样的链式法则。

## 一、这一课解决什么问题？

反向传播需要前向中间量，训练长序列时激活会占大量显存。activation checkpointing保留分段输入、反传时重算中间结果，用计算换内存。本课有真实手写MLP反传，可验证梯度等价；与前几课只有随机权重扰动的“训练模拟”不同。它也不同于保存模型文件用于断点续训的checkpoint。

## 二、核心概念与推导

### 2.1 反传需要哪些量
线性y=xW+b：dW=xᵀdy，dx=dyWᵀ，db按batch求和；ReLU需知道preactivation>0的mask。autograd为求梯度保留部分张量，不是所有张量都必须retain_grad；retain_grad是保留非叶子梯度的另一个操作。手写实现可选择保存或重算。

### 2.2 分段重算
L层分成长度k的段，前向只留段输入；反传从末段开始，取输入重跑段前向，得到局部中间量，求局部梯度，释放后处理前一段。只要参数、随机性和有状态行为一致，结果应与基线相符。dropout RNG、BatchNorm统计、FP8 amax等状态不能在重算时无意多更新。

### 2.3 简化成本模型
若forward=F、backward≈2F，无检查点约3F，全部重算一遍约4F，所以额外成本占完整step约1/3；是“总step FLOPs多33%”，不是“forward只多33%”。选择性重算若占forward的15%，额外完整step成本为.15/3=5%。真实早停重算、kernel、通信会改变比例。

### 2.4 分段内存与sqrt-L
一般可写M(k)≈ceil(L/k)S+kA+C，其中S是段输入大小，A是活动段每层中间量，C是常驻项。忽略取整时最优k≈sqrt(LS/A)，只有S≈A才近sqrt(L)。源码(n_seg+k)×B×T×d×bytes把S与A视作同单位并省掉其他项，只是示意；原文“重算算量也随sqrtL”不符合本课每层重算一次的4F模型。

### 2.5 selective、FlashAttention与offload
选择存储贵而重算相对便宜的张量，可以获得更好的折中。朴素attention概率矩阵为B×H×T²；FlashAttention不显式保存这个完整矩阵，额外checkpoint收益会变，但FFN/其他激活仍可省，不能一概说Flash下无用。CPU offload把张量来回搬运，要计双向带宽、延迟和可重叠时间。FSDP的参数/梯度卸载与activation卸载是不同对象。

### 2.6 并行与数值
TP重算可能重做collective，PP同时有多microbatch在途，峰值不能只算一个段。FP8重算需与原前向的尺度状态协调。原文“pipeline内部层不应checkpoint”“首末层不应checkpoint”等不是通用禁令，应测峰值与重算代价来选。

### 2.9 补充算例与理解检查

d8192,T8192,B1,BF16，按12BTd的粗模型：每层1,610,612,736bytes≈1.6106GB=1.5GiB，64层≈103.079GB=96GiB。k8的源码简化估计(8+8)×BTd×2=2,147,483,648bytes=2GiB；它与96GiB用了不同激活系数，不能声称真实网络必定省48倍。n_layers不是序列长度，记号L最好分别写层数/seq避免混淆。

### 原课概念部分的公式与结构示例

flops_fwd_normal = L * f_layer
flops_bwd_normal = 2 * L * f_layer
flops_total_normal = 3 * L * f_layer

flops_fwd_ckpt = L * f_layer
flops_recompute = L * f_layer  # one extra forward per layer in the segment

~~~

## 四、Build It：原课分步代码与中文讲解

### 4.1 两层MLP与保存层输入

linear_forward用@做矩阵乘，layer为Linear→ReLU→Linear。model_forward保存x及每层输出，为下一层反传提供输入。列表保存的是数组引用，没有自动拷贝；不得前后原地改写。

~~~python
import numpy as np


def linear_forward(x, w, b):
    return x @ w + b


def relu(x):
    return np.maximum(x, 0)


def layer_forward(x, w1, b1, w2, b2):
    h = relu(linear_forward(x, w1, b1))
    return linear_forward(h, w2, b2)


def model_forward(x, params):
    activations = [x]
    h = x
    for w1, b1, w2, b2 in params:
        h = layer_forward(h, w1, b1, w2, b2)
        activations.append(h)
    return h, activations
~~~

### 4.2 手写反传

从后往前，临时重算当前层h_pre和h，求W2/b2，再经ReLU mask求W1/b1和上游g。原“全保存”基线其实只保留层边界，仍重算了层内MLP，不能当PyTorch保存所有算子激活的完整内存基线。

~~~python
# 原基线只保存层边界；这里仍会重算层内ReLU。
def model_backward(grad_output, activations, params):
    grads = [None] * len(params)
    g = grad_output
    for i in range(len(params) - 1, -1, -1):
        w1, b1, w2, b2 = params[i]
        x_in = activations[i]
        h_pre = linear_forward(x_in, w1, b1)
        h = relu(h_pre)
        gh = g @ w2.T
        gw2 = h.T @ g
        gb2 = g.sum(axis=0)
        g_pre = gh * (h_pre > 0)
        gx = g_pre @ w1.T
        gw1 = x_in.T @ g_pre
        gb1 = g_pre.sum(axis=0)
        grads[i] = (gw1, gb1, gw2, gb2)
        g = gx
    return g, grads
~~~

### 4.3 每k层保存与分段反传

forward保存起点及整除k的边界；backward从最后有效段重算局部层输入，再调用前面的手写backward。L整除k时saved_inputs含最终输出，segments会多出空段，源码用start>=end跳过。L不整除k仍能按边界起点恢复最后短段。

~~~python
def model_forward_checkpointed(x, params, k=4):
    saved_inputs = [x]
    h = x
    for i, (w1, b1, w2, b2) in enumerate(params):
        h = layer_forward(h, w1, b1, w2, b2)
        if (i + 1) % k == 0:
            saved_inputs.append(h)
    return h, saved_inputs


# 反向遍历有效段，重跑局部forward后调用手写backward。
def model_backward_checkpointed(grad_output, saved_inputs, params, k=4):
    grads = [None] * len(params)
    g = grad_output
    segments = [(j * k, min((j + 1) * k, len(params))) for j in range(len(saved_inputs))]
    for seg_idx in range(len(saved_inputs) - 1, -1, -1):
        start, end = segments[seg_idx]
        if start >= end:
            continue
        x_in = saved_inputs[seg_idx]
        _, seg_acts = model_forward(x_in, params[start:end])
        g, seg_grads = model_backward(g, seg_acts, params[start:end])
        for j, gr in enumerate(seg_grads):
            grads[start + j] = gr
    return g, grads
~~~

### 4.4 FLOPs预算

docs checkpoint_cost不论segment_size都加完整额外forward，selective则加attention_fraction。这是简化模型，segment_size参数并未影响docs成本；原code/main.py用( k−1 )/k算额外量，与它实际完整重算所有段的算法又不一致，尤其k1写0%却仍重算。对照时必须说明选用哪种模型。

~~~python
# docs版本假设每层完整重算一次，segment_size不影响此公式。
def checkpoint_cost(n_layers, segment_size, flops_per_layer=1.0):
    fwd = n_layers * flops_per_layer
    recompute = n_layers * flops_per_layer
    bwd = 2 * n_layers * flops_per_layer
    return {
        "fwd": fwd,
        "recompute": recompute,
        "bwd": bwd,
        "total": fwd + recompute + bwd,
        "overhead_vs_no_ckpt": (fwd + recompute + bwd) / (fwd + bwd) - 1.0,
    }


def selective_checkpoint_cost(n_layers, attention_fraction=0.15,
                              flops_per_layer=1.0):
    fwd = n_layers * flops_per_layer
    recompute = n_layers * attention_fraction * flops_per_layer
    bwd = 2 * n_layers * flops_per_layer
    return {
        "fwd": fwd,
        "recompute": recompute,
        "bwd": bwd,
        "total": fwd + recompute + bwd,
        "overhead_vs_no_ckpt": (fwd + recompute + bwd) / (fwd + bwd) - 1.0,
    }
~~~

### 4.5 内存估算

activation_memory_mb按12BTd估基线；memory_after_checkpoint用floor段数，L非整除时会低估，应改ceil。它又省了活动段真实中间量系数、权重/梯度/优化器、工作区与PP在途张量，不是真实CUDA峰值。

~~~python
def activation_memory_mb(n_layers, hidden=8192, seq=8192,
                        batch=1, bytes_per_value=2):
    per_layer = 12 * batch * seq * hidden * bytes_per_value
    return n_layers * per_layer / 1e6


# 原课简化估计使用floor，非整除时应改ceil；不是实际峰值。
def memory_after_checkpoint(n_layers, segment_size, hidden=8192,
                           seq=8192, batch=1, bytes_per_value=2):
    n_seg = max(1, n_layers // segment_size)
    saved = (n_seg + segment_size) * 1 * batch * seq * hidden * bytes_per_value
    return saved / 1e6
~~~

### 4.6 sqrt近似

optimal_segment取round(sqrt(L))，只适用于简化同质假设；至少约束1≤k≤L，并实际扫描候选值。实际最优也受硬件、非均匀层、通信、FlashAttention影响。

~~~python
# 仅同质简化模型的启发式，不是硬件最优保证。
def optimal_segment(n_layers):
    return int(round(np.sqrt(n_layers)))
~~~

### 4.7 按张量与成本选重算

should_recompute以attention>100MB、FFN>500MB及重算比<.1做硬阈值，是教学决策。docs参数activation_bytes用bytes，main版本activation_bytes_mb用MB；调用时必须统一，不能直接混用。

~~~python
def should_recompute(layer_type, activation_bytes, recompute_flops_ratio):
    if layer_type == "attention" and activation_bytes > 100 * 1e6:
        return True
    if layer_type == "ffn" and activation_bytes > 500 * 1e6:
        return recompute_flops_ratio < 0.1
    return False
~~~

### 5.1 补充：把原文七段按顺序放入同一临时学习脚本后运行
这段用原docs定义的函数（不是main.py不同版本），产生小MLP，比较输出、输入梯度、每个参数梯度，额外验证L不能整除k。均无下载。

~~~python

rng = np.random.default_rng(0)
n_layers, hidden, inner, batch = 6, 8, 16, 2
params = []
for _ in range(n_layers):
    w1 = rng.normal(0, 0.1, (hidden, inner))
    b1 = np.zeros(inner)
    w2 = rng.normal(0, 0.1, (inner, hidden))
    b2 = np.zeros(hidden)
    params.append((w1, b1, w2, b2))
x = rng.normal(size=(batch, hidden))
y, acts = model_forward(x, params)
dy = rng.normal(size=y.shape)
dx, grads = model_backward(dy, acts, params)

for k in (1, 2, 4, 6, 8):
    y_ck, saved = model_forward_checkpointed(x, params, k=k)
    dx_ck, grads_ck = model_backward_checkpointed(dy, saved, params, k=k)
    max_diff = max(float(np.max(np.abs(a - b)))
                   for gs, gc in zip(grads, grads_ck)
                   for a, b in zip(gs, gc))
    print(k, 'output=', np.allclose(y, y_ck),
          'dx=', np.allclose(dx, dx_ck), 'max_grad_diff=', max_diff)
    assert np.allclose(y, y_ck)
    assert np.allclose(dx, dx_ck)
    for gs, gc in zip(grads, grads_ck):
        for a, b in zip(gs, gc):
            assert np.allclose(a, b, atol=1e-10, rtol=1e-8)
~~~

预期True/True，梯度差应为0或很小浮点误差；这是运行后应检查的目标，本次是否执行见导航。再用有限差分检查少数参数：扰动±ε，比较(y·dy).sum()差分与反传梯度；避免扰动跨ReLU零点。不能只检查两个实现彼此一致，因为共同错误也可一致。

### 5.2 标准库即可核对的内存/成本修正
~~~python
import math

def segment_memory_estimate(layers, k, batch, seq, hidden,
                            bytes_per_value=2, saved_factor=1, local_factor=12):
    if layers < 1 or k < 1:
        raise ValueError('layers和k必须为正')
    k = min(k, layers)
    # 显式分开段边界和活动段中间量的系数；仍是粗估。
    unit = batch * seq * hidden * bytes_per_value
    return (math.ceil(layers / k) * saved_factor + k * local_factor) * unit

print('64层粗基线GiB:', 64 * 12 * 8192 * 8192 * 2 / 2**30)
print('docs完整重算成本:', checkpoint_cost(64, 8))
print('docs选择性重算成本:', selective_checkpoint_cost(64))
print('不同系数估算GiB:', segment_memory_estimate(64, 8, 1, 8192, 8192) / 2**30)
~~~

预期96GiB；成本256对比基线192约33.33%；selective201.6对比192约5%；最后估计13GiB，只是说明换入local_factor12会改变结果，不是实际测量。

### 5.3 可选：真实PyTorch最小梯度对照（先CPU）
按[官方checkpoint说明](https://docs.pytorch.org/docs/main/utils/checkpoint.html)，显式设置use_reentrant=False，并保持重算与原前向一致。以下是补充实现，需要你现有环境已安装torch。

~~~python
import copy
import torch
from torch import nn
from torch.utils.checkpoint import checkpoint

torch.manual_seed(0)
base = nn.Sequential(nn.Linear(8, 16), nn.GELU(), nn.Linear(16, 8))
ck_model = copy.deepcopy(base)
x = torch.randn(2, 8, requires_grad=True)
x_ck = x.detach().clone().requires_grad_(True)
base(x).square().mean().backward()
checkpoint(ck_model, x_ck, use_reentrant=False).square().mean().backward()
print('input gradient match:', torch.allclose(x.grad, x_ck.grad))
print('parameter gradient match:',
      all(torch.allclose(a.grad, b.grad)
          for a, b in zip(base.parameters(), ck_model.parameters())))
~~~

预期两个True；本次不宣称已跑。GPU计时需预热、每次zero_grad(set_to_none=True)、reset_peak_memory_stats、边界synchronize，再分别记录完整forward+backward+optimizer step；同样模型、batch、dtype、seed、优化器和测量边界。allocated与reserved分别报告。

## 六、Use It：使用现成工具

PyTorch checkpoint是首个实际入口。需要activation offload时可研究[autograd.graph.save_on_cpu](https://docs.pytorch.org/docs/main/autograd.html)，其保存反传所需张量到CPU；这与[FSDP CPUOffloadPolicy](https://docs.pytorch.org/docs/main/distributed/fsdp.fully_shard.html)处理参数/梯度不是同一功能。原课把module.to_empty(device='cpu')称为激活卸载有误：to_empty不复制已有参数数据，不可当作保值卸载接口。Megatron/DeepSpeed应按所装版本区分recompute、参数卸载、optimizer卸载及专门activation功能，不直接套用文档中的概述当完整启动配置。



## 七、失败模式、原文边界与工程注意

1. checkpoint在这里是激活重算，不是定期torch.save权重。
2. 源docs与main的函数签名、成本模型、MB单位存在差异；本笔记第四节保留docs，第五节明确使用它，避免混搭。
3. 重算必须是同一个函数的同一语义；随机数、全局变量、原地修改、归一化运行统计可能使梯度不同。
4. 12BTd和5%是估计假设，原课70B+128k每rank3TB也不是独立于分片策略的通用真值。
5. FlashAttention减少特定attention中间量，不能因此排除FFN或整个block重算收益。
6. CPU列表间复制不等于真实PCIe卸载，不能把copy速度写成PCIe带宽；要用实际device拷贝并同步测量。
7. 此MLP没有attention，第3个selective练习需另建Transformer，不能声称本toy已经实现。

## 九、Exercises：保留原课练习与验收方法

1. **梯度等价。** 用第五节覆盖k1、整除和非整除、k>L，比较输出、dx及全部参数梯度；补少量有限差分。机器精度应按dtype和误差容忍表述，不要求任意硬件bitwise相同。
2. **扫描k1…L。** 分别画保存边界量、活动段估计及成本；docs简化FLOPs曲线应近常数33%，不是因k变化自然出现成本最优。再换真实测量寻找峰值/速度折中。
3. **selective。** 另建小Transformer，先短seq测attention与FFN的保存/重算，再逐步增大；32层seq8192要先做内存预算。报告FlashAttention是否启用，不能用本MLP假称已测attention。
4. **offload。** 可先用独立CPU buffer学习生命周期，但该copy时间不是PCIe。实际GPU→CPU→GPU字节数/时间，和重算时间比较，记录是否可重叠，再找盈亏点。
5. **真实PyTorch基准。** 同配置比较未包装与checkpoint包装模型的峰值allocated/reserved和step time；先验证梯度与loss合理，再报告省内存百分比和耗时增加，而非只报告能否运行。

## 十、术语与完成标准

|术语|含义|
|---|---|
|activation checkpointing|保存少量段输入、反传时重算中间量|
|rematerialization|重新产生反传需要的激活|
|segment size k|一段包含多少层|
|selective checkpointing|对部分算子/张量选择保存或重算|
|activation offload|将激活移到CPU等存储后再取回|
|FLOP overhead|额外重算FLOPs除以原完整step FLOPs|
|peak allocated/reserved|实际张量使用/分配器保留显存峰值|
|RNG state|随机数生成器状态，影响dropout重算一致性|

完成检查：

- [ ] 能手写Linear与ReLU反传并解释每个保存量用途。
- [ ] 能解释3F→4F为何是完整step多33%。
- [ ] 能区分段边界与活动段系数，不盲信sqrtL。
- [ ] 能识别to_empty不是保值激活卸载。
- [ ] 能设计梯度等价与GPU峰值/延迟的公平实验。
