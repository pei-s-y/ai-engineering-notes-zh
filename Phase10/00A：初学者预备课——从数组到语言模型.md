# 初学者预备课：从数组到语言模型

> 2026-10-31 新增教学补充。面向刚接触模型项目的读者，不要求先会深度学习框架。这里的小数字是解释用算例，运行结果在执行前称为“预期”。原课材料和历史验证记录保留在各篇正文中。

## 1. 先把整章放进一条线

语言模型反复完成一个任务：**根据已有片段，给下一个片段的各种可能性分配概率。**

例如输入“今天的天气很”，模型可能给“好”较高概率，也可能给“冷”一定概率。选出一个片段、接到已有文字后面，再重复计算，才能形成长回答。预测的单位叫token，可能是一整个词、半个词、标点或一部分字符字节。

全章可以按下面的关系理解：

1. 第01—03课准备输入：怎么把文字变编号，怎么组成训练材料。
2. 第04课建立计算函数：编号变向量，经过模型，输出候选分数和概率。
3. 第05课研究怎样把训练分配到更多硬件。
4. 第06—09课更换训练数据和目标，让模型更会按要求回答、符合偏好。
5. 第10课判断表现，第11—12课减少存储或生成开销，第13课把步骤组织起来。
6. 后续课研究新的模块、架构与运行方法；它们仍围绕输入、计算、训练目标、资源和评估展开。

理解模型只需不断追问：输入是什么？输出是什么？错误怎样计分？参数怎样根据错误更新？先用小例回答，再看完整代码。

## 2. 数、向量、矩阵、张量和shape

一个数如3叫标量。一排数如[2,5,1]叫向量。多排等长向量放成表格叫矩阵。张量是这些规则排列的数字容器的统称，可以有更多轴。深度学习框架的Tensor还有dtype、所在设备和梯度记录等属性，不等于任意嵌套Python列表。

shape说明每个轴有多少项。例如[[1,2,3],[4,5,6]]有2行3列，形状(2,3)，共6个数。形状本身不说明每个轴的含义，含义由数据协议决定。

语言模型里常见符号：

|符号|通常表示|小例|
|---|---|---|
|B|一次共同计算的样本条数，即batch size|2条句子|
|T|每条序列的位置数|每条3个token|
|d|每个位置的特征向量长度|每位置4个数|
|V|词表大小|可选10种token|
|L|重复模块的层数|2层|
|h|注意力头数|2个头|

输入ID是(B,T)=(2,3)，共有6个整数。查embedding后变成(B,T,d)=(2,3,4)，共有24个实数。输出logits可为(B,T,V)=(2,3,10)，共有60个分数：每条、每个位置、每种候选各一个。

同一个字母在别处可能换含义：attention公式中的V通常是“值向量矩阵”，不一定表示词表大小；SSM的h_t是状态，不是注意力头数。读公式时先给符号贴中文含义，不能只记字母。

### Python索引如何对应轴

`x[b,t,k]`通常取第b条、第t个位置、第k个特征；从0开始编号。`x.shape[-1]`取最后一轴长度；`sum(axis=-1)`沿最后一轴加起来。`keepdims=True`让被归约的轴留下长度1，方便后面做广播。

`reshape`重新安排同样数量的元素，例如(2,3,4)可改成(2,3,2,2)；它不会自动“找到两种语义”。`transpose`或交换轴用于改变轴的排列，必须跟清每一轴表示什么。

## 3. 看懂@、转置、广播与线性层

`*`在NumPy数组里通常逐元素相乘，`@`做矩阵乘。向量[2,3]与[4,5]点积为2×4+3×5=23。

设输入x=[2,3]，权重矩阵W的两行是[1,0,2]、[0,1,1]。则x@W=[2,3,7]。输入长度2经过这个映射变成长度3；矩阵形状为(2,3)。一般(A,B)@(B,C)得到(A,C)，中间维必须匹配。

线性层写作y=xW+b：W和b是可训练参数，x是本次输入。bias即偏置，给每个输出加一个可学习的常数。深度学习里的“线性层”常包含这个偏置，严格数学上属于仿射映射。

转置W.T把行列互换；多维张量的转置要明确交换哪些轴，不能看到.T就假定符合attention需要。广播是按兼容轴扩展参与计算，例如给形状(B,T,d)的每个位置加同一份长度d偏置。它是数组规则，不是模型理解了哪些地方应该共享。

## 4. ID、embedding与参数有什么区别

假想词表是猫→0、狗→1、句号→2。ID表示查表行号。embedding表可以是：

|ID|片段|向量（仅示意）|
|---|---|---|
|0|猫|[.2,.8]|
|1|狗|[.3,.7]|
|2|句号|[-.4,.1]|

输入[0,1]查表后得到[[.2,.8],[.3,.7]]。这不是把编号0和1当作语义大小。初始向量可能随机产生，训练通过目标函数调整它们；一条示例向量的某个维度通常不能直接命名为“可爱程度”。

参数是长期学习和保存的数值，如embedding表、W、b。激活是某次输入产生的中间结果。相同参数换输入，会产生不同激活。checkpoint模型文件保存参数等状态；第34课的activation checkpointing则是一种激活保存/重算策略，要按语境区分。

## 5. 分数为什么要变成概率：softmax

模型输出的原始分数叫logits，可以负、可以大于1，通常不相加为1。softmax将每个分数s_i变成：

$$p_i=\frac{\exp(s_i)}{\sum_j\exp(s_j)}$$

exp是指数函数；分子使各项为正，分母把总和归一化为1。求和符号Σ表示把指定范围各项加起来。三个分数[ln2,0,0]的exp是[2,1,1]，所以概率为[.5,.25,.25]。ln是自然对数，与exp互为反函数：exp(ln2)=2。

argmax挑最大分数的候选；sampling按概率随机抽。例如概率[.5,.25,.25]并不保证每次选第一个，只表示重复大量抽取时比例趋向这个分布。固定seed有助于重复一段程序的随机过程，不保证不同算法的输出逐次完全相同。

temperature是采样前的分数缩放参数。正温度越低通常越集中，越高通常越平缓；温度0需使用单独的贪心argmax分支，不能直接把所有分数除以0。

## 6. loss、梯度、反向传播与优化器

loss是把预测错误变成数值的规则。下一token任务常用交叉熵，对单个正确目标可写为L=-ln(p_correct)，也就是正确目标概率的自然对数再取负号。正确目标概率.25时L≈1.386；概率.5时L≈.693；概率越接近1，loss越接近0。不同任务或计数协议的loss数值不能不加区别地比较。

梯度告诉我们：在当前参数附近，某个参数增加一点，loss局部会怎样变化。优化器利用梯度决定更新；最简单的梯度下降是w_new=w-lr×gradient，lr就是学习率。这个局部方向不保证任意大步长都使loss下降。

手算：x=2、w=3、预测y=wx=6、目标t=5，平方误差L=(y-t)^2=1。dL/dy=2(y-t)=2，dy/dw=x=2，链式法则得到dL/dw=4。学习率.1时w更新为2.6，预测5.2，loss=.04。这是一次真实按目标更新的例子。

前向传播是“给输入算预测和loss”；反向传播是“按链式法则求各参数梯度”。自动微分框架记录计算关系，替你求导；它仍需要可微运算连接起来，不能对普通NumPy数组直接调用loss.backward就自动训练。

训练常见顺序：清旧梯度→前向→loss→backward→optimizer.step。只反复打印loss、或给参数加随机噪声，都没有证明按这个目标学习。第04—09课的原代码存在相应简化/缺口，正文具体说明会在建立概念后再读。

## 7. Attention逐步是什么意思

一个位置需要结合上下文，attention让它对可见位置算相关分数，再按权重取回信息。Q是查询表示，K是供匹配的表示，V是被取回的内容表示。它们通常由同一输入X乘不同可训练矩阵得到，不是原始文字本身。

计算顺序是Q与各K点积→按维度缩放→遮住不可见位置→softmax得到权重→对各V加权求和。

假想查询q=[1,0]，两个key=[2,0]、[0,2]，点积为2、0。按向量维数2的平方根缩放后是√2、0，softmax约[.804,.196]。若两个value是[10,0]、[0,10]，输出约[8.04,1.96]。权重描述本次计算中的加权，不是“模型有80.4%概率理解了第一句话”。

自注意力指同一序列产生查询和被查询信息。多头attention把特征分成多组做类似计算，再合并；不同头是否对应明确可命名功能要检验，不预设一个头一定只管语法。

## 8. 因果mask、padding mask和loss mask

mask本意是遮罩/选择规则，具体含义由使用位置决定：

|种类|回答什么问题|小例|
|---|---|---|
|因果mask|这个query允许看哪些位置？|第一个位置不能看到后续正确答案|
|padding mask|哪些位置是补位？|长度2补成4后，末两项不是真实输入|
|loss mask|哪些目标算进训练误差？|SFT常只对回答部分直接计分|

训练序列[A,B,C,D]可构造输入[A,B,C]、目标[B,C,D]。第一个位置只见A预测B，第二个见A/B预测C。训练时可以并行算多个位置，但因果mask禁止借助各位置后面的内容。

在attention分数上加负无穷，被遮位置exp后变0。若只把原分数设0，exp(0)=1，softmax后仍有权重，因此并未真正禁止访问。另一方面，在乘loss时用0可以表示不计分；不能把两种0/1协议混用。

## 9. 一个Transformer块里的其他零件

- FFN：前馈网络，对每个位置的向量进一步加工，常先升维再降维，中间用非线性函数。若只有线性映射，多层仍能合成一个线性映射，非线性让表示能力更丰富。
- ReLU：把负数截到0；GELU、SiLU是不同非线性，不能看到函数名就忽略实际代码。
- 残差：把模块输入x与模块输出f(x)相加。它提供直接传递与梯度路径，不是把文本原句拼回去。
- LayerNorm/RMSNorm：根据当前位置的特征尺度做规范化，再配合可学习参数。它们不等于对训练集做同一种数据标准化，也不保证输出是概率。
- 位置信息：token顺序影响意义。位置embedding通过查表等方式加入位置，RoPE则通过对Q/K分量旋转影响相对位置关系。初读先明白“顺序须被表示”，后续再看公式。

## 10. 条件概率、log-prob、sigmoid和KL

π(y|x)读作“已知x时，模型给y的概率”。π通常表示策略/模型分布，不是圆周率。回答逐token生成，整段概率是每一步条件概率的乘积。例如两个条件概率.5和.2，整段概率.1；log概率为ln(.5)+ln(.2)=ln(.1)。不同长度的整段概率不宜直接解释为回答质量。

sigmoid(z)=1/(1+exp(-z))，把一个实数变为0到1。z=0时为.5，z=1时约.731。softmax给多个候选一起分配概率，sigmoid常将一个比较分数解释为二元概率；用法要看目标函数。

KL(P||Q)=ΣP_i ln(P_i/Q_i)，用于衡量P相对Q的分布差异。P=Q时为0；方向交换一般不同，它不是普通直线距离。若P_i>0而Q_i=0，该项趋于无穷。RLHF里可用它惩罚偏离参照太远，但接近参照不等于必然安全或正确。

第07—09课会出现奖励、策略与优势：奖励是任务评分，策略是输出概率规则，优势表示相对基线好多少。奖励通常不直接等于可反传的参数梯度，需要合适的目标把评分连接到策略概率。

## 11. 内存、速度与大O怎样读

参数量乘每参数字节只是权重部分。训练还需梯度、优化器状态、激活和临时空间；推理还需KV缓存等。FP32通常每元素4字节，FP16/BF16通常2字节，具体训练可能保留多份不同精度状态。

1GB=10^9字节，1GiB=2^30字节。1000个数每数2字节是2000字节；编号数值小并不自动改变数组dtype。量化到4bit的理论紧凑存储是每数半字节，但必须实际打包才能得到这个收益。

latency是一个请求等多久；throughput是单位时间完成多少工作。多个请求共同计算可能提高吞吐，但单请求延迟仍可能上升。O(T)表示随长度的增长阶，不是精确毫秒；O(1)也不意味着没有固定内存。比较速度时要固定任务、硬件、精度、batch、输入输出长度及测量边界。

## 12. 一段可手算再运行的完整小练习

这段是本次新增的标准库教学补充，不调用模型、不安装库。它连接了点积、softmax、交叉熵与一次真实参数更新。

```python
import math

# 1. 两个向量点积：对应分量相乘，再求和。
dot = sum(a * b for a, b in zip([2, 3], [4, 5]))
assert dot == 23

# 2. 把候选分数变成概率。减最大值保持结果不变，并改善数值稳定性。
scores = [math.log(2), 0.0, 0.0]
largest = max(scores)
weights = [math.exp(s - largest) for s in scores]
probs = [w / sum(weights) for w in weights]
loss = -math.log(probs[0])  # 假设正确答案的编号为0。
print('概率:', probs, '交叉熵:', loss)

# 3. 标量回归的一次梯度下降；它不是大语言模型训练。
x, w, target, lr = 2.0, 3.0, 5.0, 0.1
prediction = x * w
before = (prediction - target) ** 2
gradient = 2 * (prediction - target) * x
w = w - lr * gradient
after = (x * w - target) ** 2
assert after < before
print('更新后权重:', w, '误差:', before, '->', after)
```

预期概率[.5,.25,.25]、交叉熵约.693147；权重2.6、平方误差1降至约.04。浮点输出可能带很多小数位。不要把这个小回归例成功等同于原课MiniGPT已能训练。

本次核对（2026-10-31）：上述标准库代码已执行，打印概率[0.5,0.25,0.25]、交叉熵0.6931471805599453、更新后权重2.6、误差1.0→0.04000000000000007，两个断言通过。这只验证本节小算例，不代表执行了全章模型训练。

## 13. 带答案自测与后续阅读

1. (2,3,4)里有几个数？**24个；每轴的语义还要查约定。**
2. logit=-2是不是负概率？**不是，logit尚未归一化成概率。**
3. embedding查表与模型训练是否同一操作？**查表是前向步骤，训练还需目标、梯度和更新。**
4. 正确答案概率提高，单目标交叉熵如何变化？**降低，因为-ln(p)随p增大而减小。**
5. loss改变能否证明参数学到了？**不能，输入变化或随机过程也能改变loss。**
6. 为什么多卡和量化不是同一种省空间方法？**前者改变任务/状态分布，后者改变数值表示，可能组合但省的是不同部分。**
